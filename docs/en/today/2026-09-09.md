## LangChain launches Connections: managed credentials and per-caller identity for Managed Deep Agents

- **Summary**: LangSmith Managed Deep Agents v0.7.0+ adds Connections — named credentials stored in the LangSmith workspace (not in code/`.env`), retrieved at runtime via `connections.get("<slug>", {"type": "agent"|"user"})`; two independent axes, Owner (agent-shared vs. per-caller user-owned) and Credential Type (static secret vs. OAuth grant), eliminating the need to hand-build an OAuth callback route/token store/refresh logic.
- **Why it matters**: Solves two real enterprise pain points for hosted agents — credential security (rotate a key without redeploying) and per-caller identity (an action the agent takes on someone's behalf carries that actual person's identity, not a generic bot identity — e.g., a filed ticket shows their own handle); turns what used to require manual OAuth plumbing into a built-in framework capability.
