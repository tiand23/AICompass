## LangChain proposes "context modes" for multi-agent collaboration in Deep Agents: Forked vs Isolated Subagents

- **Summary**: LangChain adds a `'mode': 'fork'` context mode to the Deep Agents framework — a subagent inherits the supervisor's full current state and conversation history at spawn time (leveraging prompt caching to reuse it), as opposed to the default Isolated mode (subagent gets only the task description, starting from blank context); guidance: Worker agents → fork, Verifier/Researcher agents → isolated, Memory agents → fork.
- **Why it matters**: In supervisor/subagent architectures, a subagent starting from blank context often has to redo context-gathering work (like file reads) the supervisor already did, wasting compute and time; explicitly separating the two context-propagation modes turns this tradeoff from an implicit default into an explicit, role-based engineering decision.
- **Category**: Agent
- **Related Topic**: [deep-agents](/en/topics/deep-agents)
- **Source**: https://www.langchain.com/blog/organizing-context-in-a-multi-agent-harness

## Microsoft launches Discovery Engine and CLIO: a multi-path-reasoning agent for scientific discovery

- **Summary**: Azure AI launches Microsoft Discovery Engine, powered by CLIO (Cognitive Loop via In-Situ Optimization) — multiple independent reasoning paths explore a problem in parallel, compare notes and share intermediate findings, and converge on one evidence-backed result, with the ability to decide on its own to keep exploring, switch strategy, swap models, or bring in human domain experts; scores 61.6% on health/medicine, 75.2% on physical sciences, and 64.6% on life sciences on the "Agent's Last Exam" benchmark, and claims to have helped discover a novel organic redox flow battery.
- **Why it matters**: This is a concrete productization — in the vertical domain of scientific R&D — of the core Deep Agents question of what a long-horizon agent should do when it hits uncertainty (keep exploring / switch strategy / switch model / call a human), backed by comparable benchmark scores rather than pure concept marketing.
- **Category**: Agent
