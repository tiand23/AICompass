# 2026-09-05

## GPT-6 Astra lands on Microsoft Foundry: Limited Access Program, Global/US data zones only, no EU zone

- **Summary**: Microsoft announced that GPT-6 Astra (launched 09-03) is now available on Microsoft Foundry (the Azure channel), rolling out through a Limited Access Program. Right now it can only be purchased in the Global and US data zones — **there is no EU data zone**. Pricing: the Global standard tier runs $10 to $75 per million tokens (tiered by context length), with a premium in the US data zone ($11 to $82.50); both Standard (pay-as-you-go) and Provisioned Throughput (dedicated capacity) purchasing options are available. Core capabilities: Agentic Execution (structured planning and execution toward open-ended goals), Computer Use (parsing visual interfaces to operate legacy applications with no API), and generating technical reports/spreadsheets/slide decks matched to enterprise templates. Security integrations include Microsoft Entra identity management, encryption, private networking, and full activity logging.
- **Why it matters**: This is the concrete follow-through on the 09-03 GPT-6 Astra launch announcement's promise to open up on "Azure/AWS in the coming days" — and it's another instance of Foundry's "multi-vendor model marketplace" strategy, following xAI Grok 4.6 on 08-31. But this time it comes with explicit geographic restrictions (no EU zone) and staged access (Limited Access Program) — meaning the Critical-level cybersecurity rating isn't just constraining OpenAI's own release cadence, it's flowing directly into the cloud vendor's access policy too. Enterprise buyers now need to verify "can I actually buy this in my data zone" as a precondition, rather than assuming a new model landing on Foundry means it's available everywhere (see [cloud-agent-platforms](/en/topics/cloud-agent-platforms)).
