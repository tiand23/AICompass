# 2026-09-21

## LangChain launches Jev: a dedicated structured-verdict model replacing LLM-as-judge, now live in LangSmith Evals

- **Summary**: LangChain formally ships "Jev-as-a-Judge" (first teased 09-20) into LangSmith Evals — Jev isn't another LLM judge; it's a dedicated evaluation model that returns typed verdicts directly rather than generating text. In LangChain's own test, repeatedly judging the same 500 real agent decisions, Jev matched human-reviewer verdicts on every single call, with continuous quality-score variance 92–913x lower than GPT-5.6 Luna/Terra and Claude Sonnet 4.6, averaging 0.44 seconds and $0.00035 per call — $0.34 total for the whole test run versus $28.17 for Claude Sonnet 4.6 doing the same judging.
- **Why it matters**: This extends the "dedicated judge model replaces frontier-model evaluation" idea from LangSmith Tuned Evaluators' Perceived Error evaluator (08-18), but this time with consistency data showing complete agreement with a human baseline at scale — if results like this replicate more broadly, using a frontier LLM as judge may no longer be the default for high-throughput/online evaluation; but watch for the risk VentureBeat and others flagged: a structured-verdict model can still have its ruling swayed by prompt injection.
