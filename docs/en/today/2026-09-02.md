# 2026-09-02

## Azure publishes hard numbers on agent context engineering: 34% cheaper knowledge retrieval, 97% cheaper tool libraries

- **Summary**: Microsoft's Azure blog published a new entry in its "Economics of Agent Optimization" series, giving concrete quantitative results from context engineering on Microsoft Foundry: Foundry IQ's knowledge base — which replaces broad document search with semantic reranking and targeted passage retrieval — improves evidence recall by 54% and cuts retrieval token cost by 34%. Toolboxes, which fetch tool definitions on demand instead of stuffing every tool into the prompt, cut input token consumption by roughly 97% for large tool libraries. The piece also covers Skills (centrally managed, reusable workflows that can be updated without redeployment) and tiered memory (session/user/workflow-level), which reduces the token cost of replaying conversation history.
- **Why it matters**: This is a rare public case of enterprise-grade context engineering backed by concrete numbers, speaking directly to the core pain point of "agents getting more expensive the more they're used." The "fetch tools on demand" approach is the same direction as MCP's tool-discovery mechanism and the harness-engineering practice of trimming tool lists to avoid token bloat, expressed as a different implementation — and it's a further concretization of the "runtime optimization" layer in Azure's 08-12 "three-speed governance model."
