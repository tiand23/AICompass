## Liquid AI Releases LFM2.5-Encoders: Fast Long-Context Inference on CPU

- **Summary**: Liquid AI announced LFM2.5-Encoders on HuggingFace — encoder models optimized for efficient long-context inference on ordinary CPUs.
- **Why it matters**: "Long context without a GPU" directly lowers the deployment barrier and cost for embedding/retrieval workloads — a practical win for the embedding stage of RAG pipelines and for edge/on-prem deployments, and another signal that efficient architectures (Liquid's non-Transformer LFM line) keep landing in practice.
- **Category**: Deployment
- **Related Topic**: [model-efficiency](/en/topics/model-efficiency)
- **Source**: https://huggingface.co/blog

## 1,100+ Frontier-Lab Employees Sign an AI "Pacing" Open Letter

- **Summary**: More than 1,100 employees at OpenAI, Anthropic, Google and Meta signed an open letter urging the US government to lead the creation of a verifiable international "pacing mechanism" — able to coordinate a slowdown if AI advances faster than humans can safely oversee.
- **Why it matters**: Large-scale collective voice from **inside** frontier labs is rare (previous safety appeals came mostly from outside academics); together with the open-weights position statement and the ExploitGym incident, it's part of the continuing 2026 escalation of the safety debate — "verifiable international coordination" has moved from idea to concrete mechanism demand.
- **Category**: Other (policy / ecosystem)
- **Related Topic**: [agentic-safety](/en/topics/agentic-safety)
- **Source**: https://www.buildfastwithai.com/blogs/ai-news-today-july-29-2026

## Google Expands Gemini API Managed Agents: 3.6 Flash Default, Execution Hooks and Budget Controls

- **Summary**: A batch of Gemini API Managed Agents updates: the default model moves up to Gemini 3.6 Flash (with explicit selection of 3.5 Flash / Flash-Lite for other cost/performance points); new pre/post execution hooks inside the sandbox (command or HTTP handlers that can block, lint or audit tool calls and file writes); a `max_total_tokens` budget guardrail against runaway tasks (interrupted runs can resume with a fresh budget); cron-scheduled triggers with persistent sandbox reuse; an Environments API for managing sandbox sessions; and a free tier.
- **Why it matters**: The "productionization trio" for hosted agent runtimes (hook validation pipelines, budget guardrails, scheduled tasks) is now complete on Google's platform — moving from "can run agents" to "can operate agents", squarely aligned with Claude Managed Agents' engineering trajectory; the in-sandbox validation hook design is also a useful reference for self-built runtimes.
- **Category**: Agent
- **Related Topic**: [cloud-agent-platforms](/en/topics/cloud-agent-platforms)
- **Source**: https://blog.google/innovation-and-ai/technology/developers-tools/expanding-managed-agents-gemini-api-3-6-flash-hooks/
