## LangChain Releases Deep Agents v0.7

- **Summary**: The base harness was simplified — 65% fewer base input tokens at comparable performance; filesystem tools overhauled (paginated read_file, grep with a 1,000-match cap and streamed output, no more hangs on large trees); message history moved to DeltaChannel incremental storage so checkpoints stay small as threads grow; experimental CodeInterpreterMiddleware enables code execution and programmatic tool calling in a scoped QuickJS runtime; breaking changes: TodoListMiddleware is now opt-in, backend factories removed.
- **Why it matters**: This changelog reads like the production pain list of long-horizon agents — token cost, checkpoint bloat, large-directory search; "65% fewer base tokens" is a direct cost cut for production deployments. Check the two breaking changes before upgrading.
- **Category**: Agent
- **Related Topic**: [deep-agents](/en/topics/deep-agents)
- **Source**: https://www.langchain.com/blog/deep-agents-v0-7
