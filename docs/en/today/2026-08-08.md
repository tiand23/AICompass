## Prime Intellect Releases prime-agent: An "RLM" Agent That Treats Context as Variables and Tools as Function Calls

- **Summary**: Prime Intellect open-sourced prime-agent (+2,293 stars in a day, 6.5k total) — an open-source agent for coding and long-running autonomous tasks, built on the RLM (Recursive Language Model) idea: running in a persistent Python REPL (IPython as the built-in model tool), it treats context as variables and tools as programmable function calls (including `rlm(...)` to spawn parallel subagents), rather than the conventional conversational tool-calling loop. It ships a `/refine` capability — reviewing task trajectories and writing evidence-backed updates back into supplemental harness state (memories, skills, subagent specs), persisting across sessions as a form of "self-improvement." For long-running work: daemon-backed continuity (sessions survive terminal disconnects), persistent goals tracked across turns, heartbeats for periodic re-entry, schedules, and a bounded autonomous mode with configurable token/time budgets. Architecturally: a daemon, worker and kernel with persistent state boundaries.
- **Why it matters**: A structurally different answer to "what should a coding agent look like" — instead of stacking tool calls onto a chat loop, it models the entire agent runtime as a persistent programming environment, where the agent's "thinking" is literally writing code and reading/writing variables inside that environment. The `/refine` self-improvement mechanism — "review the trajectory, then update the harness's own state" — is the same underlying idea as loopx's external state kernel and the experience-distillation in Matt Pocock's skills, expressed at a different layer: prime-agent builds this loop as the agent's own built-in capability rather than an external tool.

## Google Officially Releases skills: An Agent Skill Collection for Google's Product Line

- **Summary**: google/skills (+327 stars in a day, 16.2k total) — an official Google repository providing Agent Skills across its own products and technologies: cloud infrastructure (GKE, storage, networking), AI/ML (Agent Platform management, Gemini APIs, model tuning and deployment), data & analytics (BigQuery, AlloyDB, Spanner, Bigtable), developer tools (gcloud CLI, Firebase), security (GKE security, detection engineering), Well-Architected Framework best practices across its six pillars, advertising (Google Ads API, Mobile Ads SDK), and Cloud Run/Logging/Monitoring.
- **Why it matters**: Following two independent engineers' high-star skill packs, the first hyperscaler to officially maintain a skill collection for its own product line — a sign that "a skill is an executable version of product documentation" is being formally adopted by platform vendors: rather than waiting for the community to write skills for GKE or BigQuery, the vendor maintains an authoritative version itself, with the natural credibility edge of staying in sync with official docs. For teams on the GCP stack, this is currently the broadest official Google Cloud skill source available.
