# 2026-07-22

## OpenAI Launches Presence: An Enterprise Voice/Chat Agent Platform

- **Summary**: OpenAI introduced Presence, which helps enterprises deploy real-time voice and chat agents that can query company systems, take approved actions, and escalate to humans when needed — targeting customer support, sales development, procurement, IT and HR. It's in limited GA, with deployments led by OpenAI Forward Deployed Engineers and systems integrators; no self-service.
- **Why it matters**: OpenAI is now formally in the enterprise agent delivery business (not just selling APIs). The "platform + embedded engineers" model is both direct competition and a reference point for developers and vendors doing enterprise agent integration; OpenAI says ~75% of its own inbound support requests are already handled by the system.
- **Category**: Agent
- **Related Topic**: [enterprise-ai-agents](/en/topics/enterprise-ai-agents)
- **Source**: https://openai.com/index/introducing-openai-presence/

## A Batch of Claude Managed Agents API Updates

- **Summary**: Managed Agents now supports setting an effort level in an agent's model configuration; webhooks cover the environment and memory store lifecycle (7 new event types); sessions can be created with `initial_events` to seed and start the agent loop in one call; the `version` field is now optional when updating an agent (optimistic concurrency); thread-level event streams support event deltas for previewing subagent generation.
- **Why it matters**: These updates all point at operational maturity for hosted agents — lifecycle events without polling, one-call session bootstrap, fine-grained stream observation. Concrete signals for evaluating managed agent runtimes.
- **Category**: Agent
- **Related Topic**: [enterprise-ai-agents](/en/topics/enterprise-ai-agents) ・ [claude-models](/en/topics/claude-models)
- **Source**: https://platform.claude.com/docs/en/release-notes/overview
