# 2026-07-24

## Anthropic Releases Claude Opus 5

- **Summary**: Claude Opus 5 (`claude-opus-5`) launched as a step-change improvement over Opus 4.8: 1M-token context window (default and maximum), 128k max output, thinking on by default, at $5/$25 per MTok — same pricing as Opus 4.8 — available on the Claude API, Bedrock, Vertex AI and Microsoft Foundry.
- **Why it matters**: The flagship tier now defaults to a 1M context at no price increase — a direct win for long documents, large codebases and long-horizon agents. Note one breaking change: disabling thinking at effort `xhigh`/`max` returns a 400 (Opus 4.8 allowed it); effort (`low`–`max`, five levels) is now the primary steering control, so audit existing calls when migrating.
- **Category**: Models
- **Related Topic**: [claude-models](/en/topics/claude-models)
- **Source**: https://www.anthropic.com/news ・ https://platform.claude.com/docs/en/release-notes/overview

## Same-Day Claude API Updates: Mid-Conversation Tool Changes (Beta), Server-Side Fallback Default Mode

- **Summary**: Mid-conversation tool changes entered beta (add/remove tools between turns while preserving the prompt cache on Fable 5 / Mythos 5 / Opus 4.8 / Opus 5, beta header required); the `fallbacks` parameter gained a `"default"` mode applying Anthropic's recommended fallback models by refusal category; fast mode was removed for Opus 4.7 — migrate to Opus 5 or 4.8 to keep using it.
- **Why it matters**: Dynamically adjusting the tool set mid-conversation without busting the cache resolves the "fixed tools vs. cache invalidation" dilemma for long-running agents; the fast mode removal is a real migration work item.
