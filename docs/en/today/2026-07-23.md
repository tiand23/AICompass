## LangChain Publishes Its Deep Agents Benchmarking Methodology

- **Summary**: LangChain published "How We Benchmark Deep Agents", describing its methodology for evaluating the performance of Deep Agents (long-horizon, multi-step autonomous agents).
- **Why it matters**: Evaluating long-horizon agents is a recognized hard problem — single-turn benchmarks can't capture planning, tool use and error recovery. A leading framework vendor publishing its evaluation methodology is directly useful to teams building their own agent evals.

## Nunchaku 4-bit Diffusion Inference Lands in Diffusers

- **Summary**: HuggingFace announced the integration of Nunchaku's 4-bit quantized inference into the Diffusers library for efficient image generation.
- **Why it matters**: Native 4-bit diffusion inference in a mainstream library lowers the VRAM and cost barrier for image generation, making large diffusion models more viable on consumer GPUs.
