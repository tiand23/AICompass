# 2026-09-22

## Claude Opus 5.5 launches: built for long-horizon coding and knowledge work, adaptive thinking always on

- **Summary**: Anthropic launches Claude Opus 5.5, aimed at long-horizon agentic coding and knowledge work: a default-and-maximum 1M-token context window, 128K max output tokens, adaptive thinking always on (`thinking: disabled` now returns a 400 error); priced at $4/$20 per million tokens; available simultaneously via the Claude API, Amazon Bedrock, Claude Platform on AWS/Google Cloud, and Microsoft Foundry. Breaking API changes: the `tool_choice` types `any`/`tool` (forced tool calling) now return 400; the computer-use tool requires the upgraded `computer_toolset_20260801` (the older `computer_20251124` is no longer accepted). The same day brings Fast Mode as a research preview (Opus 5.5 only) and Inline Tools in beta (tools can now be defined mid-conversation in a system message).
- **Why it matters**: This is Anthropic's second model-line update this month, after Fable 5.1/Mythos 5.1 on 09-01 — and it's a generational refresh of the Opus tier itself (following Opus 5 in July). Making adaptive thinking mandatory and dropping manual forced-tool-calling continues the product philosophy of "replace manual prompt tuning with effort/thinking mechanisms," but it also means integrations relying on the old `tool_choice` or the legacy computer-use tool version need rework.

## GPT-6 Astra/Sol/Luna and Claude Opus 5.5 arrive on Microsoft Foundry the same day

- **Summary**: Microsoft Foundry adds two model lines on the same day — the full GPT-6 Astra/Sol/Luna lineup (OpenAI) for production agent scenarios, and the just-launched Claude Opus 5.5 for long-horizon coding and knowledge work — both folded into Foundry's unified model evaluation/deployment/governance control plane.
- **Why it matters**: This continues the "platform before model" and "multi-vendor model marketplace" strategy (following the earlier limited rollouts of Grok 4.6 and GPT-6 Astra), but this time a brand-new model line reaches Foundry the same day it launches — the lag between a model vendor's release cadence and a cloud vendor's listing cadence is shrinking. Having Claude Opus 5.5 and the GPT-6 family side by side for direct comparison further cements "enterprises already committed to a cloud can evaluate more frontier models without switching vendor contracts" (see [claude-models](/en/topics/claude-models) ・ [openai-models](/en/topics/openai-models)).
