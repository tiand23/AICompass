- **Summary**: Azure publishes a full infrastructure-stack disclosure — the custom inference chip Maia 300 delivers 40% more tokens per watt versus leading GPU systems and 7x the rack-scale throughput of Maia 200; the Cobalt 200 CPU improves performance 50%+ over Cobalt 100 and cuts agent latency 33%; on the networking side, Multipath Reliable Connection (MRC) uses a two-tier architecture scaling beyond 100,000 GPUs, and the Optical Compute Interconnect Multi-Source Agreement (OCI MSA) is released as an open spec; on power, an industry shift to 800V DC and the Mt. Following 10-12's Maia 300 architecture deep-dive, this is a broader version of the same disclosure wave, reinforcing that the competitive narrative around custom silicon keeps sharpening toward serving agent workloads specifically.

## LangSmith launches AI Search: find agent execution traces by describing behavior in natural language

- **Summary**: LangSmith adds AI Search in public beta (free on LangSmith Cloud in GCP's US, EU, and APAC regions) — instead of keyword search, you describe the behavior you're looking for in plain language and a fast decision model reads traces and returns the ones where it happened, e.g. "did the user get frustrated," "did PII leak," or "did the agent claim it finished a task but didn't." Technically, it uses trajectories to normalize traces, reducing context bloat and speeding up queries.
- **Why it matters**: This extends the trend (following Jev on 09-21 and OpenAI's Decisions API on 10-06) of splitting "decision/judgment" tasks off into dedicated models, landing this time on "searching massive production traces by behavioral semantics" — a concrete observability capability upgrading from "keyword event search" to "semantic behavior search" for teams running agents at scale (see [agent-evaluation](/en/topics/agent-evaluation)).

## LangChain launches ScaleDown integration with Deep Agents: specialized small models take over long-session context management

- **Summary**: LangChain publishes an integration of ScaleDown's "constrained decoding models" (CDMs) with Deep Agents — addressing the long-horizon agent context-management problem (deciding what to keep, summarize, or compress as history grows is slow and expensive when done with a frontier LLM) by replacing frontier models with narrow, specialized ones: `ScaledownSummarizationMiddleware` replaces Deep Agents' built-in summarization middleware to condense older history (41x cheaper than GPT-class models); a tool-result compression middleware extracts relevant portions from large tool outputs before the agent sees them (roughly 90% context reduction in demonstrated traces); an extraction mode pulls structured values (order IDs, emails) via exact copying rather than paraphrasing; a classification mode labels text against defined categories with confidence and reasoning, useful for detecting agent drift or routing. ScaleDown says these narrow-task models run 200x faster and 467x cheaper than frontier models on these tasks.
- **Why it matters**: A concrete specialization of the "vertical scenarios don't need frontier intelligence" efficiency philosophy, applied to the specific sub-problem of long-session context management — pulling structural, high-frequency, low-creativity decisions (summarize/compress/extract/classify) out of the main model loop is a directly implementable pattern for cutting long-horizon agent operating cost (see [deep-agents](/en/topics/deep-agents) ・ [model-efficiency](/en/topics/model-efficiency)).
- **Category**: Agent
- **Related Topic**: [deep-agents](/en/topics/deep-agents)・[model-efficiency](/en/topics/model-efficiency)
- **Source**: https://www.langchain.com/blog/building-long-running-agents-with-scaledown-and-deep-agents
