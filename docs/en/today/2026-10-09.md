## Claude Managed Agents previews Dynamic Workflows: agents write their own multi-stage, multi-agent workflow programs

- **Summary**: Claude Managed Agents adds Dynamic Workflows (beta, requires the `managed-agents-2026-04-01` beta header) — for tasks involving many similar items (reviewing hundreds of documents, say), the agent itself can write a "workflow program": scheduling multiple agents across phases, running them in parallel, and merging each phase's results; the workflow executes server-side as a background workflow run, tracked through the session's `workflow_run.*` event stream. Enabled by setting the `multiagent` field to `{"type": "multiagent_20261001", "workflows": {"type": "enabled"}}`, with the system prompt telling the agent when to kick off a run.
- **Why it matters**: This is a step in Managed Agents' evolution from "a single agent plus tools" toward "an agent that generates and hosts the execution of its own multi-agent orchestration program" — turning "write a program that runs several subagents" from something a developer hand-builds (explicit orchestration, LangGraph-style) into a native capability of the hosted agent runtime, echoing the "layered architecture" trend in long-horizon agents (open-source harness vs. hosted runtime), but this time delegating the generation of the orchestration logic itself to the agent.

## GitHub Trending: MCP reverse-engineering tool rea surges 54,706 stars in a day; Vercel ships a cross-platform skill package manager

- **Summary**: `morluto/rea` (an MCP server + CLI) gains 54,706 stars in a single day, 186K total, topping today's Trending — it wires professional reverse-engineering tools like Ghidra and IDA Pro behind an agent, analyzing native binaries, Electron apps, .NET assemblies, APKs, and websites, explaining how a feature works without source code and backing the explanation with an evidence chain, confidence scores, and recreation steps; compatible with Claude Code, Codex, Cursor, Gemini CLI, and other mainstream coding agents. The same day, Vercel ships `vercel-labs/skills` (`npx skills`) — an open skill package manager independent of any single vendor: `skills add/use/list/update` and other commands, supporting Claude Code, OpenCode, Codex, Cursor, and 75+ other agents, with the official v1.1.1 release adding interactive skill discovery (`npx skills find`).
- **Why it matters**: rea turns reverse engineering — a field long dependent on specialist expertise — into a delegable task for a general-purpose coding agent via MCP (continuing the thread of reverse-engineering skill packs like reverse-skill, but this time wiring up the professional toolchain directly rather than packaging expertise into instructions); Vercel's `npx skills` is the first general-purpose skill install/management tool decoupled from any specific agent vendor — much like npm is to JS packages — a signal that the skill ecosystem is moving from "everyone maintains their own repo, users figure out installation on their own" toward a unified package manager (see [agent-skills](/en/topics/agent-skills)).
