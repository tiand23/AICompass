## LlamaIndex Argues: Document OCR Is Not Getting Commoditized

- **Summary**: LlamaIndex's "Document OCR is Not Getting Commoditized": ParseBench data shows specialized parsing engines still lead GPT-5.5 by ~20 points at lower cost; frontier models score only ~8% on visual/spatial grounding versus 55-80% for specialized engines; and labs' post-training compute goes to math/coding/agents, not document reading (the GPT-5 system card and Gemini 3 launch notes mention no document-parsing improvements).
- **Why it matters**: A direct answer to the common selection assumption "once frontier models get stronger we won't need specialized parsers" — the spatial-grounding gap is structural: agents need to know which page and location data came from, and evidence chains depend on it. Four "distillation strategies" (complexity-based routing, specialized RL post-training, native file metadata like PDF text layers/OOXML, closed-loop evaluation) make the advantage durable. Caveat: ParseBench is LlamaIndex's own benchmark — a positioned argument, but the structural evidence belongs in long-term selection judgment.

## Uber Open-Sources ADR: Enterprise Detection & Response for AI Agents

- **Summary**: Uber open-sourced ADR (Agentic AI Detection and Response), an agent security system deployed in Uber's production environment: a Sensor captures intent, tool use and execution traces of 7+ coding agents (Claude Code/Cursor/Codex, etc.) on macOS/Linux/Windows; ADR-Bench builds a security benchmark from 300+ tasks and 133 MCP servers; detection uses a two-tier architecture (high-recall triage + deep agentic reasoning on suspicious sessions); the prevention module is not open-sourced. The paper is accepted at MLSys 2026.
- **Why it matters**: The "EDR for Agents" category has arrived — porting endpoint security's detect-and-respond paradigm to agent behavior, and coming from a major company's production practice rather than a security vendor's concept deck. ADR-Bench is also the first benchmark to systematically test MCP servers as an attack surface. The agent-security toolchain now has all three pieces: governance (agent-governance-toolkit), evaluation transparency (Anthropic red-team post-mortems), and runtime detection (ADR).
- **Category**: Other
- **Related Topic**: [agentic-safety](/en/topics/agentic-safety)
- **Source**: https://github.com/uber/ADR
