## LangChain Ships ReviewBench: Evaluating Code Review Agents Against Real PR Feedback

- **Summary**: ReviewBench hand-curates substantive findings from real PR review comments in the LangSmith codebase into 59 Harbor-format tasks, uses an LLM-as-judge to compare agent submissions against the human baseline, and scores coverage + precision (F1).
- **Why it matters**: Current models recover only ~30% of the human baseline issues with basic prompting — code review agents are far from saturated. Yet the same model scores markedly higher with a structured review prompt emphasizing systematic analysis: review strategy itself is an optimizable variable — no need to wait for a stronger model.
- **Category**: Evaluation
- **Related Topic**: [ai-code-review](/en/topics/ai-code-review) ・ [agent-evaluation](/en/topics/agent-evaluation)
- **Source**: https://www.langchain.com/blog/evaluating-code-review-agents-with-reviewbench

## OpenAI Adds SynthID Watermarking to GPT-Live Audio and Opens a Verification API

- **Summary**: Supported audio generated with GPT-Live (ChatGPT Voice and the API) now embeds SynthID watermarks; OpenAI's public verification tool detects provenance signals in audio (C2PA metadata + SynthID), and a new verification API lets third parties wire provenance checks into their own workflows.
- **Why it matters**: OpenAI adopting Google's SynthID rather than rolling its own means AI content watermarking is converging on a cross-vendor de facto standard; the verification API turns "is this AI-generated?" into a programmable capability — content platforms and enterprise compliance pipelines can integrate it directly, giving voice-deepfake detection its first official-grade interface.
