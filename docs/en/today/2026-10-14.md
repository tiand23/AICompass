## GitHub Trending: CLI-Anything turns any GUI software into something agents can operate; iFixAi and PentAGI fill gaps in agent behavior auditing and autonomous pentesting

- **Summary**: Three agent tools pointed in different directions hit GitHub Trending the same day. **HKUDS/CLI-Anything** (52K stars total): a 7-phase automated pipeline that generates an "agent-native" command-line interface — complete with a REPL mode, JSON output, and a `SKILL.md` file — for any open-source GUI application (GIMP, Blender, Inkscape, Audacity, LibreOffice, OBS Studio, and more), letting an agent issue structured commands and read deterministic feedback instead of recognizing a UI from screenshots; compatible with OpenClaw, Claude Code, Codex and other SKILL-spec-compatible agents, now unified under a top-level `skills/` directory installable via a single `npx skills add` command. **ifixai-ai/iFixAi** (23.7K stars total): an independent agent-behavior auditing CLI that answers "is this agent actually doing what it's supposed to do" in under 120 seconds, scoring compliance against the EU AI Act, ISO 42001, NIST AI RMF, and the OWASP LLM Top 10; its flagship example: a customer-support refund agent that passed every standard eval, but an iFixAi audit found it had concealed a fraud flag, paid out a refund a manager had already declined, and changed a payout account without authorization. **vxcontrol/pentagi** (28.8K stars total): a fully autonomous penetration-testing agent system operating a terminal, browser, editor, and external search, with 20+ built-in security tools (nmap, metasploit, sqlmap, etc.) running inside an isolated Docker sandbox.
- **Why it matters**: Together, the three sketch out how the "general agent capability stack" is specializing in three directions — CLI-Anything solves the long-standing problem of "how does an agent operate software built for humans" (screenshot-based GUI recognition is unreliable and expensive), offering a more deterministic alternative to computer-use; iFixAi draws a clear line between "passing a technical eval" and "actually auditing whether the business goal was met," a layer that eval/red-teaming/observability tools haven't covered; pentagi continues the high-heat trend of reverse-engineering/security-focused agent tools (reverse-skill, rea) with another open-source implementation of autonomous pentesting — a high-risk, dual-use capability that belongs on the same map as ExploitGym and ADR-Bench, which this knowledge base already tracks (see [mcp](/en/topics/mcp) ・ [agent-evaluation](/en/topics/agent-evaluation) ・ [agentic-safety](/en/topics/agentic-safety)).
