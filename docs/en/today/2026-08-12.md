## OpenMontage Open-Sources: Turning an AI Coding Assistant Into a Full Video Production Studio

- **Summary**: calesthio/OpenMontage (+458 in a day, 47.3k stars total, AGPLv3) — billed as "the world's first open-source agentic video production system," it turns AI coding assistants themselves (Claude Code, Cursor, Copilot, Windsurf) into the orchestrator of an entire video production studio, with no separate code-execution layer — the agent directly reads YAML pipeline manifests, calls 100+ Python tools, and checkpoints state as JSON. Its three-layer knowledge model: tools + pipeline definitions, Markdown "skills" that teach the agent production conventions, and external technology documentation knowledge packs. Twelve structured production pipelines (animated explainers, avatar spokesperson, documentary montage, podcast repurposing, localization/dubbing, and more) all follow the standard research→proposal→script→scene-plan→assets→edit→compose stages, with mandatory human approval gates at every key node. It supports 15 video-generation, 11 image-generation, and multiple TTS/music providers, and can assemble finished videos entirely from free sources like Archive.org, NASA, and Wikimedia Commons without relying on paid generative APIs.
- **Why it matters**: A complete landing example of the "AI coding assistant = general-purpose task orchestrator, not just a code writer" trend, applied to a specific vertical: video production. Its 700+ skill/production-knowledge files package professional expertise — "what makes a competent explainer video or documentary cut" — into a knowledge layer an agent can load, another instance of the skills ecosystem expanding from "general engineering discipline" into "full-pipeline domain expertise." Its governance design — mandatory human approval at every key node, decision audit trails, budget controls — is also a concrete engineering implementation of "autonomous execution with retained human checkpoints" for long-horizon, multi-stage agent tasks, consistent with the long-horizon agent governance theme this knowledge base has tracked.
