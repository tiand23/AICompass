# 2026-10-03

## Microsoft × Hugging Face launch ThinkingBox: grading enterprise workflow agents on database end-state, not self-reported completion

- **Summary**: Microsoft and Hugging Face jointly publish ThinkingBox — instead of trusting an agent's final response or its record of tool calls, it directly inspects the end-state and side effects the agent left in a database; it covers 507 stateful enterprise business workflows run across 18 LLMs, with each workflow repeated 20 times per model, built on the core argument that both "the final response" and "a valid tool call" are only proxies — an agent can sound correct while writing the wrong value, changing the wrong record, or creating an extra side effect, and only the records it leaves behind settle whether it actually succeeded.
- **Why it matters**: Following 09-29's ProvenanceGuard (checking whether a citation's source is correct), this is another instance of agent evaluation systematizing "don't just trust what the agent says about itself" into a reproducible methodology — this time shifting the object of verification from "source attribution" to "actual system-state change," and its 20-repeats-per-task design quantifies a dimension rarely measured on its own: whether an agent can succeed reliably, not just get lucky once.
