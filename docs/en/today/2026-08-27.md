## Anthropic Previews the Model Hardware Standard: A Shared Spec for Agents to Safely Operate Physical Lab/Manufacturing Equipment

- **Summary**: Anthropic opened a research preview of the Model Hardware Standard (MHS) to a first group of scientific research labs and advanced manufacturers — a shared specification letting AI agents operate multiple lab and manufacturing instruments (microscopes, liquid handlers, robotic arms) in parallel, spanning tasks from routine drug-discovery experiments to laser calibration on a quantum computer. The pain point it addresses: devices typically don't talk to each other, and labs/factories usually need weeks to months of specialist work to build bespoke integrations; MHS compresses that integration work to hours or minutes. MHS is model-agnostic, works with any device with a programmable interface, and any agent harness can access it via standard protocols like the Model Context Protocol. Developed in collaboration with HHMI Janelia Research Campus, it's currently research-preview only, with plans to open-source it later.
- **Why it matters**: This is the first time this knowledge base has recorded "agents safely operating physical-world hardware" being systematically standardized — prior agentic-safety discussion has centered on the digital world (sandbox escape, tool misuse); MHS is the first systematic transplant of "what permissions an agent gets, how approval works, how isolation works" into lab/manufacturing equipment scenarios where mistakes have real physical consequences. Accessing it via an existing protocol (MCP) also signals that the protocol layer didn't need reinventing — what's new is the device-integration and safe-operation spec itself (see [agentic-safety](/en/topics/agentic-safety)).

## Anthropic Expands Support for Scientists: 10,000 Free/Discounted Claude Seats, Government Partnership Opens Mythos-Class Models to Life Sciences Researchers

- **Summary**: Anthropic announced 10,000 free and discounted Claude Team seats for scientists — standard seats are free, premium seats with 5x usage limits cost $15/month with pricing locked for a year, and the program is planned to expand well beyond 10,000 seats in coming months. The expansion builds on Claude Science (launched 06-30, an AI workbench pre-configured with 60+ skills and connectors for genomics, single-cell analysis, proteomics, structural biology and cheminformatics), and extends the previously biology-only AI for Science credit program to a broader range of fields. Anthropic is also partnering with the US government to establish an access program letting life-sciences professionals use its Mythos-class models for life-sciences R&D, with the first participants already enrolled.
- **Why it matters**: Another substantial expansion of the Claude Science product line (launched 06-30, with Compliance API coverage just extended to it on 08-26) — opening both a "free/discounted access" path and a "government-partnered Mythos-class model access" path simultaneously suggests scientific research is becoming a second major product focus for Anthropic alongside enterprise agents (see [claude-models](/en/topics/claude-models)).

## OpenAI Tests a Codex "Persistent Mode": An Agent That Keeps Working Across Sessions and Creates Its Own Follow-Up Tasks (backfilled)

- **Summary**: WIRED found an unreleased "Persistent mode" setting in the public Codex CLI codebase — it appears in Codex's reasoning-effort menu and lets an agent use far more compute, tokens and time than existing modes, which force-stop after minutes to hours. A companion proactivity feature lets the agent create its own follow-up tasks after finishing a request and continue them across sessions, using past interactions and "knowledge of the user" to decide what to work on next, occasionally messaging the user first. An OpenAI spokesperson confirmed the company is testing it, but stressed there are "no immediate plans to launch"; OpenAI also acknowledged persistent AI systems carry heightened risk.
- **Why it matters**: This is the first concrete signal on OpenAI's side of a thread this knowledge base has tracked continuously — agents persisting and self-coordinating across sessions (Claude Code's 08-07 cross-session messaging, loopx's external state kernel, prime-agent's built-in self-improvement). Multiple vendors exploring "letting an agent break out of a single session's boundary and decide its own next move" at roughly the same time suggests this isn't one company's isolated experiment but a shared direction for the coding-agent category. That this was only discovered in code rather than officially announced is also a reason to treat its maturity and launch timeline cautiously (see [coding-agents](/en/topics/coding-agents)).
