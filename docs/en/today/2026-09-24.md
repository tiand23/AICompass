# 2026-09-24

## Microsoft Foundry adds voice agents in preview, expanded model choice, and continuous optimization

- **Summary**: Microsoft Foundry ships three updates: voice agents in public preview (sub-second latency, 80+ languages/140+ locales, deployable to web, Teams, Teams Phone, and Twilio, supporting both prompt-based and hosted agent forms, with speech-to-text/text-to-speech model choice spanning OpenAI, Microsoft, and others); expanded model choice (adding new GPT-6-series SKUs and Claude Opus 5.5); and continuous optimization (using production trace data to keep tuning an agent's instructions, skills, tools, and model choice against quality, latency, and cost).
- **Why it matters**: Voice agents fill the last piece of Foundry's puzzle to compete with Google Gemini Live (see [voice-agents](/en/topics/voice-agents)), while "continuously optimize from production traces" echoes LangSmith Engine's auto-diagnosis-and-fix approach — the two major platforms are converging on the same methodology of using real runtime data to drive continuous agent iteration.
- **Category**: Agent
- **Related Topic**: [cloud-agent-platforms](/en/topics/cloud-agent-platforms)
- **Source**: https://azure.microsoft.com/en-us/blog/ship-agents-faster-with-expanded-model-choice-voice-agents-and-continuous-optimization/

## LangChain ships a LangSmith platform update wave: Engine v2, Managed Deep Agents v0.8, Trajectories, Fine-Tuning, Custom Apps

- **Summary**: LangChain ships five LangSmith updates at once — **Engine v2**: adds red-teaming and automated testing to Engine (the built-in Deep Agent that auto-scans production traces to diagnose agent failures, last upgraded 08-25); **Managed Deep Agents v0.8**: adds authentication, memory management, and messaging channels — another hosted-runtime capability expansion right on the heels of 09-09's Connections; **Trajectories**: a new "readable" view of an agent session's entire run inside LangSmith; **LangSmith Fine-Tuning**: built-in fine-tuning capability; **LangSmith Custom Apps**: the ability to build custom interfaces around agent data.
- **Why it matters**: This is a bundled "platform capability release week" spanning observability (Trajectories), security testing (Engine v2 red-teaming), hosted runtime (Managed Deep Agents v0.8), model customization (Fine-Tuning), and the interface layer (Custom Apps) — five previously separately-evolving directions — signaling LangSmith is converging from "a collection of tools" toward "an integrated agent production platform." Notably, Managed Deep Agents' new auth capability lands right after Connections (09-09), with the hosted credential/identity thread iterating twice within two weeks.
- **Category**: Agent

- **Source**: https://www.langchain.com/blog/new-in-langsmith-engine-v2-managed-deep-agents-fine-tuning-and-more
