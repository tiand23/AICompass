## Prime Intellect 发布 prime-agent：把上下文当变量、工具当函数调用的"RLM" Agent

- **一句话总结**：Prime Intellect 开源 prime-agent（单日 +2,293，累计 6.5k star）——面向编码与长时程自主任务的开源 Agent，核心是 RLM（Recursive Language Model，递归语言模型）思路：在持久化的 Python REPL（IPython 为内置模型工具）里，把上下文当变量、把工具当可编程函数调用（含 `rlm(...)` 用于派生并行子 Agent），而非常规的对话式工具调用。自带`/refine`能力——复盘任务轨迹，把有据可查的经验更新写回辅助 harness 状态（记忆、skills、子 Agent 规格），跨会话持久化，即"自我改进"。长任务侧配 daemon 常驻（终端断开会话不丢）、跨轮持久目标、心跳定期唤醒、定时任务、可配置 token/时间预算的有界自主模式。架构上是 daemon + worker + kernel 三层带持久状态边界。
- **为什么重要**：这是"编码 Agent 该长什么样"的一个结构性不同答案——不是在聊天循环上堆工具调用，而是把整个 Agent 运行时建模成一个持久化编程环境，Agent 的"思考"直接是在这个环境里写代码、读写变量。`/refine` 这类"复盘轨迹→更新 harness 自身状态"的自我改进机制，和 loopx 的外部状态内核、Matt Pocock skills 里的经验萃取是同一条"让 Agent 的运行留下可复用沉淀"的思路在不同层面的体现——只不过 prime-agent 把这个循环做成了 Agent 自己的内置能力，而非外部工具。
- **分类**：Agent

- **来源**：https://github.com/PrimeIntellect-ai/prime-agent
