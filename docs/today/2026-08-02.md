# 2026-08-02

## OpenAI 开始推送 "Sign in with ChatGPT"

- **一句话总结**：OpenAI 面向部分插件与合作站点 beta 推出 "Sign in with ChatGPT"——首批覆盖 Airtable、GitLab、HubSpot、Notion、Supabase、Vercel，用 ChatGPT 账号少步骤创建/关联合作方账号，随后可直接在 ChatGPT 或 Codex 中使用该服务；合作方仅获得姓名、邮箱、头像，插件的数据访问权限仍需单独审查授权。
- **为什么重要**：这是把 ChatGPT 做成身份层的一步——"Sign in with Google" 的 AI 时代翻版。对开发者是两面的：接入方获得低摩擦的获客与账号打通入口；同时 OpenAI 在 Agent 工作流上游又多了一个锁定点（账号体系），平台依赖评估时需要把身份层也算进去。
