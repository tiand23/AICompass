# 2026-07-24

## Anthropic 发布 Claude Opus 5

- **一句话总结**：Claude Opus 5（`claude-opus-5`）发布，相对 Opus 4.8 跨代提升：1M token 上下文（默认即最大）、128k 最大输出、thinking 默认开启，定价 $5/$25 每百万 token 与 Opus 4.8 持平，同步上线 Claude API、Bedrock、Vertex AI 与 Microsoft Foundry。
- **为什么重要**：旗舰档在不涨价的前提下把上下文默认拉到 1M，对长文档、大代码库和长时程 Agent 场景是直接利好。注意一个破坏性变更：effort 为 `xhigh`/`max` 时禁用 thinking 会返回 400（Opus 4.8 允许）；effort（`low`~`max` 五档）成为该模型的主要调控手段，迁移时需检查现有调用。
- **分类**：Models
- **关联 Topic**：[claude-models](/topics/claude-models)
- **来源**：https://www.anthropic.com/news ・ https://platform.claude.com/docs/en/release-notes/overview

## Claude API 同日更新：会话中途换工具（beta）、服务端 fallback 默认模式

- **一句话总结**：Mid-conversation tool changes 进入 beta（Fable 5 / Mythos 5 / Opus 4.8 / Opus 5 上可在多轮间增删工具且保留 prompt cache，需 beta header）；`fallbacks` 参数新增 `"default"` 模式按拒答类别应用官方推荐的兜底模型；Opus 4.7 的 fast mode 移除，继续用需迁移到 Opus 5 或 4.8。
- **为什么重要**：多轮间动态调整工具集而不打穿缓存，解决了长会话 Agent "工具集固定"与"缓存失效"二选一的痛点；fast mode 移除是实际的迁移工作项。
- **分类**：Agent
- **关联 Topic**：[claude-models](/topics/claude-models)
- **来源**：https://platform.claude.com/docs/en/release-notes/overview
