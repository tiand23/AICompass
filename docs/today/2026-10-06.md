# 2026-10-06

## Anthropic 扩展 Cyber Verification Program：三级访问分层开放网络安全能力

- **一句话总结**：Anthropic 把此前的 Project Glasswing 与 Cyber Verification Program 合并为统一的扩展版计划，向通过审核的网络安全专业人员开放三档访问级别——Defense Access、Red Team Access、Specialized Access，各档均可用 Claude Opus 5.5、Sonnet 5.5、Mythos 5.1 及未来新模型，且护栏分类器随访问级别放宽；官方披露 Glasswing 合作方在 2026 年 4-7 月间已核实识别 12.9 万个漏洞，开源扫描在 4-10 月间又识别 5500 个漏洞，其中超过 3.3 万个被归类为严重或高危。
- **为什么重要**：这是继 OpenAI Daybreak Blue/Red 两档分级准入（08-10）之后，"能力越强、审核越严"分层准入模式在 Anthropic 一侧的进一步细化（从两档到三档），并首次给出大规模真实防御效果的量化数字（12.9 万+5500 个漏洞）作为"放宽护栏换防御效果"这一权衡的实证支撑。
- **分类**：其他
- **关联Topic**：[agentic-safety](/topics/agentic-safety)
- **来源**：https://www.helpnetsecurity.com/2026/10/07/anthropic-expands-cyber-verification-program/

## OpenAI Decisions API 开放公测：GPT-6 Luna 驱动的结构化决策端点，仅按输入计费

- **一句话总结**：OpenAI 把 09-29 DevDay 限量预览的 Decisions API 开放给所有开发者公测——该端点让 GPT-6 Luna 专注于开发者预定义的一组问题与有限候选答案，输入文本或图片即返回可直接用于内容分类/请求路由/决定 Agent 下一步动作的结构化答案；官方称比走 Responses API 直接调用 Luna 快至多 10 倍；计费只针对输入 token（$0.10/百万），缓存读写与输出 token 均不计费，正式 GA 预计未来几周内到来。
- **为什么重要**：与 09-21 LangChain 发布的 Jev（专用结构化判定模型）、10-07 LiquidAI 发布的 d1（专精决策的端侧模型）共同构成一条清晰的新趋势——"决策/判定"正在从"调用通用对话模型拿到文本答案再解析"分化成独立的模型品类，三家不同背景的厂商（框架方、模型方、端侧方）在一个月内分别推出了结构一致的解法：窄定义问题 + 类型化输出 + 远低于通用调用的成本（详见 [agent-evaluation](/topics/agent-evaluation)）。
- **分类**：Models
- **关联Topic**：[openai-models](/topics/openai-models)・[agent-evaluation](/topics/agent-evaluation)
- **来源**：https://www.unite.ai/openai-releases-decisions-api-in-public-beta-powered-by-gpt-6-luna/

## Google 同日发布 Gemini Nano Banana 2.1、Gemini Enterprise Antigravity 管理控制、EmbeddingGemma 2

- **一句话总结**：Google 一天内发布三项更新——**Gemini Nano Banana 2.1**：保持 Flash 级速度与成本的图像生成/对话式编辑模型，视觉质量、prompt 遵循度、多轮角色一致性、文字渲染、宽幅/全景画幅生成均有提升；**Gemini Enterprise Antigravity 管理控制**：企业管理员可集中管控 Antigravity 的 Boost（分层多 Agent 架构，解决复杂算法/深度调试任务，已 GA）与 Teamwork（协调自主子 Agent 执行大规模长时程项目，预览阶段）两项功能的可用范围；**EmbeddingGemma 2**：7.4 亿参数的开放多模态端侧嵌入模型（Apache 2.0），基于 Gemma 4，用 2.7 亿参数文本/代码主干 + 1.7 亿视觉编码器 + 3 亿音频编码器把文本/代码/图像/音频/视频统一映射进同一向量空间，量化后完整版在 Pixel 11 Pro 上仅占约 567MB 内存（纯文本部分 191MB），上下文窗口 8192 token（前代的 4 倍），在 MTEB Code、MAEB 等基准上领先 10 亿参数以下的多模态嵌入模型。
- **为什么重要**：三项更新分别覆盖生成、Agent 平台治理、检索基础设施三条线——EmbeddingGemma 2 尤其值得关注：它把隐私优先、离线可用的多模态语义检索/RAG 能力压进消费级硬件可承受的内存范围，是"端侧小模型覆盖垂直能力"效率路线在嵌入/检索这一 RAG 核心环节的具体样本；Antigravity 管理控制则是 Google 版"给企业 Agent 功能配治理开关"的落地（详见 [rag](/topics/rag) ・ [cloud-agent-platforms](/topics/cloud-agent-platforms) ・ [diffusion-models](/topics/diffusion-models)）。
- **分类**：Models
- **关联Topic**：[rag](/topics/rag)・[cloud-agent-platforms](/topics/cloud-agent-platforms)・[diffusion-models](/topics/diffusion-models)
