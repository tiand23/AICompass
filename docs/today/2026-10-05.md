## LlamaIndex 提出 Agentic OCR 三原则：自适应策略、证据驱动纠错、有界执行

- **一句话总结**：LlamaIndex 发文《OCR is Dead. Long Live Agentic OCR.》，把"Agentic OCR"定义为用 LLM 工具调用循环自适应处理文档（而非单次转换），提出三条设计原则——自适应策略（对表格/图表等复杂元素分配更多处理资源，而非对所有页面元素一视同仁）、证据驱动纠错（一次"纠正"必须有证据证明确实改善了结果，而不是多调一次模型换个答案）、有界执行（明确目标与时间/成本硬上限，产出"够用能用"的结果，拒绝开放式无限打磨）；并主张随着 Agent 承担更多有实际后果的任务，文档处理基础设施的标准要从"机器可读"提高到"忠实还原"——保留版式关系、页眉页脚等上下文元素。
- **为什么重要**：延续 LlamaIndex 一系列文档解析方法论文章（08-05《OCR 不会被前沿模型商品化》、08-12《LLM OCR 错误更难被发现》），这次首次把"Agentic OCR"系统化成三条可操作的设计原则，而不只是现象描述，为评估/选型"是否算得上 Agentic OCR"提供了具体标尺。
