## Firecrawl 开源 pdf-inspector：文档解析的"第一道分诊"组件

- **一句话总结**：pdf-inspector（Rust）单日 +1,699 star（累计 8.2k）——Firecrawl 开源的轻量 PDF 检测库：10-50ms 内把 PDF 分类为文本型/扫描型/图像型/混合型（带置信度，靠采样页面的内容流分析文本/图像算子），免 OCR 做位置感知的文本抽取并转干净 Markdown（含表格检测、多语言编码），支持 WASM 浏览器本地运行，带 Python/Node 绑定。
- **为什么重要**：文档解析管线的"第一道分诊"被做成了专用组件——先毫秒级判断 PDF 类型，再路由到 OCR 或直接文本抽取，与 LlamaIndex Parse Gateway 的页面级路由是同一趋势的不同粒度；WASM 支持意味着分诊可以完全在端侧完成，敏感文档不必出本地。
- **分类**：RAG
- **关联 Topic**：[document-parsing](/topics/document-parsing)

## DeepSeek-Reasonix 登上 Trending：终端编码 Agent 按模型生态分化

- **一句话总结**：DeepSeek-Reasonix（Go）连续两日 Trending（单日 +883，累计 29.9k）——DeepSeek 原生的终端编码 Agent：单一静态 Go 二进制，provider/agent/工具/插件全部在 `reasonix.toml` 里声明的配置驱动架构；围绕 DeepSeek prefix cache 调优上下文管理（保持缓存稳定、修剪过期工具输出）压长会话成本；插件经 stdio JSON-RPC 子进程运行（兼容 MCP），任意 OpenAI 兼容端点可接。
