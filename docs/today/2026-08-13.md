## Google 发布 Gemini 3.7 Flash：距上代仅 3 周，编码/Agent 基准大幅跳升，价格减半

- **一句话总结**：Google 发布 Gemini 3.7 Flash——距 3.6 Flash 发布仅 3 周，定位"面向编码、Web 开发、知识工作与 Agent 工作流的高速主力模型"。编码/Agent 相关基准大幅提升：DeepSWE v1.1 从 49.0% 跳到 65.3%，AutomationBench 从 17.0% 跳到 30.4%，WebDev Arena Elo 从 1538 升到 1588。引入价 API 输入 $0.75/百万 token、输出 $3.75/百万 token，是 3.6 Flash 发布价的一半（标准价 $1.50/$7.50 从 2027-01-01 起生效）。未发布 3.5 Pro。
- **为什么重要**：3 周一次的迭代节奏本身就是信号——Google 在 Flash 档上明确选择了"高频小步提升"而非"憋大招"的打法，这与知识库此前记录的"跳过 3.5 Pro 直推 Flash"策略一脉相承。编码/Agent 类基准的跳升幅度（AutomationBench 近乎翻倍）比通用对话类基准更值得关注，因为这是 Flash 档定位为"Agent 工作流主力模型"的直接能力证据；引入价减半则延续了 Flash 系列"更便宜+更高效"的一贯打法，对成本敏感场景的模型选型再添一个有力候选。

## HuggingFace：2,226 篇 ICML 论文被编码 Agent 复现，51% 至少一条主张验证成功

- **一句话总结**：HuggingFace 公布 2026-07-15~08-02 期间举办的 ICML 2026 可复现性黑客松结果：1,221 名参与者用编码 Agent（Claude Code、Codex、Cursor 等）尝试复现当届 6,352 篇录用论文中的 2,226 篇（占比 34%），流程是从论文摘要提炼核心主张、每人 20 美元算力额度、Agent 自主读论文写代码跑实验、结果发布为可审计的"Trackio logbook"静态页面，再用自动化裁判模型（GLM-5.2）对每条主张判定"已验证/被证伪/仅玩具规模复现/无法判定"。最终产出 6,816 份复现记录、35,908 条主张判定：51% 的被检验论文至少有一条主张被验证，23% 的论文有主张被证伪或存在争议，266 篇论文所有主张全部验证通过。文章总结：Agent 会陷入循环、误读规模依赖型行为等局限依然存在，最可靠的结果来自"人在回路"——人类主导 Agent、做关键判断，而非完全放手。
- **为什么重要**：这是编码 Agent 能力迄今为止最大规模、最贴近真实科研场景的一次实战检验——不是刷基准题，而是让 Agent 独立完成"读论文→写代码→跑实验→验证主张"这一整条科研复现链路，覆盖三分之一的会议论文体量。51%/23%/12%（266/2226）这组数字给"Agent 能不能做科研复现"这个此前只有零星案例的问题提供了首个系统性的量化基线；"最可靠结果来自人在回路"这一结论也呼应了知识库反复出现的"读自主、写（或此处：下结论）必须过人"设计原则——科研复现这个高风险判断场景同样适用。
- **分类**：Agent
