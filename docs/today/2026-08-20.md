# 2026-08-20

## Claude Python SDK 发布 v1.0：httpx 迁移至 httpx2，移除多项长期废弃接口

- **一句话总结**：Anthropic 发布 Claude Python SDK v1.0：HTTP 层从 `httpx` 迁移至自维护的 API 兼容分支 `httpx2`（依赖 tracing/mocking 补丁 httpx 的库需调用 `httpx2.alias_httpx()`）；要求 Python 3.10+；移除 legacy Text Completions API、Messages 方法上的 `temperature`/`top_p`/`top_k`、tool runner 客户端侧 `compaction_control` 等长期废弃接口；异步客户端 `.with_raw_response` 结果需 `await response.parse()`；`AnthropicBedrock` 未配置 region 时直接报错而非默认 `us-east-1`。官方提供完整迁移指南。
- **为什么重要**：典型的"大版本清债"发布——移除项均已废弃多时，跟着最新用法走的用户几乎无感，但停留旧版本、依赖 httpx 补丁或未配置 region 的集成方需按迁移指南逐项排查，属实质性破坏性变更（详见 [claude-models](/topics/claude-models)）。
- **分类**：Agent
- **关联 Topic**：[claude-models](/topics/claude-models)
- **来源**：https://platform.claude.com/docs/en/release-notes/overview

## LangSmith 发布 Preview Builds 公测：PR 自动生成 Agent 预览部署

- **一句话总结**：LangSmith Preview Builds 公测：PR 打开时自动为 Agent 部署创建关联生产环境的隔离预览实例，新提交自动重建并保持同步，为团队（含产品/领域专家/QA 等非工程角色）提供可直接访问测试的"PR 专属产物"；支持"每个 PR"或"仅带标签"触发，预览继承父部署密钥，可配置闲置存活时间与最大并发数；仅限使用 GitHub 集成的 LangSmith Cloud 部署，公测未公布定价。
- **为什么重要**：把 Web 开发里成熟的"CI/CD 预览环境"实践系统性搬进 Agent 部署——此前 Agent 变更要么本地测、要么直接上生产验证，现在有了可协作评审的中间态，也把非工程角色纳入"能直接点开测"的评审范围（详见 [enterprise-ai-agents](/topics/enterprise-ai-agents)）。
- **分类**：Agent
- **关联 Topic**：[enterprise-ai-agents](/topics/enterprise-ai-agents)
- **来源**：https://www.langchain.com/blog/langsmith-preview-builds-test-agent-changes-before-production

## LiquidAI 发布 LFM2.5-DSpark：投机解码草稿模型，端侧/云端推理提速最高 3.18 倍

- **一句话总结**：Liquid AI 发布 LFM2.5-DSpark——面向 LFM2.5 系列（2.6B/1.2B-Instruct/8B-A1B）的投机解码草稿模型（约 3 亿参数），组合 DFlash 式并行主干、轻量顺序头（建模相邻 token 马尔可夫依赖提高接受率）与置信度调度验证器（超成本收益比时剪掉低置信度后缀）。H100 上平均加速 2.1-2.67 倍（MATH500 峰值 3.18 倍），M4 Max MacBook 上端侧加速 1.18-2.54 倍，工具调用延迟平均降 57%；输出与贪心解码基线逐 token 一致，不损失质量；已支持 llama.cpp（Metal 内核）与 SGLang。
- **为什么重要**：与同批 QAD（量化路线，08-19 已收录）互补——一个靠精确量化保精度，一个靠更懂目标模型行为的草稿模型保精度，两条路线合起来覆盖"端侧模型不掉质量还能跑更快"的主要解法（详见 [model-efficiency](/topics/model-efficiency)）。
- **分类**：Models
- **关联 Topic**：[model-efficiency](/topics/model-efficiency)
- **来源**：https://huggingface.co/blog/LiquidAI/lfm25-dspark
