## OpenAI 停运 Atlas 浏览器,把"浏览器 Agent"能力并入 ChatGPT 与 Codex

- **一句话总结**：OpenAI 宣布 Atlas（2025-10-21 上线、以 ChatGPT 为核心的独立浏览器,内置 Agent 模式预览）于 2026-08-09 停止工作,建议用户在此之前导出书签等重要数据。取而代之,OpenAI 把从 Atlas 中学到的经验用于强化 ChatGPT 自身的浏览器体验——多标签页、下载、导航优化、账号登录支持等,更深度的浏览器 Agent 工作被引导至 ChatGPT 桌面应用;"浏览器 Agent 能力"同时并入 Codex。
- **为什么重要**：这是"独立浏览器 Agent 产品"这条路线在不到一年内被验证不如"把 Agent 能力嵌进现有主力产品"划算的一个案例——类似此前 Agent Builder 等平台层产品的弃用节奏,OpenAI 押注独立新形态产品的存续风险再添一例,佐证了知识库长期强调的"OpenAI 平台层产品弃用较快、核心能力向 ChatGPT/Codex 收敛"这一行为模式。对开发者，若曾围绕 Atlas 的 Agent 模式或浏览器自动化接口做集成，需要评估迁移到 ChatGPT/Codex 对应能力的路径。
- **分类**：Agent
- **关联 Topic**：[openai-models](/topics/openai-models) ・ [agent-workspaces](/topics/agent-workspaces)
- **来源**：https://help.openai.com/en/articles/20001371-evolving-atlas-into-chatgpt-for-browser-based-agentic-work

## Harvey 开源法律 Agent 基准 Harvey LAB：24 个执业领域、1,671 个真实任务

- **一句话总结**：法律 AI 公司 Harvey 开源 Harvey LAB（单日 +47，累计 695 star）——评测 LLM Agent 在真实法律工作环境中表现的基准：数据集含 Agent 指令、文档与评分细则,配套执行 harness 跑评测；覆盖 24 个法律执业领域（尤重合同）、1,671 个任务,含逼真的并购（M&A）数据室任务,用全通过（all-pass）细则评分 + LLM judge 判定,并提供评分报告与对比看板。MIT 协议开源,接受新任务与模型适配器贡献。
- **为什么重要**：继 ReviewBench（代码评审）、语音 Agent 三轴评测之后，"真实任务派生基准 + LLM-as-judge"这套评估方法论在法律这一高专业度、高风险垂直领域的落地——由该领域头部厂商亲自下场开源，基准的权威性和任务真实度比第三方構建的更强。这也提示一个通用模式：任何专业服务型 Agent（法务、财务、医疗）要评估能力上限，都需要针对该领域构建全通过细则的真实任务基准，通用编码/对话基准测不出行业深水区的表现。
- **分类**：Evaluation
- **关联 Topic**：[agent-evaluation](/topics/agent-evaluation)
- **来源**：https://github.com/harveyai/harvey-labs

## code-graph-rag 登场：用知识图谱（而非纯 AST）做跨语言代码理解

- **一句话总结**：vitali87/code-graph-rag（单日 +59，累计 2.7k star）——用 Tree-sitter 解析多语言代码库的抽象语法树，再把解析结果存入 Memgraph 构建成知识图谱（而非停留在 AST 快照），维持函数/类/导入/数据流之间的可查询关系；支持基于 AST 的代码搜索与结构化替换、跨赋值与函数调用的数据流追踪、沿调用图识别死代码、经 MCP server 接入 Claude Code 等客户端、用 AI 生成 Cypher 查询做自然语言问答。支持 Python/TypeScript/JavaScript/Rust/Go/Java/C/C++/C#/PHP/Lua/Dart 等语言。
- **为什么重要**：这是"给 AI 工具建代码结构图"这条思路的图数据库实现版本，和几天前基于 Tree-sitter+本地 SQLite 的 code-review-graph 形成有意思的对照——同一个"代码知识图谱"目标，一个走轻量本地存储+MCP 查询工具的路线，一个走专业图数据库+自然语言转 Cypher 查询的路线；后者的优势在于原生支持复杂的多跳关系查询（如"这个函数的调用链最终影响哪些数据库表"），代价是引入额外的图数据库依赖。两条路线的分野本身就是"代码图"这个新兴子领域架构选型的一个具体样本。
- **分类**：Coding
- **关联 Topic**：[ai-code-review](/topics/ai-code-review) ・ [coding-agents](/topics/coding-agents)
- **来源**：https://github.com/vitali87/code-graph-rag
