## HuggingFace 发布语音识别基准"刷分"检测方法论：三种探针戳穿 ASR 模型的数据集指纹识别

- **一句话总结**：HuggingFace 博客提出三种探针检测语音识别（ASR）模型是否在"刷基准"而非真正提升转录能力：①**参考分歧探针**——11 个模型中 6 个即使音频与基准参考文本矛盾，仍复现基准已知的错误参考文本，但换成新采集的国会录音/合成音频后同一模型常会切回忠实转录；②**遮蔽实体检索**——静音音频中的数字后，头部模型在公开基准上恢复率达 30%-40%，明显高于未见过数据；③**拼写切换**——模型按数据集选择正确拼写惯例（如 "Mr." vs "Mister"）的准确率达 90%，暗示模型具备"数据集指纹识别"能力。
- **为什么重要**：这是"基准分数是否反映真实能力"这一评估领域反复出现的质疑，第一次在语音识别垂直领域给出可操作、可复现的检测方法——基准分数好看不代表任务能力真的强，需专门设计探针戳穿"利用基准特征作弊"的可能（详见 [agent-evaluation](/topics/agent-evaluation)）。

## OpenAI 下调 GPT-5.6 Sol API 价格逾 20%，为期三个月（补漏）

- **一句话总结**：OpenAI 自 08-21 起下调 GPT-5.6 Sol 的 API 与信用点定价：输入文本降价超 20%，输出降价约三分之一（短上下文输入从每百万 token $5 降至 $4，输出从 $30 降至 $20）；优惠延伸到 ChatGPT Work 与 Codex 的信用点定价（陆续上线），保证维持到 11 月 21 日；ChatGPT Pro/Plus/Business 订阅价格不受影响。
- **为什么重要**：这是继 07-30 Luna 降价 80%/Terra 降价 20% 之后，OpenAI 主力模型档位又一次幅度可观的价格调整，报道将其归因于 Anthropic 与中国模型的竞争压力，延续了"价格波动大"这条选型风险提示——用 OpenAI 平台做长期成本测算应按"当前价 × 缓冲系数"而非官网价签规划。三个月的限时窗口也提示这更接近促销而非永久调价，需在到期前重新评估（详见 [openai-models](/topics/openai-models)）。
