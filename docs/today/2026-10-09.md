## Claude Managed Agents 公测 Dynamic Workflows：Agent 自己编写多阶段多 Agent 工作流程序

- **一句话总结**：Claude Managed Agents 新增 Dynamic Workflows（beta，需 `managed-agents-2026-04-01` beta header）——面向"要处理大量相似条目"的任务（如审阅数百份文档），Agent 本身可以编写一个"工作流程序"：分阶段调度多个 Agent 并行工作、合并各阶段结果，工作流在服务端作为后台 workflow run 执行，session 的事件流通过 `workflow_run.*` 系列事件跟踪每次运行进度；通过把 `multiagent` 字段设为 `{"type": "multiagent_20261001", "workflows": {"type": "enabled"}}` 开启，并需在 system prompt 里告知 Agent 何时该启动一次 run。
- **为什么重要**：这是 Managed Agents 从"单 Agent 配工具"向"Agent 自己生成并托管执行多 Agent 编排程序"演进的一步——把"写一个跑多个子 Agent 的程序"这件事从开发者手动搭建（如 LangGraph 式显式编排）变成托管 Agent 运行时的原生能力，呼应长时程 Agent领域"分层架构"（开源 harness vs 托管运行时）的趋势，但把编排逻辑的生成也下放给了 Agent 本身。
- **分类**：Agent
- **关联Topic**：[claude-models](/topics/claude-models)・[deep-agents](/topics/deep-agents)
- **来源**：https://platform.claude.com/docs/en/managed-agents/multiagent-orchestration#dynamic-workflows
