## LangChain 发布 Connections：Managed Deep Agents 的托管凭证与按调用者身份系统

- **一句话总结**：LangSmith Managed Deep Agents v0.7.0+ 新增 Connections——把命名凭证存在 LangSmith 工作区（不进代码/`.env`），运行时通过 `connections.get("<slug>", {"type": "agent"|"user"})` 取用；两条独立维度：归属（Agent 共享 vs 按调用者各自的用户凭证）与凭证类型（静态密钥 vs OAuth 授权），无需自建回调路由/令牌存储/刷新逻辑。
- **为什么重要**：解决托管 Agent 的两个真实企业痛点——凭证安全（轮换密钥不用重新部署）与"按调用者身份"（Agent 代表具体某个人执行的操作，落地时带着这个人的真实身份而非笼统的机器人身份，例如提工单显示的是本人账号）；把此前需要手工搭建的 OAuth 管道变成框架内置能力。
