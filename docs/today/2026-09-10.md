## Azure 发布"Agent 优化经济学"系列终篇：可见性・约束・价值度量三支柱

- **一句话总结**：Azure 发布"Agent 优化经济学"系列最后一篇，把 Agent 成本治理归纳为三支柱——可见性（Foundry 成本管理/API Gateway 指标/Agent trace 多层追踪谁在花钱）、约束（项目级 token-per-minute 限流配额、经 Azure API Management 跨模型厂商统一施加策略、财务预算兜底）、价值度量（新增 ROI 功能，把任务完成率/工单转移率等业务结果与运行成本直接挂钩，按 Agent 算净值与回报率）；核心主张是把 Agent 当"持续管理的投资系统"而非一次性降本项目。
- **为什么重要**：这是本知识库自 08-12"三速治理模型"以来持续跟踪的 Azure 成本治理系列的收官——从战略框架（三速模型）到战术清单（四个杠杆）再到量化案例（Foundry IQ/Toolboxes），最后落到"可见性/约束/价值度量"三支柱与可直接核算 ROI 的产品功能，形成一条完整的企业 Agent 成本治理方法论演进链。
