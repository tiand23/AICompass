## OpenMontage 开源：AI 编码助手变身全流程视频制作工作室

- **一句话总结**：calesthio/OpenMontage（单日 +458，累计 4.73 万 star，AGPLv3）——号称"首个开源 Agentic 视频制作系统"，把 Claude Code/Cursor/Copilot/Windsurf 等 AI 编码助手本身变成视频制作工作室的编排者（无独立的代码执行层，Agent 直接读取 YAML 管线定义、调用 100+ 个 Python 工具、按 JSON 记录状态检查点）。三层知识模型：工具+管线定义、Markdown 编写的"skills"（教 Agent 制作规范）、外部技术文档知识包；12 套结构化生产流程（动画解说、数字人播报、纪录片剪辑、播客二创、本地化配音等）均走"调研→提案→脚本→分镜→素材→剪辑→合成"标准阶段，每个关键节点强制人工审批。支持 15 个视频生成、11 个图像生成、多个 TTS/音乐供应商，也能完全用 Archive.org/NASA/Wikimedia Commons 等免费素材库拼出成片，不依赖付费生成式 API。
- **为什么重要**：这是"AI 编码助手 = 通用任务编排器，而非只写代码"这条趋势在视频制作这个具体垂直领域的一次完整落地样本——700+ 个 skill/生产知识文件把"如何做出合格的解说视频/纪录片剪辑"这种专业经验封装成 Agent 可加载的知识层，是 skill 生态从"通用工程纪律"向"专业领域全流程知识"扩张的又一实例；而"每个关键节点强制人工审批 + 决策审计轨迹 + 预算控制"的治理设计，也是长时程多阶段 Agent 任务里"自主执行但保持人工检查点"这一模式的具体工程实现，与知识库此前梳理的长时程 Agent 治理主题一脉相承。
- **分类**：Agent
- **关联 Topic**：[deep-agents](/topics/deep-agents) ・ [agent-skills](/topics/agent-skills)
