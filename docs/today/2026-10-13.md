## LangChain 发布 ScaleDown 与 Deep Agents 集成：专用小模型接管长会话上下文管理

- **一句话总结**：LangChain 发文介绍 ScaleDown 的"约束解码模型"（Constrained Decoding Models，CDM）与 Deep Agents 的集成——针对长时程 Agent 的上下文管理痛点（该保留什么、该摘要什么、该压缩什么，用前沿 LLM 做这类决策又慢又贵），用专精窄任务的小模型替代：`ScaledownSummarizationMiddleware` 替换 Deep Agents 内置摘要中间件压缩旧对话历史（成本比 GPT 系模型低 41 倍）；工具结果压缩中间件在 Agent 看到大型工具输出前先提取相关片段（实测可压缩约 90% 上下文）；抽取（从用户消息里精确拷贝订单号/邮箱等结构化字段而非改写）；分类（按预定义类别打标签+置信度+理由，可用于检测 Agent 行为漂移或路由决策）；所有模型支持最多 100 万 token 输入且多模态（图像/PDF）。官方称这类窄任务模型比前沿模型快 200 倍、便宜 467 倍。
- **为什么重要**：这是"垂直场景不需要前沿智能"效率哲学（此前已见于 LangSmith Tuned Evaluators、Switchyard 模型路由）在"长会话上下文管理"这个具体子问题上的专用化落地——把摘要/压缩/抽取/分类这几类结构性、高频、低创造性的决策从主模型循环里剥离出来，是降低长时程 Agent 运行成本的一个直接可落地的具体模式（详见 [deep-agents](/topics/deep-agents) ・ [model-efficiency](/topics/model-efficiency)）。
- **分类**：Agent
- **关联Topic**：[deep-agents](/topics/deep-agents)・[model-efficiency](/topics/model-efficiency)
- **来源**：https://www.langchain.com/blog/building-long-running-agents-with-scaledown-and-deep-agents
