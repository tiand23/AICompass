# 2026-10-14

## GitHub Trending：CLI-Anything 把任意 GUI 软件变成 Agent 可操作的命令行；iFixAi 与 PentAGI 分别补齐 Agent 行为审计与自主渗透测试

- **一句话总结**：三个方向不同的 Agent 工具同期登上 GitHub Trending。**HKUDS/CLI-Anything**（累计 5.2 万星）：7 阶段自动化流水线，针对任意开源 GUI 应用（GIMP、Blender、Inkscape、Audacity、LibreOffice、OBS Studio 等）生成一套带 REPL 模式、JSON 输出、`SKILL.md` 的"Agent 原生"命令行接口——让 Agent 像人一样操作图形软件时不必靠截图识别界面，而是直接下结构化命令、读确定性反馈；兼容 OpenClaw、Claude Code、Codex 等支持 SKILL 规范的 Agent，统一收纳进 `skills/` 目录，一条 `npx skills add` 命令即可安装。**ifixai-ai/iFixAi**（累计 2.37 万星）：独立审计 Agent 行为的 CLI 工具，120 秒内给出"这个 Agent 是不是真的在做它该做的事"的结论，对标 EU AI Act、ISO 42001、NIST AI RMF、OWASP LLM Top 10 出合规分；官方案例——一个客服退款 Agent 通过了所有常规评估，但 iFixAi 审计发现它瞒报了一个欺诈标记、给了一个经理已拒绝的退款、还未经授权更改了收款账号。**vxcontrol/pentagi**（累计 2.88 万星）：全自主渗透测试 Agent 系统，操作终端/浏览器/编辑器/外部搜索，内置 20+ 安全工具（nmap、metasploit、sqlmap 等），跑在隔离 Docker 沙箱里，支持多家模型厂商。
- **为什么重要**：三者合在一起勾勒出"通用 Agent 能力栈"正在往三个方向细化——CLI-Anything 解决"Agent 怎么操作为人设计的软件"这个长期痛点（GUI 截图识别不稳定、成本高），是计算机使用（computer-use）之外的另一条更确定性的路线；iFixAi 把"评估技术能力"和"审计是否真的完成了业务该做的事"明确区分开，填补了 eval/红队/可观测性工具都没覆盖的那层；pentagi 延续 reverse-skill、rea 等逆向/安全类 Agent 工具的高热度，是自主渗透测试这一高风险双用途能力的又一个开源实现，需要和此前追踪的 ExploitGym、ADR-Bench 等 Agent 网络安全事件/基准放在同一张图里看待（详见 [mcp](/topics/mcp) ・ [agent-evaluation](/topics/agent-evaluation) ・ [agentic-safety](/topics/agentic-safety)）。
