# 2026-09-22

## Claude Opus 5.5 发布：面向长时程编码与知识工作，始终开启自适应思考

- **一句话总结**：Anthropic 发布 Claude Opus 5.5，定位长时程 Agent 编码与知识工作：默认即最大 100 万 token 上下文、12.8 万最大输出 token、自适应思考始终开启（`thinking: disabled` 返回 400 错误）；定价 $4/$20 每百万 token；经 Claude API、Amazon Bedrock、AWS/Google Cloud 上的 Claude Platform、Microsoft Foundry 同步提供。API 侧破坏性变更：`tool_choice` 的 `any`/`tool` 两种强制工具调用类型返回 400；计算机工具需升级到 `computer_toolset_20260801`（旧版 `computer_20251124` 不再接受）。同日上线 Fast Mode 研究预览（Opus 5.5 专属）与 Inline Tools beta（可在对话中途的 system 消息里定义工具）。
- **为什么重要**：这是继 09-01 Fable 5.1/Mythos 5.1 之后 Anthropic 本月第二次模型线更新，且是 Opus 档位本身的换代（7 月发布的 Opus 5 之后）；强制自适应思考、移除手工工具强制调用，延续"用 effort/thinking 机制替代手工 prompt 调优"的产品哲学，但也意味着依赖旧 `tool_choice`/旧版计算机工具的集成方需要改造。
- **分类**：Models
- **关联Topic**：[claude-models](/topics/claude-models)
- **来源**：https://platform.claude.com/docs/en/release-notes/overview

## GPT-6 Astra/Sol/Luna 与 Claude Opus 5.5 同日登陆 Microsoft Foundry

- **一句话总结**：Microsoft Foundry 同日新增两条模型线——面向生产 Agent 场景的 GPT-6 Astra/Sol/Luna 全系（OpenAI），以及刚发布的 Claude Opus 5.5（面向长时程编码与知识工作）；均纳入 Foundry 统一的模型评估/部署/治理控制面。
- **为什么重要**：延续"平台先于模型"与"多厂商模型市场"策略（继此前 Grok 4.6、GPT-6 Astra 限量接入之后），这次是新模型发布当天即同步上架 Foundry，模型厂商发布节奏与云厂商上架节奏的间隔正在缩短；Claude Opus 5.5 与 GPT-6 系列同台可直接对比选型，进一步坐实"已承诺某云的企业无需切换供应商合同即可评估更多前沿模型"（详见 [claude-models](/topics/claude-models) ・ [openai-models](/topics/openai-models)）。
- **分类**：Agent
- **关联Topic**：[cloud-agent-platforms](/topics/cloud-agent-platforms)
- **来源**：https://azure.microsoft.com/en-us/blog/gpt-6-astra-sol-and-luna-for-production-agents-in-microsoft-foundry/
