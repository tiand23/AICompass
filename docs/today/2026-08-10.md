## Semantica 登场：给 AI 系统装一层"确定性"知识图谱基础设施

- **一句话总结**：semantica-agi/semantica（单日 +967，累计 3.7k star）——开源 Python 库，在 LLM 和向量库之下再垫一层确定性的推理与溯源层，构图/推理/审计全程不依赖机器学习。核心是 Context Graph：把实体、关系、**决策本身**都建成带类型的图节点/边，可按图遍历查询而非向量相似度匹配；`record_decision()`/`trace_decision_chain()`/`find_similar_decisions()` 把每个决策变成可追溯、可按先例检索、有因果链接的一等对象，并可导出成 W3C PROV-O 供监管提交。推理引擎支持前向链、Rete 网络、Datalog、SPARQL，全部给出可解释的推理路径；内置多源摄取（Databricks/Snowflake/数据库/文件/API/流）与冲突检测；存储可接 Neo4j/FalkorDB（属性图）、Blazegraph/Apache Jena（RDF 三元组）及主流向量库；支持时间点快照与双时态事实。配 MCP server（接 Claude Desktop/Windsurf/Cline/VS Code）、REST API、CLI 与浏览器端图谱可视化工作台。118,000 节点的生产图谱上，节点搜索经 embedding 缓存优化后提速 6000 倍（24ms→0.004ms）。
- **为什么重要**：这是知识库长期标注"待积累"的 Knowledge Graph / GraphRAG 生态位一个分量很重的样本，也是对"Agent 黑箱不可审计"这个真实痛点的正面回应——面向金融、医疗、政府等受监管行业，把"决策"本身而非仅"知识"建模成图里的一等对象，是比常规 GraphRAG（图谱辅助检索）更进一步的定位：不只是"用图查得更准"，而是"每个 Agent 决策天生带因果链和先例可查"。对企业 AI 架构而言，这提供了一种不依赖模型可解释性研究、而是靠外部确定性结构层来满足合规审计要求的现实路径。
- **分类**：RAG
- **关联 Topic**：[knowledge-graph](/topics/knowledge-graph)
- **来源**：https://github.com/semantica-agi/semantica

## Paperclip 登场：把管理 Agent 团队做成"给 Agent 当经理"的产品

- **一句话总结**：paperclipai/paperclip（累计 7.62 万 star）——开源 Node.js 服务端 + React 界面，定位是"公司里用来管理 Agent 干活的那个 App"：以工单/任务为单位追踪工作，Agent 状态跨会话持久保留；提供组织架构（角色、汇报线、权限）、按 Agent/项目/公司维度的预算强制与成本追踪、定时心跳驱动 Agent 自主工作、面向人工监督的治理与审批流、多公司数据隔离、密钥管理与审计日志。明确不做的事：不是聊天机器人、不是 Agent 框架、不是工作流编排器——它假设你已经有 Agent（Claude Code、OpenClaw、Codex 等），只负责把它们组织成"团队"来干活，而不是逐个开 20+ 个终端标签页手动盯着。
- **为什么重要**：这是"给 Agent 团队配一套企业管理软件"这条思路第一次做成独立产品——把 loopx（外部状态内核）、openwork Den（组织级管控面）、Claude Managed Agents 的预算硬顶等此前分散在各处的碎片能力（跨会话状态、预算、治理审批、审计）整合进一个统一的"Agent 人力管理"心智模型；7.62 万 star 说明"像管理员工一样管理 Agent"这个类比切中了真实需求。对正在同时跑多个 Agent 会话的团队，这提供了一个脱离"人工盯 N 个终端"的现成参考架构。
- **分类**：Agent
- **关联 Topic**：[enterprise-ai-agents](/topics/enterprise-ai-agents) ・ [agent-workspaces](/topics/agent-workspaces)
- **来源**：https://github.com/paperclipai/paperclip
