# 2026-09-24

## Microsoft Foundry 新增语音 Agent 公测、扩展模型选择与持续优化

- **一句话总结**：Microsoft Foundry 发布三项更新：语音 Agent 公测（亚秒级延迟、80+ 语言/140+ 地区、可部署到 Web/Teams/Teams Phone/Twilio 电话线路，支持 prompt 式与托管两种 Agent 形态，语音转文字/文字转语音可选 OpenAI、Microsoft 等多家模型）；模型选择扩展（新增 GPT-6 系列 SKU 与 Claude Opus 5.5）；持续优化能力（用生产环境 trace 数据针对质量/延迟/成本持续调优 Agent 的指令、skills、工具与模型选型）。
- **为什么重要**：语音 Agent 补上 Foundry 对标 Google Gemini Live 的最后一块产品拼图（详见 [voice-agents](/topics/voice-agents)），而"用生产 trace 持续优化"呼应 LangSmith Engine 的自动诊断修复思路——两大平台正收敛到同一套"用真实运行数据驱动 Agent 持续迭代"的方法论。
- **分类**：Agent
- **关联Topic**：[cloud-agent-platforms](/topics/cloud-agent-platforms)
- **来源**：https://azure.microsoft.com/en-us/blog/ship-agents-faster-with-expanded-model-choice-voice-agents-and-continuous-optimization/

## LangChain 发布 LangSmith 平台更新：Engine v2、Managed Deep Agents v0.8、Trajectories、Fine-Tuning、Custom Apps

- **一句话总结**：LangChain 一次性发布 LangSmith 五项更新——**Engine v2**：为 Engine（自动扫描生产 trace 诊断 Agent 故障的内置 Deep Agent，08-25 已有性能升级记录）新增红队测试与自动化测试能力；**Managed Deep Agents v0.8**：新增身份认证、记忆管理与消息渠道（Channels）能力，紧接 09-09 Connections 托管凭证功能之后的又一次托管运行时能力扩充；**Trajectories**：LangSmith 内新增"可读"的 Agent 会话全过程查看视图；**LangSmith Fine-Tuning**：平台内置微调能力；**LangSmith Custom Apps**：围绕 Agent 数据构建自定义界面的能力。
- **为什么重要**：这是一次打包的"平台能力发布周"，覆盖了可观测性（Trajectories）、安全测试（Engine v2 红队）、托管运行时（Managed Deep Agents v0.8）、模型定制（Fine-Tuning）与界面层（Custom Apps）五个此前分散演进的方向，说明 LangSmith 正从"工具集合"向"一体化 Agent 生产平台"收敛——尤其 Managed Deep Agents 身份认证能力与 09-09 Connections 衔接，托管凭证/身份这条线在两周内连续两次迭代。
- **分类**：Agent
- **关联Topic**：[cloud-agent-platforms](/topics/cloud-agent-platforms)・[deep-agents](/topics/deep-agents)
- **来源**：https://www.langchain.com/blog/new-in-langsmith-engine-v2-managed-deep-agents-fine-tuning-and-more
