## LangChain 发布 Deep Agents v0.7

- **一句话总结**：基础 harness 精简，同等性能下基础输入 token 减少 65%；文件系统工具全面优化（分页 read_file、grep 千条上限 + 流式输出、大目录不再卡死）；消息历史改用 DeltaChannel 增量存储，checkpoint 不随会话变长而膨胀；实验性 CodeInterpreterMiddleware 支持在 QuickJS 沙箱内执行代码与程序化调用工具；破坏性变更：TodoListMiddleware 改为手动开启、backend factories 移除。
- **为什么重要**：这份更新清单就是长时程 Agent 的生产痛点清单——token 成本、checkpoint 膨胀、大目录检索——"基础 token 省 65%"对生产部署是直接的成本削减；在用的注意两个破坏性变更再升级。
- **分类**：Agent
- **关联 Topic**：[deep-agents](/topics/deep-agents)
- **来源**：https://www.langchain.com/blog/deep-agents-v0-7
