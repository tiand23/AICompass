## Azure 发布 Agent 上下文工程实测数据：知识库检索省 34% token、工具库省 97% token

- **一句话总结**：微软 Azure 博客发布"Agent 优化经济学"系列新文章，围绕 Microsoft Foundry 的上下文工程给出具体量化数据：Foundry IQ 知识库用语义重排序+定向段落检索替代宽泛文档搜索，证据召回率提升 54%、检索 token 成本降低 34%；Toolboxes 机制按需检索工具定义而非把全部工具塞进 prompt，大型工具库场景下输入 token 消耗降低约 97%；另有 Skills（可复用流程集中管理、免重新部署即可更新）与分级记忆（会话/用户/流程级）机制，减少对话重放带来的重复消耗。
- **为什么重要**：这是少见的、给出具体量化数字的企业级上下文工程实践公开案例，直接回应"Agent 越用越贵"这个企业落地的核心痛点；"工具按需检索"这个思路与 MCP 工具发现机制、以及 harness 工程里"精简工具清单避免 token 膨胀"是同一方向的不同实现，是 08-12 Azure 提出的"三速治理模型"里"运行时优化"这一层的又一次具体化。
