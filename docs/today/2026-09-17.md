## LangChain 发布 Deep Life Sci：面向临床与实验室科学家的开源 Agent harness

- **一句话总结**：LangChain 基于自家 Deep Agents harness 发布 Deep Life Sci——开源的临床/实验室科研 Agent，接入 60 万+ ClinicalTrials.gov 临床试验、2900 万篇 PubMed 摘要、1200 万篇 PubMed Central 全文，支持 PDF/图像/表格/RIS 文献库/SMILES 与 FASTA 序列/RNA-seq/蛋白质组学等输入，用沙箱化子 Agent 分工检索/审阅/分析，LangSmith 记录检索、代码执行、文档审阅、子 Agent 路由到最终答案的全链路，可供调试与审计；因开源，机构可接入私有数据、换模型、加自定义护栏。此前 09-14 已有 LangChain 发文分享 Madrigal Pharmaceuticals、Abridge、Vizient 三家医疗/生命科学客户的 Agent 规模化经验，09-17 同日还有 Included Health 用 Deep Agents + LangGraph 构建医疗导航联邦 Agent 的案例发布，三篇文章共同标志生命科学/医疗正成为 Deep Agents 继客服、企业内部工具之后的下一个重点垂直场景。
- **为什么重要**：这是继 OpenMontage（视频制作）、Harvey LAB（法律）之后，"开源通用 harness + 垂直领域深度定制"模式在生命科学这一高专业壁垒领域的落地，且直接给出可审计的证据链设计——对需要满足临床/科研合规要求的 Agent 应用有直接参考价值。
- **分类**：Agent
- **关联Topic**：[deep-agents](/topics/deep-agents)・[enterprise-ai-agents](/topics/enterprise-ai-agents)
- **来源**：https://www.langchain.com/blog/agent-harness-life-sciences

## Anthropic 推出 Life Sciences Verification Program 公测：从实时拦截转向离线行为模式监控

- **一句话总结**：Anthropic 开放生命科学验证计划（LSVP）公测申请——通过验证的团队可解除 Fable 系列在药物发现、研究生物学、临床开发、生产制造等场景的默认拦截；分两档授权：面向团队、按年续期的 Standard Use（覆盖多数生物研发工作流）与项目范围、6 个月期的 High-risk Use（为 Opus 5/Sonnet 5 完全移除生命科学拦截）；执法方式从"逐条请求实时拦截"转向"跨行为模式的离线监控"，被标记行为相关数据需保留 30 天。
- **为什么重要**：是 08-27 预告的"与美国政府合作为生命科学研究者开放 Mythos 级模型访问"计划的正式产品化落地，也是双重用途护栏从"一刀切拦截"向"分级授权+事后监控"演进（继 08-07 分类器重训精细化之后）的又一步——用订阅式信任换取更少打断，同时把监控成本转移到离线行为分析。
- **分类**：Models
- **关联Topic**：[agentic-safety](/topics/agentic-safety)・[claude-models](/topics/claude-models)
- **来源**：https://www.anthropic.com/news/life-sciences-verification-program
