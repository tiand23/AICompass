## Anthropic 发布 Claude Fable 5.1 与 Claude Mythos 5.1：Terminal-Bench-Science 翻倍，缓存读取降价 75%

- **一句话总结**：Anthropic 发布新一代旗舰模型 Claude Fable 5.1（面向所有人）与 Claude Mythos 5.1（仅限受信任访问计划内的美国企业/个人，护栏更宽松），二者同底座、安全护栏级别不同。跑分：Terminal-Bench-Science 0.1 从上代 Fable 5 的 24.7% 提升到 52.6%（翻倍以上）；Terminal-Bench 4.0 编码基准 Fable 5.1 得 55.8%（Fable 5 为 42.0%，Opus 5 为 52.3%），Mythos 5.1 在更宽松的网络安全护栏下达 60.9%；知识工作基准 GDPval-AA v2 得分 1,853（Opus 5 为 1,824）。缓存读取成本降低 75%，典型工作负载综合降本约 25%、高强度 Agent 场景最高降 45%，基础定价维持 $10/$50 每百万 token 不变；网络安全场景误报减少 60%。默认 100 万 token 上下文、12.8 万最大输出、始终开启自适应思考；生成内容附带水印与 C2PA 内容凭证；两个模型均要求 30 天数据留存，非明确授权不支持零数据留存。
- **为什么重要**：这是继 Opus 5 之后 Anthropic 顶层模型档位的又一次迭代，编码与科研两个场景的基准提升幅度都很大（尤其 Terminal-Bench-Science 翻倍），同时把成本和安全误报都往下压——"更强、更便宜、更少误杀"三个方向同时推进，直接影响正在用 Fable/Mythos 系列做编码或科研 Agent 的团队的选型和成本预估（详见 [claude-models](/topics/claude-models)）。

## Anthropic 推出 Enterprise Frontier Safeguards：零数据留存 + 免人工审查的自动化滥用监控

- **一句话总结**：Anthropic 联合 100 余家企业客户（涵盖金融、医疗、制造、电信、法律、零售、公共部门，包括高盛、Visa、Salesforce 及 AWS/Google Cloud/Azure 等云厂商）共同开发 Enterprise Frontier Safeguards——一套把"零数据留存隐私承诺"与"自动化滥用检测"结合在一起的机制：企业可自主控制数据如何被审查、存储、管理，且能开启完全不经过 Anthropic 人工审查的自动化安全监控。分阶段上线，目标今年秋季更大范围可用；免费提供，无论客户是直连 Anthropic 还是经云厂商访问都生效。此次调整发生在客户对此前数据留存政策提出反馈之后。
- **为什么重要**：这是零数据留存与滥用监控"两难"问题的企业级解法，与 OpenAI 8/19 发布的 Private Safety Processing 思路高度对称——都是"保留 ZDR 承诺的同时，找一种不依赖窥探原始内容的方式做安全监控"，且都强调"不需要人工审查"这一点。两大厂商在同一个问题上给出相似方向的答案，说明这已经成为面向企业客户的行业级刚需，而不是单家公司的特例（详见 [agentic-safety](/topics/agentic-safety)）。
