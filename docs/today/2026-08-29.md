## OpenAI 终止与 Cursor 的合作：SpaceX/xAI 收购 Cursor 后模型访问权被切断

- **一句话总结**：SpaceX 今年 6 月以股票方式同意收购 Cursor（含以 600 亿美元收购或支付 100 亿美元分手费的选择权条款），交易已于 8 月 14 日完成。8 月 29 日，OpenAI 宣布终止与 Cursor 的合作关系，提出 11 月 12 日为 Cursor 失去 OpenAI 模型直接访问权的日期——这是合同允许的最长通知期。OpenAI 官方表态："基于我们与埃隆·马斯克旗下公司此前违反合同的经历，我们无法确信 SpaceX 会在我们的服务条款范围内使用我们的技术。"Cursor CEO Michael Truell 淡化影响，称 OpenAI 模型目前仅处理其约 5% 的流量，Anthropic 已承诺提供更多 Claude 模型支持作为补位。
- **为什么重要**：这是编码 Agent 生态里罕见的"模型供应商主动切断特定下游客户访问权"事件，直接原因是收购方（马斯克旗下企业）与 OpenAI 的既有信任与合同纠纷延伸到了模型访问层——对使用 Cursor 或其他被竞争对手收购/关联的 AI 编码工具的开发者，这是一个具体的供应链风险案例：工具层面的稳定性不仅取决于工具本身的技术路线，也取决于其股权归属与上游模型厂商的商业关系。5% 流量占比、Anthropic 迅速补位的细节也说明当前编码 Agent 工具普遍已做多模型冗余，单一模型断供的实际冲击可能有限（详见 [coding-agents](/topics/coding-agents)）。
- **分类**：其他（生态/供应链）

## three.ws 开源：给 AI Agent 装上"身体、大脑、钱包与工作"的全栈框架

- **一句话总结**：three.ws 是一套开源平台（Apache 2.0），把四个此前分散的能力整合进单一 Agent 实例：①**身体**——3D 生成管线，接受文字/照片/草图输入，路由到 Microsoft TRELLIS、Hunyuan3D 2.1、TripoSR 等多个生成引擎（按延迟与健康度选路，自动故障转移），产出带骨骼绑定与贴图的可动画 glTF 角色；②**大脑**——多模型路由运行时（而非单一模型），把请求分发给 Claude、GPT-5.x、Grok 及经 NVIDIA NIM 提供的开源模型，维护跨会话的分类记忆（用户/反馈/项目/参考），把情绪状态混入表情/动作，迭代式执行工具调用；③**钱包**——基于 Solana 的链上经济身份，通过 CREATE2 把 ERC-8004 合约部署到 12 条 EVM 链，用 x402（HTTP 402 支付协议）结算，Agent 可按函数调用收取 USDC 微支付而无需人工托管私钥，截至 8 月 25 日已完成 110,416 笔链上 USDC 结算；④**工作**——多端分发，一行代码嵌入网页、AR 放置链接、72 个 MCP server、ChatGPT 插件、Android Trusted Web Activity、`npx` 终端运行，同一个 Agent 实例可以同时存在于网页、聊天客户端、物理空间与语音界面。资金转移动作经过 7 层强制检查的守卫链。已与 OpenAI（Select Partner）、NVIDIA（Inception 会员）、IBM（Business Partner）建立官方合作。
- **为什么重要**：这是第一次看到"3D 具身、多模型推理、链上经济身份、多端分发"这四个此前分别演进的方向被整合进同一个开源框架——尤其是"钱包"这一环（x402 协议 + 链上身份让 Agent 能自主收发微支付而不经人工），补上了 Agent 经济活动这条此前知识库较少涉及的线；72 个 MCP server 的官方注册表也是 MCP 协议在分发层的一次大规模应用样本（详见 [mcp](/topics/mcp)）。作为单一社区项目，其长期影响力仍待观察，但这套"具身+推理+支付+分发"四件套的组合思路本身是一个值得记录的新综合方向（详见 [agent-frameworks](/topics/agent-frameworks)）。
