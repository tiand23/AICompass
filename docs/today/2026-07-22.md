# 2026-07-22

## OpenAI 发布 Presence：面向企业的语音/对话 Agent 平台

- **一句话总结**：OpenAI 推出 Presence，帮助企业部署可查询公司系统、执行经批准的操作并在需要时升级到人工的实时语音与聊天 Agent，主打客服、销售开发、采购、IT、HR 场景；目前为受限 GA，由 OpenAI 前置部署工程师（FDE）与系统集成商主导交付，不提供自助开通。
- **为什么重要**：OpenAI 正式下场做企业 Agent 交付（而非只卖 API），"平台 + 驻场工程师"的模式对做企业 Agent 集成的开发者/服务商是直接的竞争与参照系；OpenAI 自称其约 75% 的入站支持请求已由该系统处理。
- **分类**：Agent
- **关联 Topic**：暂无
- **来源**：https://openai.com/index/introducing-openai-presence/

## Claude Managed Agents 一批 API 更新

- **一句话总结**：Managed Agents 支持在 agent 的模型配置里设置 effort 级别；webhook 覆盖 environment 与 memory store 生命周期（共 7 种新事件类型）；创建 session 时可用 `initial_events` 预置事件并直接启动 agent loop；更新 agent 时 `version` 改为可选（乐观并发）；线程级事件流支持 event deltas 预览子 agent 生成过程。
- **为什么重要**：这批更新都指向"托管 Agent 的工程化运维"——免轮询的生命周期事件、一次调用完成会话初始化、细粒度流式观测，是评估托管式 Agent 运行时成熟度的具体信号。
- **分类**：Agent
- **关联 Topic**：暂无
- **来源**：https://platform.claude.com/docs/en/release-notes/overview
