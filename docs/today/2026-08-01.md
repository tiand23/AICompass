## openwork 登上 GitHub Trending：Claude Cowork 的开源替代

- **一句话总结**：openwork（TypeScript）单日 +796 star（累计 19.5k）——基于 opencode 的开源跨平台桌面 Agent 工作台，定位 Claude Cowork / Codex 替代品；一个 openwork MCP 接入 Claude Code、Cursor、Codex 等任意客户端，即可跨工具、跨团队复用同一套 skills、MCP 与连接服务，并配组织级管控面 Den（供给推理、管理访问、发布 skill、控制策略）。

## reverse-skill 登上 GitHub Trending：首个 skill 路由包形态

- **一句话总结**：reverse-skill（PowerShell）单日 +612 star——逆向工程/授权渗透测试/安全研究领域的 skill 路由包：AI 按任务自动路由到对应专项 skill，按需自举工具链，配自动进化的经验库，支持 Claude Code、Kiro、Cursor、Cline 等客户端。

- **分类**：Agent
- **关联 Topic**：[agent-skills](/topics/agent-skills)
- **来源**：https://github.com/zhaoxuya520/reverse-skill
