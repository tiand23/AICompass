## code-review-graph 登场：用 Tree-sitter 代码图给 AI 工具做"血缘分析"省 token

- **一句话总结**：tirth8205/code-review-graph（单日 +237，累计 2.9 万 star）——用 Tree-sitter 解析代码库的函数、类、导入、调用关系成有向图，存本地 SQLite（`.code-review-graph/` 目录）；改动代码时做影响范围分析（blast-radius），追溯受影响的调用方、依赖方与测试；AI 工具通过 30 个 MCP 工具查询这张图，而不必读整棵文件树。实测：审查 Flask 代码库朴素方式耗 143,594 token，用图只需 2,196 token——**71 倍**降幅；六个真实仓库上按问题计的中位数节省约 **65 倍**。支持增量更新（3000 文件项目重新索引约 2.5 秒）、40+ 语言、GitHub Action 风险评分 PR 审查、可选向量语义搜索、Leiden 算法社区检测。
- **为什么重要**：这是"给 AI 工具建代码结构图省 token"这条思路的一个具体且数据扎实的实现——本质和文档解析里的"空间定位"、视频剪辑里的"转写代理视觉信息"是同一个模式的第三次复现：把高维原始信息（整个代码库文本）压缩成一张结构化的低维代理表示（调用图），推理主要发生在代理表示上，真正需要源码细节时才局部展开。MCP 作为图查询的接口层，也是"用协议暴露结构化知识而非文本转储"这一实践的又一实例。
- **分类**：Coding
- **关联 Topic**：[ai-code-review](/topics/ai-code-review) ・ [coding-agents](/topics/coding-agents)
- **来源**：https://github.com/tirth8205/code-review-graph

## Claude Managed Agents 一次上线四项企业级运维能力：预算硬顶、顾问模型、数据落地地、GitHub 加载 skills

- **一句话总结**：Claude Managed Agents 同日发布四项功能：①Session Budget——给会话设消费硬顶（按公开价目计费），触达上限即暂停（`budget_reached`），改预算或清除后可续跑；②Advisor——给会话主线程配一个能力不低于自身的"顾问模型"，执行中途可咨询获取策略建议；③`inference_geo`——按 agent 或按会话指定模型推理的地理位置，对应数据落地（data residency）合规需求；④Skills 可直接从 GitHub 仓库加载——会话挂载仓库后，根目录 `.claude/skills` 下的 skill 在会话启动时自动发现并可用。

## Anthropic 大幅收窄 Fable 5 生物学误判：假阳性降约 85%

- **一句话总结**：Anthropic 重写了 Fable 5 生物安全分类器的"宪法"（区分受限内容与允许内容的规则集），为良性用途新增细化豁免条款，收集专家反馈并用更新的训练数据重新训练分类器——结果是生物学相关的误拦截（fallback）降低约 85%，模型能承接更大范围的合法生物学任务。病毒学、毒理学、分子设计这三类高风险请求仍被拦截并路由给能力较弱的 Opus 5；面向前沿生物研究的可信访问通道仍在开发中。
- **为什么重要**：这是"双重用途安全护栏"从"一刀切限制"走向"精细化校准"的一个具体案例——Fable 5 发布时因生物能力突出而设了宽泛限制，此次调整证明安全团队确实在拿真实使用数据反哺分类器，而不是把护栏定了就不再动。对做生物医药、化学等敏感领域应用的开发者，这意味着此前被误拦的合法请求值得重新试一次；也提示了一种可复制的方法论——护栏的精度提升来自"规则细化 + 数据反哺"，而不是简单放宽阈值。
- **分类**：其他（安全）
- **关联 Topic**：[claude-models](/topics/claude-models)
- **来源**：https://www.anthropic.com/news/improving-fable-5-s-biology-safeguards

## LangSmith 发布 Managed Deep Agents 公测：Deep Agents 的托管运行时

- **一句话总结**：LangSmith 推出 Managed Deep Agents 公测（Public Beta）——把开源的 Deep Agents 框架变成托管服务：本地用 `mda dev` 开发调试，`mda deploy` 部署到 LangSmith 托管运行时；提供持久化执行（长任务可暂停/重试/恢复不丢状态）、流式进度与状态持久化、沙箱（文件操作与代码执行隔离环境，接入 LangSmith Sandboxes）、跨会话的 Agent 级记忆、原生 Slack/GitHub 接入通道、支持 OIDC 的身份认证与按用户线程隔离、Harbor 框架评估集成、LangSmith 全链路可观测。目前限 LangSmith Cloud 美国区，CLI 优先，未公布定价。

## Claude Code v2.1.224：会话之间可以互相发消息，从单会话工具变成小型分布式系统

- **一句话总结**：Claude Code 2.1.224 新增跨会话通信能力：独立的 Claude Code 会话可以通过 `ListAgents`/`SendMessage` 两个工具互相发现并交换纯文本消息——消息只是"一个 Claude 写给另一个 Claude 的一段文字"，不含对话历史或文件本身。同机器会话走 Unix domain socket 通信，跨机器会话经 Anthropic 的 Remote Control 基础设施路由。次日 2.1.225 进一步放宽限制：会话可以按名字主动发起与 Remote Control 会话的对话，而不再局限于被动回复模式。目前仅支持 macOS/Linux。与前一天发布的自托管 runner（详见 08-06）互为补充：runner 解决"执行放在哪"，跨会话消息解决"多个独立会话之间怎么协调"。
- **为什么重要**：这是把 Claude Code 从"一个人配一个终端会话"推向"多个会话自主协调"的关键一步——此前多 Agent 协作要么靠外部编排框架（LangGraph 一类），要么靠外部状态层（loopx 一类），Claude Code 现在把最基础的"发现同伴、互发消息"能力做进了产品自身。消息被严格限定为"纯文本、不含历史与文件"这个设计选择也值得注意——避免了上下文/凭证跨会话泄露的风险面，用最小的信息带宽换取跨会话协调能力，是权限最小化原则在多 Agent 通信场景的具体体现。
- **分类**：Agent
- **关联 Topic**：[coding-agents](/topics/coding-agents) ・ [deep-agents](/topics/deep-agents)
- **来源**：https://code.claude.com/docs/en/whats-new/2026-w32
