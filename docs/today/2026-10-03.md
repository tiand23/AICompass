## Microsoft × HuggingFace 发布 ThinkingBox：按数据库终态而非 Agent 自述评估企业工作流 Agent

- **一句话总结**：Microsoft 与 HuggingFace 联合发布 ThinkingBox 基准——不信任 Agent 的最终回复或工具调用记录，而是直接检查它在数据库里留下的终态与副作用；覆盖 507 个有状态的企业业务工作流，在 18 个 LLM 上每个工作流重复跑 20 次，核心论点是"最终回复"与"合法的工具调用"都只是代理指标，Agent 可能话说得很对但写错了值、改错了记录、或产生了多余的副作用，只有它留下的记录才能回答问题到底做对没有。
- **为什么重要**：这是继 09-29 ProvenanceGuard（核查引用来源对不对）之后，Agent 评估领域又一次把"不要只信 Agent 自己说了什么"系统化成可复现方法论——这次核查对象从"答案的溯源"转向"系统状态的真实变化"，且用 20 次重复同一任务的设计直接量化了"Agent 能不能稳定做对，而不是蒙对一次"这个此前很少被单独测量的维度。
