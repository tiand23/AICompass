## Anthropic 预览 Model Hardware Standard：让 Agent 安全操作实验室/制造业物理设备的通用规范

- **一句话总结**：Anthropic 面向首批科研实验室与先进制造企业开放 Model Hardware Standard（MHS）研究预览——一套让 AI Agent 并行操作显微镜、液体处理器、机械臂等多种实验室/制造设备的共享规范，任务范围覆盖从常规药物发现实验到量子计算机激光校准。当前痛点是每套设备互不通信，实验室/工厂通常需要数周到数月时间由专人搭建定制集成；MHS 把这一集成工作压缩到几小时到几分钟。MHS 与模型无关，兼容任意具备可编程接口的设备，任意 Agent harness 可通过 Model Context Protocol 等标准协议访问；由 Anthropic 与 HHMI Janelia Research Campus 合作开发，目前仅研究预览阶段，计划未来开源。
- **为什么重要**：这是知识库首次记录"Agent 安全操作物理世界硬件"这条线被系统性标准化——此前 Agent 安全的讨论集中在数字世界（沙箱逃逸、工具滥用），MHS 把"给 Agent 什么权限、怎么审批、怎么隔离"这套原则第一次系统性搬进了会造成真实物理后果的实验室/制造设备场景；用 MCP 这类既有协议接入也说明"协议层不必重新发明"，新增的是设备接入与安全操作规范本身（详见 [agentic-safety](/topics/agentic-safety)）。
- **分类**：其他（安全/协议）

## Anthropic 扩大科研支持：开放 1 万个免费/折扣 Claude 席位，联邦政府合作开放 Mythos 级模型给生命科学研究者

- **一句话总结**：Anthropic 宣布向科学家开放 1 万个免费与折扣 Claude Team 席位——标准席位免费，用量五倍的高级席位每月 15 美元且价格锁定一年，未来数月计划扩展到远超 1 万席位。此次扩展建立在 06-30 发布的 Claude Science（预配置基因组学/单细胞分析/蛋白质组学/结构生物学/化学信息学等领域 60+ skill 与连接器的科研工作台）之上，并把此前仅限生物科学的 AI for Science credit 计划扩展到更广领域。同时 Anthropic 正与美国政府合作，为生命科学专业人士建立访问计划，使用其 Mythos 级模型做生命科学研发，首批参与者已入组。
- **为什么重要**：这是 Claude Science 产品线（06-30 发布、08-26 刚扩展 Compliance API 覆盖）的又一次实质性扩容——把"免费/折扣访问"与"政府合作的 Mythos 级模型访问计划"两种准入路径同时打开，说明科研场景正在成为 Anthropic 除企业 Agent 之外重点投入的第二条产品线（详见 [claude-models](/topics/claude-models)）。
- **分类**：其他（产品/访问计划）
- **关联 Topic**：[claude-models](/topics/claude-models)
- **来源**：https://www.anthropic.com/news/expanding-support-for-scientists
