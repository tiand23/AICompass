# 2026-09-21

## LangChain 发布 Jev：取代 LLM-as-judge 的专用结构化判定模型，正式接入 LangSmith Evals

- **一句话总结**：LangChain 把此前预告的"Jev-as-a-Judge"（09-20 首发）正式接入 LangSmith Evals——Jev 不是又一个 LLM judge，而是直接输出类型化判定结果（而非生成文本）的专用评估模型；官方实测：对同一组 500 条真实 Agent 决策重复判定，Jev 与人工评审结果全部一致，连续型质量评分的方差比 GPT-5.6 Luna/Terra 与 Claude Sonnet 4.6 低 92～913 倍，平均每次判定仅 0.44 秒、$0.00035，整组测试总成本 $0.34（Claude Sonnet 4.6 做同样判定要 $28.17）。
- **为什么重要**：延续 08-18 LangSmith Tuned Evaluators（Perceived Error 评估器）"专用裁判模型替代前沿模型做评估"的思路，但这次直接给出了与人工基线完全吻合的一致性数据和两个数量级的成本/延迟优势——如果这类结果能在更多场景复现，"用前沿 LLM 当 judge"在高吞吐量/在线评估场景可能不再是默认选项；但也要警惕 VentureBeat 等报道指出的新风险：结构化判定模型同样可能被 prompt injection 影响裁决结果。
