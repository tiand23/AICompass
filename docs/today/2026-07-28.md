## Google 扩展 Gemini API Managed Agents：3.6 Flash 默认、执行 Hooks 与预算控制

- **一句话总结**：Gemini API Managed Agents 一批更新：默认模型升至 Gemini 3.6 Flash（可显式选 3.5 Flash / Flash-Lite 换性价比）；新增沙箱内 pre/post 执行 hooks（command 或 HTTP handler，可拦截、lint、审计工具调用与文件写入）；`max_total_tokens` 预算护栏防任务失控（中断可带新预算续跑）；cron 定时触发（沙箱持久复用）、Environments API 管理沙箱会话，并开放免费层。
- **为什么重要**：托管 Agent 运行时的"生产化三件套"（hooks 验证管线、预算护栏、定时任务）在 Google 平台补齐——从"能跑 Agent"走向"可运维的 Agent"，与 Claude Managed Agents 的工程化路线正面对齐；沙箱内执行校验的 hooks 设计对自建运行时也有参考价值。
- **分类**：Agent
- **关联 Topic**：[cloud-agent-platforms](/topics/cloud-agent-platforms)
- **来源**：https://blog.google/innovation-and-ai/technology/developers-tools/expanding-managed-agents-gemini-api-3-6-flash-hooks/
