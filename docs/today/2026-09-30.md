# 2026-09-30

## Claude Sonnet 4.5 宣布退役，2026-11-30 停止服务

- **一句话总结**：Anthropic 正式宣布 `claude-sonnet-4-5-20250929` 退役时间表，2026-11-30 停止服务，建议用户迁移到 09-28 刚发布的 Claude Sonnet 5.5。
- **为什么重要**：两个月的迁移窗口是 Anthropic 近期模型退役的典型节奏（对照 08-05 Opus 4.1 退役），使用固定模型 ID 的集成方需要把这个日期排进维护计划；叠加 09-22/09-28 接连发布的 Opus 5.5、Sonnet 5.5，Claude 模型线的新旧更替在这个月内集中发生。
