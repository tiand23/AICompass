# 2026-08-17

## Google 正式关停 Imagen 4 三档生成端点，全面转向 Gemini 原生图像模型

- **一句话总结**：Google 于 2026-08-17 正式关停 Gemini API 侧的 Imagen 4 三个生成端点（`imagen-4.0-generate-001`、`imagen-4.0-fast-generate-001`、`imagen-4.0-ultra-generate-001`），引导调用方迁移到 Gemini 3.1 Flash Image；Imagen 4 此前已于 2026-03-24 在 Vertex AI 侧弃用，这次是 Gemini API 侧的最终下线。官方特别说明这不是无缝替换——原来的 `generate_images()` 方法整体消失，调用方需要按 Gemini 原生图像生成 API 的调用方式重写，而不是简单换个模型名字。
- **为什么重要**：这是"独立专用生成模型线并入通用多模态旗舰"这条产品收敛路径的又一例——此前 OpenAI 把独立浏览器产品 Atlas 并入 ChatGPT/Codex，现在 Google 把独立的图像生成模型线 Imagen 并入 Gemini 原生多模态能力，同一收敛逻辑在不同厂商、不同产品形态上反复出现：与其维护一条独立技术栈+独立品牌，不如把能力整合进旗舰模型统一迭代。对正在用 Imagen API 的团队，这不是一次可以延后处理的模型升级，而是一次有明确截止日期、且调用接口发生破坏性变化的强制迁移，需要提前规划测试。
