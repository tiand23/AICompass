## LangChain 发布 ReviewBench：用真实 PR 评审意见评测代码评审 Agent

- **一句话总结**：ReviewBench 从 LangSmith 代码库的真实 PR 评审意见中人工筛选出实质性问题，构建成 59 个 Harbor 格式任务，用 LLM-as-judge 比对 Agent 提交与人工基线，以覆盖率 + 精确率（F1）评测代码评审 Agent。
- **为什么重要**：当前模型用基础 prompt 只能找回约 30% 的人工基线问题——代码评审 Agent 远未饱和；而同一模型换上强调系统性分析的结构化评审 prompt 后分数明显提升，说明"评审策略"本身就是可优化变量，不必坐等更强的模型。
- **分类**：Evaluation
- **关联 Topic**：[ai-code-review](/topics/ai-code-review) ・ [agent-evaluation](/topics/agent-evaluation)
- **来源**：https://www.langchain.com/blog/evaluating-code-review-agents-with-reviewbench

## OpenAI 为 GPT-Live 音频加入 SynthID 水印并开放验证 API

- **一句话总结**：GPT-Live（ChatGPT Voice 与 API）生成的受支持音频开始嵌入 SynthID 水印；OpenAI 的公开验证工具可检测音频中的来源信号（C2PA 元数据 + SynthID），并新增验证 API 供第三方把来源核查接进自己的流程。
- **为什么重要**：OpenAI 采用 Google 的 SynthID 而非自研方案，意味着 AI 内容水印正向跨厂商事实标准收敛；验证 API 则把"这段内容是不是 AI 生成的"变成可编程能力——内容平台与企业合规流程可以直接集成，语音伪造检测第一次有了官方级接口。
- **分类**：其他
- **关联 Topic**：[content-provenance](/topics/content-provenance) ・ [openai-models](/topics/openai-models)
