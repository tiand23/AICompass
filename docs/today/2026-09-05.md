# 2026-09-05

## GPT-6 Astra 登陆 Microsoft Foundry：Limited Access Program、仅 Global/美国数据区、无欧盟区

- **一句话总结**：微软宣布 GPT-6 Astra（09-03 正式发布）在 Microsoft Foundry（Azure 渠道）上线，通过 Limited Access Program 分批开放，目前只有 Global 与美国数据区可购买，**没有欧盟数据区**。定价：Global 标准档输入 $10～输出 $75 每百万 token（按上下文长度分档），美国数据区有溢价（$11～$82.50）；支持 Standard（按量付费）与 Provisioned Throughput（专属吞吐量）两种购买方式。核心能力：Agentic Execution（开放式目标的结构化规划+动态执行）、Computer Use（解析可视化界面操作没有 API 的老旧应用）、按企业模板生成技术报告/表格/幻灯片。安全集成 Microsoft Entra 身份管理、加密、专用网络与全量操作日志。
- **为什么重要**：这是 09-03 GPT-6 Astra 发布公告里"未来几天将开放 Azure/AWS"的具体落地，也是继 08-31 xAI Grok 4.6 之后 Foundry 又一次"多厂商模型集市"策略的印证——但这次附带了明确的地域限制（无欧盟区）和分批准入（Limited Access Program），说明 Critical 级网络安全定级不仅约束了 OpenAI 自己的发布节奏，也直接传导进了云厂商侧的准入策略，企业选型时需要把"能不能在自己的数据区买到"作为前提条件核实，而不能假设新模型上了 Foundry 就等于随处可用（详见 [cloud-agent-platforms](/topics/cloud-agent-platforms)）。
