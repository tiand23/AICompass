# Content Provenance

## 简介

AI 内容来源标识与验证：通过水印（如 Google SynthID）和签名元数据（C2PA 标准）标记 AI 生成内容，并提供检测工具/API 验证一段内容是否出自 AI。2026 年的关键进展是跨厂商收敛——OpenAI 也采用 Google 的 SynthID 并加入 C2PA，水印开始从各家自研走向事实标准。

## 为什么重要

生成内容（图像、音频、视频）逼真度已越过人眼/人耳可辨阈值，伪造检测从"研究问题"变成"合规刚需"。对开发者的实际意义在于验证 API 的出现：内容平台、企业合规流程可以把"是否 AI 生成"作为可编程检查项接进自己的 pipeline，而不是依赖第三方检测服务的猜测。

## 核心概念

- **水印（SynthID）**：生成时嵌入人耳/人眼不可感知的信号，对裁剪、压缩等常见变换有一定鲁棒性；Google 提出，OpenAI 2026 年采用，覆盖图像与音频。
- **文本水印（Claude）**：路线与图像/音频水印本质不同——不嵌入独立信号，而是改写生成时低风险词语选择所用的随机数来源，用密钥+前文共同决定词语倾向；单次选择不可辨，长文本可统计探测。文本的离散、低维特性决定了它没有音视频那种可藏水印的"冗余信号空间"，因此走了完全不同的技术路径。
- **签名元数据（C2PA）**：内容凭证（Content Credentials）行业标准，在文件元数据中记录生成来源与编辑历史；可被剥离，与水印互补。
- **验证工具与 API**：如 OpenAI 的公开验证工具，检查上传文件中是否含 OpenAI 来源信号（C2PA + SynthID），支持图像与音频，并提供 API 供程序化集成。
- **局限**：水印只覆盖"配合的生成方"——开源模型或不加水印的服务生成的内容检测不到；来源验证是"阳性可信"，阴性不代表非 AI。Claude 文本水印同样非决定性检测器：旧模型生成、大幅编辑、改写、翻译或与其他文字混合的内容可能检测不到。

## 最佳实践

- 平台侧接验证 API 时按"阳性可信、阴性不定"设计策略，别把"未检出水印"当成"人类创作"的证据。
- 自建生成服务对外输出时主动附 C2PA 凭证，成本低且是合规趋势方向。
