# Agent Evaluation

## 简介

Agent 评估：衡量 Agent 在多步骤、有真实副作用的任务上表现的方法与基准。与传统模型基准（一问一答对分数）不同，Agent 评估要面对轨迹不唯一、结果多样、任务开放的难题，当前主流做法是"真实任务样本 + LLM-as-judge 比对基线"。

## 为什么重要

Agent 能不能上生产，最终由评估说了算——没有可复现的评估，改 prompt、换模型、调工具都是盲调。评估基准也是行业的"进度条"：如 ReviewBench 显示当前模型只能找回约 30% 的人工评审基线问题，说明代码评审 Agent 远未饱和，也量化了改进空间在哪。

## 核心概念

- **真实任务派生基准**：从生产数据（真实 PR 评审意见、真实工单）筛选出实质性样本构建任务，比合成任务更能反映实际水平（ReviewBench 的做法）。
- **覆盖率 vs 精确率**：Agent 评估的两个基本轴——找没找全（coverage）与报得准不准（precision），通常以 F1 为综合分；对评审类 Agent 尤其关键，误报直接消耗用户信任。
- **LLM-as-judge**：用模型比对 Agent 输出与人工基线是否命中同一问题（语义等价而非字面匹配），是开放式任务评分的主流方案，需注意 judge 本身的偏差。
- **策略是变量**：同一模型换评估目标明确的结构化 prompt，分数可显著提升——评估应把"模型 + 策略"作为整体对象，而非只测模型。
- **垂直领域基准由该领域头部厂商亲自构建**：Harvey LAB（法律，24 个执业领域、1,671 任务）延续了 ReviewBench（代码评审）的模式——由深耕该领域的公司自建全通过细则的真实任务基准，比第三方通用基准更贴近行业深水区的真实表现，这是专业服务型 Agent（法务/财务/医疗）评估的共同路径。
- **大规模真实科研任务作为压力测试**：ICML 2026 可复现性黑客松让 1,221 人用编码 Agent 复现 2,226 篇论文（占会议录用总量 34%）的核心主张，用自动化裁判模型统一判定"已验证/被证伪/仅玩具规模/无法判定"——是"真实任务派生基准"方法论在开放式科研复现场景的极限规模样本，量化基线为 51% 论文至少一条主张验证通过、23% 被证伪或存疑；结论强调最可靠结果来自人在回路，而非 Agent 完全自主判定。
- **专用裁判模型替代前沿模型做评估**：与其自建 LLM-as-judge，评估工具链厂商可以直接把"专门训练过的判断模型"做成托管服务——LangSmith Tuned Evaluators 首发的 Perceived Error 评估器，在标注对话数据上做专门后训练，判断准确度超过所有前沿模型，同时成本降低 82%（部分场景达 98%）；"垂直场景不需要前沿智能"这条效率哲学延伸到了评估工具本身。
- **基准"刷分"（benchmaxxing）检测**：模型在公开基准上高分不代表任务能力真的强，可能是学会了识别"自己身处哪个基准"进而复现基准特有模式；参考分歧、遮蔽实体恢复率、拼写惯例选择等探针可用来检测这种数据集指纹识别行为（ASR 领域的具体方法论，参见 [voice-agents](/topics/voice-agents)）。

## 最佳实践

- 评估集优先从自己的真实失败案例里建，通用基准分数与自己场景的相关性往往有限。
- 把 prompt/策略纳入被评估对象做 A/B，很多"模型不行"其实是策略不行。

## Timeline

### [2026-08-21](/today/2026-08-21)

HuggingFace 提出 ASR 基准"刷分"检测方法论：参考分歧探针、遮蔽实体检索、拼写切换三种探针发现部分语音识别模型存在"数据集指纹识别"行为而非单纯提升转录能力——为"基准分数是否反映真实能力"这一评估领域的核心质疑首次在语音识别垂直领域提供可复现检测方法（详见 [voice-agents](/topics/voice-agents)）。

### [2026-08-18](/today/2026-08-18)

LangSmith 推出 Tuned Evaluators（调优评估器）托管服务：首发 Perceived Error 评估器，在标注对话式 Agent trace 上专门后训练，判断准确度超过所有前沿模型且成本降低 82%（部分客户工作负载达 98%）；线程需满足最少两轮人类-AI 消息对，评估在 12 小时内完成，仅成功执行计费。

### [2026-08-13](/today/2026-08-13)

HuggingFace 公布 ICML 2026 可复现性黑客松结果：1,221 名参与者用 Claude Code、Codex、Cursor 等编码 Agent 尝试复现 2,226 篇论文核心主张，产出 6,816 份复现记录、35,908 条主张判定——51% 的被检验论文至少一条主张验证通过，23% 有主张被证伪或存疑，266 篇全部通过；Agent 存在陷入循环、误读规模依赖行为等局限，最可靠结果来自人在回路（详见 [coding-agents](/topics/coding-agents)）。

### [2026-08-09](/today/2026-08-09)

Harvey 开源 Harvey LAB：法律 Agent 基准，24 个执业领域、1,671 个真实任务（含 M&A 数据室场景），全通过细则评分 + LLM judge——"真实任务派生基准"方法论在法律这一高专业度垂直领域的落地，由领域头部厂商亲自构建。

### [2026-08-04](/today/2026-08-04)

LangChain 提出语音 Agent 三轴评测框架：执行（工具调用/流程正确性）、结果（业务达成）、体验（延迟/打断/自然度）——语音场景把"体验"从软性感受变成了独立评测轴（详见 [voice-agents](/topics/voice-agents)）。

### [2026-07-31](/today/2026-07-31)

LangChain 发布 ReviewBench：59 个由 LangSmith 真实 PR 评审意见派生的任务，LLM-as-judge 比对基线，F1 计分。基础 prompt 下模型只找回约 30% 基线问题；结构化评审 prompt 显著提分。
