# World Models

## 简介

世界模型 / 生成式仿真：学习环境动态并实时生成逼真的模拟环境，用于机器人训练、验证与合成数据生产。代表系列如 NVIDIA Cosmos。

## 为什么重要

生成式仿真正在成为具身智能与机器人开发的基础设施——真实数据昂贵且危险的领域（如医疗）尤其依赖它。垂直落地案例（如手术机器人）是该方向从演示走向生产的信号。

## 核心概念

- **生成式仿真**：用生成模型实时产生环境反馈，替代手工建模的仿真器。
- **合成训练数据**：仿真环境产出的数据用于训练下游策略模型。
