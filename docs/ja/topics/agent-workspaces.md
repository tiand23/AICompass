# Agent Workspaces

## 概要

エージェントワークスペース：「エージェントに作業環境を与える」ことを中心としたデスクトップ/ローカルアプリの形態——ユーザーは 1 つのインターフェースでエージェントにタスクを割り当て、サービスを接続し、能力（skills/MCP）を装備させ、エージェントは制御された環境で長時間自律的に働く。代表製品：Anthropic の Claude Cowork（ナレッジワーク向け）、OpenAI の Codex アプリ、オープンソース側の openwork（opencode ベース）。

## なぜ重要か

エージェントワークスペースは「チャット UI」の次の対話形態：一問一答から「仕事を任せて成果物を受け取る」への転換。オープンソース代替（openwork が日次 +796 スターで Trending 入り）の迅速な登場はこの形態が実証済みであることを示す。さらに openwork が「同一の skills・MCP・接続サービスをツール横断・チーム横断で再利用」を中核の売りにしたことは、マルチツール時代の本当の痛点を言い当てている——能力設定は単一ツールの私有資産から可搬資産へ変わりつつある。

## コアコンセプト

- **ワークスペース vs コーディングツール**：コーディングツール（Claude Code/Cursor）はコードベース中心。ワークスペースはタスクと接続サービス中心で、非コーディングのナレッジワークをカバー。
- **能力設定の可搬性**：skills、MCP サーバー、アカウント接続を独立した資産レイヤーとして、統一アクセスポイント（openwork MCP など）経由で複数のエージェントクライアント間で共有。
- **組織レベルの管理プレーン**：チーム単位の推論供給、アクセス管理、skill 配布、ポリシー制御（openwork の Den）——企業向けエージェントプラットフォームの管理プレーンと同じ発想。
