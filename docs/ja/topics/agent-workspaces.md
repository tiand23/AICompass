# Agent Workspaces

## 概要

エージェントワークスペース：「エージェントに作業環境を与える」ことを中心としたデスクトップ/ローカルアプリの形態——ユーザーは 1 つのインターフェースでエージェントにタスクを割り当て、サービスを接続し、能力（skills/MCP）を装備させ、エージェントは制御された環境で長時間自律的に働く。代表製品：Anthropic の Claude Cowork（ナレッジワーク向け）、OpenAI の Codex アプリ、オープンソース側の openwork（opencode ベース）。

## なぜ重要か

エージェントワークスペースは「チャット UI」の次の対話形態：一問一答から「仕事を任せて成果物を受け取る」への転換。オープンソース代替（openwork が日次 +796 スターで Trending 入り）の迅速な登場はこの形態が実証済みであることを示す。さらに openwork が「同一の skills・MCP・接続サービスをツール横断・チーム横断で再利用」を中核の売りにしたことは、マルチツール時代の本当の痛点を言い当てている——能力設定は単一ツールの私有資産から可搬資産へ変わりつつある。

## コアコンセプト

- **ワークスペース vs コーディングツール**：コーディングツール（Claude Code/Cursor）はコードベース中心。ワークスペースはタスクと接続サービス中心で、非コーディングのナレッジワークをカバー。
- **独立ブラウザエージェント製品の存続リスク**：OpenAI の Atlas（独立ブラウザ + Agent モード）は 1 年足らずで終了し、能力は ChatGPT/Codex に統合された——既存の主力入口にエージェント能力を組み込む方が、独立した新形態製品を作るより価値を実証しやすい。この「新形態をまず試し、後で統合する」路線は現在のプラットフォームベンダーによく見られる。
- **能力設定の可搬性**：skills、MCP サーバー、アカウント接続を独立した資産レイヤーとして、統一アクセスポイント（openwork MCP など）経由で複数のエージェントクライアント間で共有。
- **組織レベルの管理プレーン**：チーム単位の推論供給、アクセス管理、skill 配布、ポリシー制御（openwork の Den）——企業向けエージェントプラットフォームの管理プレーンと同じ発想。
- **単一エージェントワークスペースからマルチエージェントチーム管理へ**：openwork が解決するのは「1 人に 1 つのエージェント作業環境を与える」こと、Paperclip が代表する新しい層が解決するのは「1 つのチームに丸ごと 1 部隊のエージェントを与える」こと——チケット割当、組織構造、予算、承認フロー。メンタルモデルは「エージェントに作業環境を与える」から「従業員のように一群のエージェントを管理する」へ進化している。
- **複数 Agent の並走と記憶共有**：holaOS は Claude Code、Codex など複数の Agent を切り替えることなく同じワークスペースで並走させ、同じ記憶を共有する——記憶はベンダー独自のクラウド形式ではなくユーザーが読み書きできる平文ファイルとして保存され、「記憶は監査可能で単一ベンダーにロックインされるべきではない」という原則をワークスペース製品層で具体的に実装している。

## Timeline

### [2026-08-12](/ja/today/2026-08-12)

holaOS がオープンソース化（累計 6.2k スター）：「あなたとあなたの Agent のためのコンピュータ」——Claude Code/Codex/ネイティブ Agent が 1 つのワークスペースで並走し、平文のローカル記憶を共有；100+ 連携 + MCP、内蔵モデルと BYOK。複数 Agent の並走と Agent 横断の記憶共有がワークスペース製品の新たな差別化要因に。

### [2026-08-10](/ja/today/2026-08-10)

Paperclip が登場（累計 7.62 万スター）：オープンソースの「エージェントチーム人事管理」プロダクト——チケット追跡、組織構造、予算強制、ガバナンス承認、監査ログ。フレームワークもオーケストレーションもせず、管理プレーンに徹する。ワークスペース形態が「1 人 1 エージェント」から「チームが一部隊のエージェントを管理する」へ拡張（詳細は [enterprise-ai-agents](/ja/topics/enterprise-ai-agents)）。

### [2026-08-09](/ja/today/2026-08-09)

OpenAI が独立ブラウザ製品 Atlas を終了し、ブラウザエージェント能力を ChatGPT デスクトップアプリと Codex に統合——「独立した新形態製品」が 1 年足らずで「既存主力製品への組み込み」に道を譲った（詳細は [openai-models](/ja/topics/openai-models)）。

### [2026-08-01](/ja/today/2026-08-01)

openwork が GitHub Trending 入り（日次 +796、累計 19.5k スター）：opencode ベースの Claude Cowork オープンソース代替。MCP 1 つで任意クライアントに接続し同一の skills/MCP/接続を再利用、組織管理プレーン Den 付き。
