# AI Code Review

## 概要

LLM / エージェントによるコードレビューのツールとアーキテクチャパターン。現在の主流設計は「決定論的パイプライン + LLM エージェント」のハイブリッド：ルールで判定できるものはルールで、意味理解が必要なものはモデルに任せる。

## なぜ重要か

コードレビューは AI コーディングツールチェーンの中で最も費用対効果が直接的な工程のひとつ。大手ベンダーの OSS 実装（alibaba/open-code-review など）は、いつルールを信じ、いつモデルを信じ、誤検知をどう制御するかという参照可能なエンジニアリング上の判断を提供する。

## コアコンセプト

- **ハイブリッドアーキテクチャ**：決定論的チェック（lint、ルール）と LLM 意味レビューの分担とオーケストレーション。
- **誤検知の制御**：レビューツールの有用性は S/N 比で決まる。複数検証者による投票、再現性チェックが常套手段。

## 関連技術

- Claude Code / Codex などの AI コーディングツール（レビュー機能内蔵）
- CI 統合（パイプラインの一工程としてのレビュー）

## ベストプラクティス

- AI レビューの導入は「高確信度の問題」（ヌル参照、リソースリーク）から始め、意味系チェックは段階的に開放する——誤検知は信頼を消耗する。
