# AI Code Review

## 概要

LLM / エージェントによるコードレビューのツールとアーキテクチャパターン。現在の主流設計は「決定論的パイプライン + LLM エージェント」のハイブリッド：ルールで判定できるものはルールで、意味理解が必要なものはモデルに任せる。

## なぜ重要か

コードレビューは AI コーディングツールチェーンの中で最も費用対効果が直接的な工程のひとつ。大手ベンダーの OSS 実装（alibaba/open-code-review など）は、いつルールを信じ、いつモデルを信じ、誤検知をどう制御するかという参照可能なエンジニアリング上の判断を提供する。

## コアコンセプト

- **ハイブリッドアーキテクチャ**：決定論的チェック（lint、ルール）と LLM 意味レビューの分担とオーケストレーション。
- **誤検知の制御**：レビューツールの有用性は S/N 比で決まる。複数検証者による投票、再現性チェックが常套手段。
- **能力ベースライン**：ReviewBench（実 PR レビューコメント由来のベンチマーク）によれば、現在のモデルは基本プロンプトで人間ベースラインの約 30% しか回収できない。構造化レビュープロンプトでスコアは顕著に向上——戦略はモデルと同じくらい重要。
- **全文読み取りの代わりにコードグラフ**：Tree-sitter でコードベースを関数/クラス/呼び出し関係の構造化グラフに解析し、レビュー時はファイルツリー全体を読む代わりに影響範囲（blast-radius）でグラフを問い合わせる——ナイーブな全文読み取りに比べ約 65 倍のトークン節約を実測（code-review-graph の事例）。レビューのスケール化における鍵となるコスト削減策。
- **軽量ローカルストレージ vs グラフデータベース**：コードグラフの 2 つの実装路線——ローカル SQLite + MCP 問い合わせツール（code-review-graph）は軽量でデプロイが容易；専門のグラフデータベース + 自然言語から Cypher へのクエリ（code-graph-rag、Memgraph 使用）は複雑な多段階の関係クエリをネイティブにサポートするが、追加のインフラ依存というコストを伴う。必要なクエリの複雑さで選定する。

## 関連技術

- Claude Code / Codex などの AI コーディングツール（レビュー機能内蔵）
- CI 統合（パイプラインの一工程としてのレビュー）

## ベストプラクティス

- AI レビューの導入は「高確信度の問題」（ヌル参照、リソースリーク）から始め、意味系チェックは段階的に開放する——誤検知は信頼を消耗する。

## Timeline

### [2026-08-09](/ja/today/2026-08-09)

code-graph-rag が登場（累計 2.7k スター）：Tree-sitter の解析結果を Memgraph グラフデータベースに格納し、関数/クラス/呼び出し/データフローを問い合わせ可能な関係として維持——code-review-graph の軽量ローカル SQLite 路線との対比で、コードグラフというサブ分野のアーキテクチャ選定の具体的なサンプルとなった。

### [2026-08-07](/ja/today/2026-08-07)

code-review-graph が登場（累計 2.9 万スター）：Tree-sitter コードグラフ + ローカル SQLite + 30 個の MCP 問い合わせツールで、全文読み取りを影響範囲分析に置き換え——Flask コードベースのレビュー時のトークン消費が 143,594 から 2,196（71 倍）に、6 リポジトリの中央値は約 65 倍。文書解析の「空間的位置特定」、動画編集の「転写代理」と同じ「低次元構造化代理表現への圧縮」パターンの 3 度目の再来。

### [2026-07-31](/ja/today/2026-07-31)

LangChain が ReviewBench を公開：実 PR レビューコメント由来の 59 タスクでコードレビューエージェントを評価、F1 採点。基本プロンプトではベースラインの約 30% しか回収できない（詳細は [agent-evaluation](/ja/topics/agent-evaluation)）。

### [2026-07-27](/ja/today/2026-07-27)

alibaba/open-code-review が GitHub Trending 日間ランキング上位に（1 日で +980 スター）：決定論的パイプライン + LLM エージェントのハイブリッドレビューツール。
