# 2026-07-22

## OpenAI、Presence を発表：エンタープライズ向け音声/チャット・エージェントプラットフォーム

- **概要**：OpenAI は Presence を発表。社内システムへの照会、承認済みアクションの実行、必要時の人間へのエスカレーションが可能なリアルタイム音声・チャットエージェントを企業が展開できるようにするもので、カスタマーサポート、営業開発、調達、IT、HR が主対象。現在は限定 GA で、OpenAI の Forward Deployed Engineer と SIer が導入を主導し、セルフサービス提供はなし。
- **なぜ重要か**：OpenAI が（API 販売にとどまらず）エンタープライズエージェントのデリバリー事業に正式参入した。「プラットフォーム + 常駐エンジニア」モデルは、企業向けエージェント統合を手がける開発者・ベンダーにとって直接の競合であり参照点でもある。OpenAI 自身の受信サポートリクエストの約 75% を既に同システムが処理しているという。
- **分類**：Agent
- **関連 Topic**：[enterprise-ai-agents](/ja/topics/enterprise-ai-agents)
- **出典**：https://openai.com/index/introducing-openai-presence/

## Claude Managed Agents の API アップデート一式

- **概要**：Managed Agents でエージェントのモデル設定に effort レベルを指定可能に。webhook が environment と memory store のライフサイクルをカバー（新イベント 7 種）。セッション作成時に `initial_events` で初期イベントを投入し、同一コールでエージェントループを開始可能に。エージェント更新時の `version` はオプションに（楽観的並行性制御）。スレッド単位のイベントストリームが event deltas に対応し、サブエージェントの生成をプレビューできるように。
- **なぜ重要か**：いずれも「ホスト型エージェントの運用成熟度」に向かう更新——ポーリング不要のライフサイクルイベント、1 コールでのセッション初期化、細粒度のストリーム観測は、マネージドエージェントランタイムの成熟度を測る具体的なシグナル。
- **分類**：Agent
- **関連 Topic**：[enterprise-ai-agents](/ja/topics/enterprise-ai-agents) ・ [claude-models](/ja/topics/claude-models)
- **出典**：https://platform.claude.com/docs/en/release-notes/overview
