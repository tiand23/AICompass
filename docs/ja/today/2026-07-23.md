## LangChain、Deep Agents のベンチマーク手法を公開

- **概要**：LangChain が「How We Benchmark Deep Agents」を公開し、Deep Agents（長期・多段階の自律タスクをこなすエージェント）の性能評価手法を解説した。
- **なぜ重要か**：長期タスクエージェントの評価は公知の難問——単発ベンチマークでは計画立案・ツール利用・エラー回復の能力を測れない。主要フレームワークベンダーが自らの評価手法を公開することは、独自のエージェント評価体系を構築するチームに直接役立つ。
- **分類**：Evaluation
- **関連 Topic**：なし（deep-agents を観察中）
- **出典**：https://www.langchain.com/blog/

## Nunchaku の 4-bit 拡散モデル推論が Diffusers に統合

- **概要**：HuggingFace が Nunchaku の 4-bit 量子化推論技術を Diffusers ライブラリに統合し、効率的な画像生成を可能にしたと発表。
- **なぜ重要か**：主要ライブラリが 4-bit 拡散推論をネイティブサポートしたことで、画像生成の VRAM・コストの敷居がさらに下がり、コンシューマー GPU で大型拡散モデルを動かす現実性が高まった。
- **分類**：Deployment
- **関連 Topic**：なし
- **出典**：https://huggingface.co/blog
