## テンセントクラウドが TencentDB-Agent-Memory を公開：チームレベルのエージェント記憶ハブ

- **概要**：TencentDB-Agent-Memory（TypeScript）が 1 日で +602 スター（累計 11k）——会話・ドキュメント・コードを 4 種類の再利用可能な記憶資産に変換する：階層化 Chat Memory（L0 生会話 → L3 ペルソナ）、エージェントの対話から抽出する Skills（バージョン管理、チームレビュー後に共有）、構造化 Wiki（リンクグラフ付き）、コードシンボルと呼び出し関係を索引する CodeGraph。資産は RBAC 可視性（private/team/restricted/agent）を持ち、グローバル注入ではなくエージェントごとの loadout として紐付け。OpenClaw、hermes-agent などのフレームワークと統合済み。
- **なぜ重要か**：エージェント記憶が「単一ユーザーのセッションコンテキスト」から「チーム共有の資産レイヤー」へ格上げされつつある——4 種の資産（記憶/スキル/知識/コードグラフ）は記憶インフラの完全な参照アーキテクチャを示した。さらに「対話から skill を自動抽出しレビュー後に共有」は skill の生産工程を記憶パイプラインに組み込むもので、記憶と能力エコシステムが合流し始めている。
- **分類**：Agent
- **関連 Topic**：[agent-memory](/ja/topics/agent-memory) ・ [agent-skills](/ja/topics/agent-skills)
- **出典**：https://github.com/TencentCloud/TencentDB-Agent-Memory

## Agent-Reach が GitHub Trending に：エージェントに「ネット接続能力」を持たせる CLI 能力レイヤー

- **概要**：Agent-Reach（Python）が 1 日で +659 スター（累計 64.7k）——プラットフォームごとの API キー不要で、X、Reddit、YouTube、GitHub、Bilibili、小紅書、Instagram、LinkedIn、RSS などの読み取りと検索をエージェントに提供。yt-dlp、Jina Reader などの成熟した CLI ツールを再利用（一部サービスは MCP 経由）し、各プラットフォームに「主要メソッド + フォールバックリスト」を設定、経路が壊れると自動で切り替える。Claude Code、Cursor など CLI 実行可能なクライアントに対応。
- **なぜ重要か**：MCP の「プロトコル標準化」と相互補完のもう一つのエンジニアリング路線——プロトコルのラッパーを書かず、既存 CLI ツールの再利用にヘルスチェックとフォールバックルーティングを加える。解決するのは「アンチスクレイピングと API 変更でツールが毎日壊れる」という運用の現実。「エージェントがコンテンツプラットフォームに触達する」レイヤーのエンジニアリング化が形になりつつある。
- **分類**：Agent
- **関連 Topic**：[mcp](/ja/topics/mcp)
- **出典**：https://github.com/Panniantong/Agent-Reach
