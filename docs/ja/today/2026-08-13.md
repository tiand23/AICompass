## Google が Gemini 3.7 Flash を発表：前モデルからわずか 3 週間、コーディング/Agent ベンチマークが大幅向上、価格は半額に

- **概要**：Google が Gemini 3.7 Flash を発表した——3.6 Flash からわずか 3 週間後のリリースで、「コーディング、Web 開発、知識労働、Agent ワークフロー向けの高速ワークホースモデル」と位置づけられる。コーディング/Agent 関連ベンチマークが大幅に向上：DeepSWE v1.1 が 49.0% から 65.3% へ、AutomationBench が 17.0% から 30.4% へ、WebDev Arena Elo が 1538 から 1588 へ。導入価格は API 入力 $0.75／100 万トークン、出力 $3.75／100 万トークンで、3.6 Flash のローンチ価格の半額（標準価格 $1.50／$7.50 は 2027-01-01 から適用）。3.5 Pro は発表されなかった。
- **なぜ重要か**：3 週間というリリース間隔そのものがシグナルだ——Google は Flash ティアにおいて「大きな飛躍を待つ」のではなく「頻繁で段階的な向上」を明確に選んでおり、本ナレッジベースが以前記録した「3.5 Pro を飛ばして Flash に直行する」戦略と一貫している。コーディング/Agent 系ベンチマークの向上幅（AutomationBench はほぼ倍増）は、汎用対話系ベンチマークよりも重要な意味を持つ——それは Flash が「Agent ワークフローのワークホース」として位置づけられていることの直接的な能力の証拠だからだ。導入価格の半額化は「より安く、より効率的に」という Flash シリーズ一貫の戦略を継続するもので、コスト重視シナリオのモデル選定にまた 1 つ有力な候補を加える。

## HuggingFace：2,226 件の ICML 論文をコーディング Agent が複現、51% は少なくとも 1 件の主張が検証成功

- **概要**：HuggingFace が、2026-07-15～08-02 に開催した ICML 2026 可復現性ハッカソンの結果を公開した：1,221 名の参加者が Claude Code、Codex、Cursor などのコーディング Agent を使い、当該会議の採択論文 6,352 件のうち 2,226 件（全体の 34%）の複現を試みた。プロセスは、論文要旨から核心的な主張を抽出し、参加者 1 人あたり 20 ドルの計算クレジットで Agent 主導の実験を実行、結果を監査可能な静的ページ「Trackio logbook」として公開し、自動化された裁判モデル（GLM-5.2）が各主張について「検証済み／反証済み／玩具規模のみ／判定不能」の判定を下すというもの。最終集計：6,816 件の複現記録が公開され、35,908 件の主張が判定された——検証対象となった論文の 51% が少なくとも 1 件の主張を検証済みとされ、23% は主張が反証されたか異論があり、266 件の論文はすべての主張が完全に検証済みとなった。記事は、Agent には依然として限界がある（ループに陥る、規模依存の挙動を誤読するなど）とし、最も信頼できる結果は「人間が主導する」ワークフローから生まれたと結論づける——人間が Agent を導き最終判断を下すのであって、Agent が完全に自律的に判断するのではない。
- **なぜ重要か**：これはこれまでで圧倒的に最大規模かつ最も現実に即した、コーディング Agent 能力の実地検証だ——ベンチマーク問題ではなく、Agent が「論文を読む→コードを書く→実験を実行する→主張を検証する」という研究複現の全工程を、ある会議の論文総量の 3 分の 1 にわたって独立して完遂した。51%/23%/12%（266/2226）という数字は、これまで散発的な事例しかなかった「Agent は研究複現ができるか」という問いに、初めて体系的な定量ベースラインを与えた。「最も信頼できる結果は人間が主導するワークフローから生まれる」という結論も、本ナレッジベースで繰り返し登場してきた設計原則——「読み取りは自律でよいが、（ここでは：結論を下すことは）必ず人間を経由する」——を裏付けている。研究複現のような高リスクな判断シナリオもその例外ではない。
