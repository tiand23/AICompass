# 2026-09-17

## LangChain が Deep Life Sci を発表：臨床・実験室科学者向けのオープンソース Agent harness

- **概要**：LangChain 自社の Deep Agents harness を基盤に、臨床・実験室科学向けのオープンソース Agent「Deep Life Sci」を発表——60 万件以上の ClinicalTrials.gov 臨床試験、2,900 万件の PubMed 抄録、1,200 万件の PubMed Central 全文にアクセスし、PDF・画像・表・RIS 文献ファイル・SMILES/FASTA 配列・RNA-seq 結果・プロテオミクスデータなどの入力に対応、サンドボックス化されたサブエージェントが検索・レビュー・分析を分担、LangSmith が検索・コード実行・レビューした文書・サブエージェントのルーティングから最終回答までの全経路を記録しデバッグと監査に活用できる；オープンソースのため組織は独自データの接続・モデルの差し替え・カスタムガードレールの追加が可能。前日 09-14 には LangChain が Madrigal Pharmaceuticals、Abridge、Vizient のスケーリング事例を既に公開しており、同日 09-17 には Included Health が Deep Agents + LangGraph で連合型医療ナビゲーション Agent を構築した事例も公開——3 本の記事が合わせて、カスタマーサポートや社内業務ツールに続き、ヘルスケア/ライフサイエンスが Deep Agents の次の重点垂直領域になりつつあることを示している。
- **なぜ重要か**：OpenMontage（動画制作）、Harvey LAB（法律）に続き、「オープンな汎用 harness + 垂直領域への深いカスタマイズ」というパターンが、専門性の壁が高いライフサイエンス領域に着地した事例であり、臨床・研究のコンプライアンス要件を満たす必要がある Agent アプリケーションに直接参考になる、監査可能な証拠連鎖の設計を具体的に示している。
- **分類**：Agent
- **関連Topic**：[deep-agents](/ja/topics/deep-agents)・[enterprise-ai-agents](/ja/topics/enterprise-ai-agents)
- **出典**：https://www.langchain.com/blog/agent-harness-life-sciences

## Anthropic が Life Sciences Verification Program の公開ベータを開始：リアルタイム拦截からオフライン行動パターン監視へ

- **概要**：Anthropic が Life Sciences Verification Program（LSVP）のベータ申請を開始——検証済みチームは Fable 系列が薬物発見・研究生物学・臨床開発・製造などの場面でデフォルトで行っているブロックを解除できる。チーム単位で年次更新される Standard Use（大半の生物学研究開発ワークフローをカバー）と、プロジェクト単位で 6 か月間の High-risk Use（Opus 5/Sonnet 5 のライフサイエンス関連ブロックを完全に解除）の 2 段階；執行方式は個別リクエストのリアルタイムブロックから、行動パターン全体を見るオフライン監視へ移行し、フラグが立った行動に関するデータは 30 日間保持される。
- **なぜ重要か**：08-27 に予告されていたライフサイエンス研究者向けアクセスプログラム（米国政府との協力）の正式な製品化であり、二重用途ガードレールが「一律ブロック」から「段階的権限付与＋事後監視」へ進化する流れ（08-07 の分類器再訓練によるきめ細かい調整に続く）のさらなる一歩——サブスクリプション型の信頼と引き換えに中断を減らし、監視コストをオフラインの行動分析側へ移している。
- **分類**：Models
- **関連Topic**：[agentic-safety](/ja/topics/agentic-safety)・[claude-models](/ja/topics/claude-models)
- **出典**：https://www.anthropic.com/news/life-sciences-verification-program
