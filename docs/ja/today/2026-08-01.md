## openwork が GitHub Trending に：Claude Cowork のオープンソース代替

- **概要**：openwork（TypeScript）が 1 日で +796 スター（累計 19.5k）——opencode ベースのオープンソース・クロスプラットフォームなデスクトップ型エージェントワークスペースで、Claude Cowork / Codex の代替を掲げる。openwork MCP を 1 つ Claude Code、Cursor、Codex などの任意クライアントに追加するだけで、同一の skills・MCP・接続サービスをツール横断・チーム横断で再利用でき、組織レベルの管理プレーン Den（推論の供給、アクセス管理、skill 配布、ポリシー制御）も備える。
- **なぜ重要か**：エージェントワークスペースが独立した製品カテゴリになりつつある——Cowork の後をオープンソースが即座に追った。さらに重要なのは「スキルと接続設定のツール横断共有」という設計が、マルチツール時代の本当の痛点を突いていること：skills/MCP 設定は単一ツールの私有資産から可搬な資産へ変わりつつあり、これは skill エコシステムの標準化を逆に加速する。
- **分類**：Agent
- **関連 Topic**：[agent-workspaces](/ja/topics/agent-workspaces) ・ [agent-skills](/ja/topics/agent-skills)
- **出典**：https://github.com/different-ai/openwork

## reverse-skill が GitHub Trending に：初の skill ルーターパック形態

- **概要**：reverse-skill（PowerShell）が 1 日で +612 スター——リバースエンジニアリング/許可済みペネトレーションテスト/セキュリティ研究領域の skill ルーターパック：AI がタスクに応じて対応する専門 skill へ自動ルーティングし、ツールチェーンをオンデマンドで自己構築、自動進化する経験ベースを備える。Claude Code、Kiro、Cursor、Cline などのクライアントに対応。
- **なぜ重要か**：1 週間で 4 つ目の Trending 入り skill プロジェクトであり、初の「skill router」形態——単一領域の skill が内部ルーティングを要するほど増えたとき、skill は単一ファイルの能力パッケージから構造を持つ能力ライブラリ（ルーター + ツールチェーン + 経験ベースの三点セット）へ進化する。また、許可済みセキュリティテストのような高度な専門性と強いプロセス制約を持つ領域が skill 化されたこと自体、能力パッケージ化が深部へ向かうシグナルである。
- **分類**：Agent
- **関連 Topic**：[agent-skills](/ja/topics/agent-skills)
- **出典**：https://github.com/zhaoxuya520/reverse-skill
