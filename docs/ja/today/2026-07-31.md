## last30days-skill が GitHub Trending に：クロスプラットフォーム調査 Skill

- **概要**：last30days-skill（Python）が 1 日で +378 スター——「任意のトピックの直近 30 日を調査する」を能力として封装したエージェント skill。Reddit、X、YouTube、Hacker News、Polymarket、Web を自動横断する。
- **なぜ重要か**：1 週間で 3 つ目の Trending 入り skill プロジェクト（book-to-skill → superpowers → last30days）——しかもこの skill がやることは本ナレッジベースの `/update` と同種：「定期的な調査と総括」が再利用可能な標準能力としてパッケージ化されつつある。skill エコシステムの爆発はトレンドから事実になった。
- **分類**：Agent
- **関連 Topic**：[agent-skills](/ja/topics/agent-skills)
- **出典**：https://github.com/mvanhorn/last30days-skill

## LangChain が ReviewBench を公開：実 PR レビューコメントでコードレビューエージェントを評価

- **概要**：ReviewBench は LangSmith コードベースの実際の PR レビューコメントから実質的な指摘を人手で厳選し、59 個の Harbor 形式タスクを構築。LLM-as-judge でエージェントの提出と人間のベースラインを照合し、網羅率 + 精度（F1）で採点する。
- **なぜ重要か**：現在のモデルは基本プロンプトでは人間ベースラインの約 30% しか回収できない——コードレビューエージェントは飽和にほど遠い。一方、同じモデルでも体系的分析を強調する構造化レビュープロンプトに替えるとスコアが明確に向上：「レビュー戦略」自体が最適化可能な変数であり、より強いモデルを待つ必要はない。
- **分類**：Evaluation
- **関連 Topic**：[ai-code-review](/ja/topics/ai-code-review) ・ [agent-evaluation](/ja/topics/agent-evaluation)
- **出典**：https://www.langchain.com/blog/evaluating-code-review-agents-with-reviewbench

## OpenAI が GPT-Live 音声に SynthID 透かしを導入し検証 API を公開

- **概要**：GPT-Live（ChatGPT Voice と API）で生成される対応音声に SynthID 透かしが埋め込まれるようになった。OpenAI の公開検証ツールは音声内の来歴シグナル（C2PA メタデータ + SynthID）を検出でき、新たに検証 API も提供——第三者が自らのワークフローに来歴チェックを組み込める。
- **なぜ重要か**：OpenAI が自社方式ではなく Google の SynthID を採用したことは、AI コンテンツ透かしがベンダー横断の事実上の標準に収斂しつつあることを意味する。検証 API は「このコンテンツは AI 生成か」をプログラマブルな能力に変えた——コンテンツプラットフォームや企業のコンプライアンスフローが直接統合でき、音声ディープフェイク検出に初めて公式級のインターフェースが生まれた。
- **分類**：その他
- **関連 Topic**：[content-provenance](/ja/topics/content-provenance) ・ [openai-models](/ja/topics/openai-models)
- **出典**：https://openai.com/research/verify/
