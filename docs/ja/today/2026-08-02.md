# 2026-08-02

## OpenAI が「Sign in with ChatGPT」の提供を開始

- **概要**：OpenAI が一部プラグインとパートナーサイト向けに「Sign in with ChatGPT」を beta 提供開始——第一陣は Airtable、GitLab、HubSpot、Notion、Supabase、Vercel。ChatGPT アカウントで少ないステップでパートナーのアカウントを作成/連携し、そのまま ChatGPT や Codex 内でそのサービスを利用できる。パートナーが受け取るのは氏名・メール・プロフィール画像のみで、プラグインのデータアクセス権限は別途の審査と承認が必要。
- **なぜ重要か**：ChatGPT をアイデンティティレイヤーにする一歩——「Sign in with Google」の AI 時代版。開発者にとっては両面がある：接続側は低摩擦の獲得・アカウント連携チャネルを得る一方、OpenAI はエージェントワークフローの上流にもう一つのロックインポイント（アカウント体系）を得る——プラットフォーム依存の評価には身分レイヤーも含める必要が出てきた。
