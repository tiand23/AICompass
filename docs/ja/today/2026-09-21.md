# 2026-09-21

## LangChain が Jev を発表：LLM-as-judge に代わる専用の構造化判定モデル、LangSmith Evals に正式統合

- **概要**：LangChain が前日 09-20 に予告していた「Jev-as-a-Judge」を LangSmith Evals に正式統合——Jev はもう 1 つの LLM judge ではなく、文章を生成する代わりに型付きの判定結果を直接出力する専用の評価モデル。LangChain 自身のテストでは、同一の 500 件の実際の Agent 決定を繰り返し判定させたところ、Jev は全件で人間のレビュアーの判定と一致し、連続的な品質スコアの分散は GPT-5.6 Luna/Terra および Claude Sonnet 4.6 より 92～913 倍低く、1 回あたりの判定は平均 0.44 秒・$0.00035、テスト全体のコストはわずか $0.34（同じ判定を Claude Sonnet 4.6 で行うと $28.17）。
- **なぜ重要か**：08-18 の LangSmith Tuned Evaluators（Perceived Error 評価器）が示した「専用の判定モデルが前沿モデルによる評価に取って代わる」という流れを継承しつつ、今回は人間の基準と完全に一致する大規模な一貫性データを初めて提示した——同様の結果がより広く再現されるなら、高スループット/オンライン評価の場面で前沿 LLM を judge に使うことがデフォルトではなくなる可能性がある；ただし VentureBeat などが指摘するように、構造化判定モデルも prompt injection によって判定が左右されうるリスクには注意が必要。
