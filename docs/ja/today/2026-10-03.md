## Microsoft × Hugging Face が ThinkingBox を発表：Agent の自己申告ではなくデータベースの終状態で企業ワークフローを評価

- **概要**：Microsoft と Hugging Face が共同で ThinkingBox を発表——Agent の最終回答やツール呼び出しの記録を信用せず、Agent がデータベースに残した終状態と副作用を直接検査する；507 件のステートフルな企業業務ワークフローを 18 の LLM 上で実行し、各ワークフローをモデルごとに 20 回繰り返す；核心的な主張は「最終回答」も「正しいツール呼び出し」もあくまで代理指標にすぎず、Agent は正しく聞こえる発言をしながら間違った値を書き込んだり、間違ったレコードを変更したり、余計な副作用を生んだりしうる——残された記録だけが本当に成功したかどうかを決める、というもの。
- **なぜ重要か**：09-29 の ProvenanceGuard（引用元が正しいかの検証）に続き、「Agent 自身が言っていることをそのまま信じない」という方法論を体系化したもう一つの事例——今回は検証対象が「出典の帰属」から「システム状態の実際の変化」へ移り、同じタスクを 20 回繰り返すという設計によって、これまで単独で測定されることが少なかった「安定して成功できるか（運良く一度成功しただけではないか）」という次元を定量化している。
