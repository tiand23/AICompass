# 2026-10-06

## Anthropic が Cyber Verification Program を拡張：3 段階アクセスで高度なサイバー能力を開放

- **概要**：Anthropic が以前の Project Glasswing と元の Cyber Verification Program を統合し、審査済みのセキュリティ専門家に 3 段階のアクセスレベル——Defense Access、Red Team Access、Specialized Access——を開放；各ティアで Claude Opus 5.5、Sonnet 5.5、Mythos 5.1 および将来のモデルにアクセスでき、ティアが上がるほどガードレール分類器が緩和される。Anthropic は、Glasswing のパートナーが 2026 年 4〜7 月に少なくとも 12.9 万件の脆弱性を検証・識別し、オープンソースのスキャンが 4〜10 月にさらに 5,500 件（うち 3.3 万件超が重大/高危険度）を識別したと公表している。
- **なぜ重要か**：OpenAI の Daybreak Blue/Red の 2 段階アクセスモデル（08-10）に続き、「能力が高いほど審査を厳しくする」という段階的アクセスのパターンを Anthropic 側でさらに細分化（2 段階から 3 段階へ）したものであり、「ガードレールを緩めて防御効果を得る」というトレードオフを大規模な実際の効果の定量データ（12.9 万+5,500 件の脆弱性）で初めて裏付けている。
- **分類**：その他
- **関連Topic**：[agentic-safety](/ja/topics/agentic-safety)
- **出典**：https://www.helpnetsecurity.com/2026/10/07/anthropic-expands-cyber-verification-program/

## OpenAI の Decisions API が公開ベータへ：GPT-6 Luna 駆動の構造化判断エンドポイント、入力分のみ課金

- **概要**：OpenAI が 09-29 の DevDay で限定プレビューされた Decisions API を全開発者向けの公開ベータとして開放。このエンドポイントは GPT-6 Luna を、開発者が定義した有限の候補回答を持つ質問群に集中させる——テキストや画像を入力すると、コンテンツ分類・リクエストのルーティング・Agent の次の行動決定に直接使える構造化された回答が返る；Responses API 経由で Luna を直接呼ぶより最大 10 倍速いと OpenAI は説明；価格設定は入力トークンのみに課金され（100 万トークンあたり $0.10）、キャッシュの読み書きと出力トークンは無料、正式 GA は数週間以内を予定。
- **なぜ重要か**：LangChain の Jev（09-21 発表、専用の構造化判定モデル）、LiquidAI の d1（10-07 発表、決定に特化したエッジモデル）と合わせて、「意思決定/判定」が「汎用チャットモデルを呼んでテキストの答えを解析する」から独立した専用モデル品類へ分化するという明確な新潮流を形成している——背景の異なる 3 社（フレームワークベンダー、モデルベンダー、エッジモデルベンダー）が 1 か月のうちにそれぞれ構造的に一致した解法——狭く定義された質問＋型付き出力＋汎用呼び出しよりはるかに低いコスト——に到達した（詳細は [agent-evaluation](/ja/topics/agent-evaluation)）。
- **分類**：Models
- **関連Topic**：[openai-models](/ja/topics/openai-models)・[agent-evaluation](/ja/topics/agent-evaluation)
- **出典**：https://www.unite.ai/openai-releases-decisions-api-in-public-beta-powered-by-gpt-6-luna/

## Google が Gemini Nano Banana 2.1、Gemini Enterprise の Antigravity 管理コントロール、EmbeddingGemma 2 を同日発表

- **概要**：Google が 1 日で 3 つの更新を発表——**Gemini Nano Banana 2.1**：Flash レベルの速度とコストを維持したまま、視覚品質、prompt への忠実度、複数ターンにわたるキャラクターの一貫性、テキストレンダリング、ワイド/パノラマアスペクト比生成を改善した画像生成/対話的編集モデル；**Gemini Enterprise の Antigravity 管理コントロール**：企業の管理者が Antigravity の Boost（複雑なアルゴリズム課題や深いデバッグタスクを解く階層型マルチ Agent 構成、GA 済み）と Teamwork（大規模・長時程プロジェクトを実行する協調的な自律サブエージェント群、プレビュー段階）の利用範囲を中央管理できるようになった；**EmbeddingGemma 2**：Gemma 4 を基盤とする 7.4 億パラメータのオープンな多モーダルオンデバイス埋め込みモデル（Apache 2.0）で、2.7 億パラメータのテキスト/コード基盤 + 1.7 億の視覚エンコーダ + 3 億の音声エンコーダにより、テキスト・コード・画像・音声・動画を同一のベクトル空間に統合してマッピングする；量化後の完全版は Pixel 11 Pro 上で約 567MB のメモリ（テキストのみの部分は 191MB）で動作し、コンテキストウィンドウは 8,192 トークン（前世代の 4 倍）、MTEB Code や MAEB などのベンチマークで 10 億パラメータ未満の多モーダル埋め込みモデルをリードする。
- **なぜ重要か**：3 つの更新はそれぞれ生成、Agent プラットフォームのガバナンス、検索基盤という異なる系列をカバーする——特に EmbeddingGemma 2 は注目に値する：プライバシー優先でオフライン利用可能な多モーダルセマンティック検索/RAG 能力を、コンシューマー向けハードウェアが許容できるメモリ容量に収めた、「オンデバイスの小型モデルで垂直的な能力をカバーする」という効率化路線の、RAG の中核をなす埋め込み/検索という工程における具体的な事例である；Antigravity の管理コントロールは「企業向け Agent 機能にガバナンスのスイッチを付ける」という発想の Google 版の実装である（詳細は [rag](/ja/topics/rag) ・ [cloud-agent-platforms](/ja/topics/cloud-agent-platforms) ・ [diffusion-models](/ja/topics/diffusion-models)）。
- **分類**：Models
