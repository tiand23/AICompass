# 2026-09-22

## Claude Opus 5.5 発表：長時程のコーディングと知的業務向け、適応的思考が常時オン

- **概要**：Anthropic が Claude Opus 5.5 を発表、長時程の Agent コーディングと知的業務に照準を合わせる：デフォルトかつ最大となる 100 万トークンのコンテキストウィンドウ、12.8 万の最大出力トークン、適応的思考が常時オン（`thinking: disabled` は 400 エラーを返す）；価格は 100 万トークンあたり $4/$20；Claude API、Amazon Bedrock、AWS/Google Cloud 上の Claude Platform、Microsoft Foundry で同時提供。破壊的な API 変更：`tool_choice` の `any`/`tool`（強制ツール呼び出し）は 400 を返すようになった；コンピュータ使用ツールはアップグレード版の `computer_toolset_20260801` が必須（旧版の `computer_20251124` は受け付けなくなった）。同日、Fast Mode のリサーチプレビュー（Opus 5.5 専用）と Inline Tools のベータ（会話途中の system メッセージでツールを定義可能）も公開。
- **なぜ重要か**：09-01 の Fable 5.1/Mythos 5.1 に続く Anthropic 今月 2 回目のモデルライン更新であり、Opus 階層自体の世代交代でもある（7 月の Opus 5 に続く）；適応的思考を必須化し手動での強制ツール呼び出しを廃止したことは、「手作業の prompt チューニングを effort/thinking メカニズムに置き換える」という製品哲学の延長線上にあるが、同時に旧版の `tool_choice` や旧バージョンのコンピュータ使用ツールに依存する統合先は改修が必要になる。
- **分類**：Models
- **関連Topic**：[claude-models](/ja/topics/claude-models)
- **出典**：https://platform.claude.com/docs/en/release-notes/overview

## GPT-6 Astra/Sol/Luna と Claude Opus 5.5 が同日に Microsoft Foundry に登場

- **概要**：Microsoft Foundry が同日に 2 つのモデルラインを追加——本番 Agent 向けの GPT-6 Astra/Sol/Luna 全系列（OpenAI）と、発表されたばかりの Claude Opus 5.5（長時程のコーディングと知的業務向け）——いずれも Foundry 統一のモデル評価/デプロイ/ガバナンス管理面に組み込まれた。
- **なぜ重要か**：「プラットフォームがモデルに先行する」「マルチベンダーモデルマーケットプレイス」戦略の継続（これまでの Grok 4.6 や GPT-6 Astra の限定提供に続く）だが、今回は新モデルが発表された当日のうちに Foundry に登場しており、モデルベンダーのリリースサイクルとクラウドベンダーの掲載サイクルの間隔が縮まっている。Claude Opus 5.5 と GPT-6 系列が同じ場で直接比較できることは、「既に特定クラウドにコミットしている企業はベンダー契約を切り替えることなくより多くの前沿モデルを評価できる」という主張をさらに裏付ける（詳細は [claude-models](/ja/topics/claude-models) ・ [openai-models](/ja/topics/openai-models)）。
- **分類**：Agent
- **関連Topic**：[cloud-agent-platforms](/ja/topics/cloud-agent-platforms)
- **出典**：https://azure.microsoft.com/en-us/blog/gpt-6-astra-sol-and-luna-for-production-agents-in-microsoft-foundry/
