## GPT-6 Astra が Microsoft Foundry に登場：Limited Access Program、Global／米国データゾーンのみ、EU ゾーンなし

- **概要**：マイクロソフトは、GPT-6 Astra（09-03 発表）が Microsoft Foundry（Azure チャネル）で利用可能になったと発表した。Limited Access Program を通じて段階的に展開されており、現時点では Global と米国データゾーンでのみ購入可能——**EU データゾーンは存在しない**。価格：Global 標準ティアはコンテキスト長に応じて 100 万トークンあたり $10～$75、米国データゾーンには割増あり（$11～$82.50）；Standard（従量課金）と Provisioned Throughput（専用スループット）の 2 種類の購入方式に対応。核心機能：Agentic Execution（オープンエンドな目標に対する構造化された計画立案と実行）、Computer Use（API を持たない旧来のアプリケーションをビジュアルインターフェース解析により操作）、企業テンプレートに沿った技術レポート／表計算／スライド資料の生成。セキュリティ面では Microsoft Entra による ID 管理、暗号化、専用ネットワーク、全操作ログを統合。
- **なぜ重要か**：これは 09-03 の GPT-6 Astra 発表で予告されていた「今後数日で Azure／AWS に展開」の具体的な実行であり、08-31 の xAI Grok 4.6 に続く Foundry の「マルチベンダーモデルマーケットプレイス」戦略のもう一つの事例でもある。ただし今回は明確な地域制限（EU ゾーンなし）と段階的アクセス（Limited Access Program）を伴っている——つまり Critical レベルのサイバーセキュリティ判定は OpenAI 自身のリリースケイデンスを制約するだけでなく、クラウドベンダー側のアクセスポリシーにも直接波及しているということだ。企業の導入担当者は、新しいモデルが Foundry に載ったからといってどこでも利用できると想定せず、「自分のデータゾーンで実際に購入できるか」を前提条件として確認する必要がある（詳細は [cloud-agent-platforms](/ja/topics/cloud-agent-platforms) を参照）。
