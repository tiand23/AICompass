# 2026-07-24

## Anthropic、Claude Opus 5 をリリース

- **概要**：Claude Opus 5（`claude-opus-5`）が Opus 4.8 からの段違いの改善としてリリース：100 万トークンのコンテキストウィンドウ（デフォルト＝最大）、最大出力 128k、thinking デフォルト有効、価格は Opus 4.8 と同じ $5/$25 per MTok。Claude API、Bedrock、Vertex AI、Microsoft Foundry で同時提供。
- **なぜ重要か**：フラッグシップ帯が値上げなしでコンテキストをデフォルト 1M に引き上げたことは、長文ドキュメント・大規模コードベース・長期エージェントに直接の恩恵。破壊的変更に注意：effort `xhigh`/`max` で thinking を無効化すると 400 が返る（Opus 4.8 では許可されていた）。effort（`low`〜`max` の 5 段階）が主要な制御手段となるため、移行時は既存の呼び出しを確認すること。
- **分類**：Models
- **関連 Topic**：[claude-models](/ja/topics/claude-models)
- **出典**：https://www.anthropic.com/news ・ https://platform.claude.com/docs/en/release-notes/overview

## 同日の Claude API アップデート：会話途中のツール変更（beta）、サーバーサイドフォールバックの default モード

- **概要**：Mid-conversation tool changes が beta に（Fable 5 / Mythos 5 / Opus 4.8 / Opus 5 でターン間のツール追加・削除が可能、prompt cache は維持、beta ヘッダー必須）。`fallbacks` パラメータに `"default"` モードが追加され、拒否カテゴリごとに Anthropic 推奨のフォールバックモデルを適用。Opus 4.7 の fast mode は廃止——継続利用には Opus 5 または 4.8 への移行が必要。
- **なぜ重要か**：キャッシュを壊さずに会話の途中でツールセットを動的に変更できることは、長時間稼働エージェントの「ツール固定 vs キャッシュ無効化」のジレンマを解消する。fast mode 廃止は実際の移行作業項目。
- **分類**：Agent
- **関連 Topic**：[claude-models](/ja/topics/claude-models)
- **出典**：https://platform.claude.com/docs/en/release-notes/overview
