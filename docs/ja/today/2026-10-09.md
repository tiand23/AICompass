## Claude Managed Agents が Dynamic Workflows を公開ベータ提供：Agent が自ら多段階・マルチ Agent のワークフロープログラムを書く

- **概要**：Claude Managed Agents に Dynamic Workflows（ベータ、`managed-agents-2026-04-01` beta header が必要）を追加——数百件の文書レビューのような「同種の項目を大量に処理する」タスク向けに、Agent 自身が「ワークフロープログラム」を書けるようになった：複数の Agent を段階的にスケジューリングして並行で作業させ、各段階の結果を統合する；ワークフローはサーバー側でバックグラウンドの workflow run として実行され、セッションのイベントストリームで `workflow_run.*` 系のイベントを通じて進捗を追跡できる。`multiagent` フィールドを `{"type": "multiagent_20261001", "workflows": {"type": "enabled"}}` に設定することで有効化し、system prompt で Agent にいつ run を開始すべきかを伝える。
- **なぜ重要か**：Managed Agents が「ツールを持つ単一の Agent」から「自らマルチ Agent 編成プログラムを生成しホスト実行する Agent」へ進化する一歩であり——「複数のサブ Agent を走らせるプログラムを書く」という作業を、開発者が手作業で構築するもの（LangGraph 式の明示的な編成など）からホスト型 Agent ランタイムのネイティブ機能へ変える；長時程 Agent 領域の「積層アーキテクチャ」（オープンソース harness vs ホスト型ランタイム）という流れに呼応しつつ、今回は編成ロジックの生成自体も Agent 自身に委ねている。
- **分類**：Agent

- **出典**：https://platform.claude.com/docs/en/managed-agents/multiagent-orchestration#dynamic-workflows

## GitHub Trending：MCP 逆向工程ツール rea が 1 日で 5.47 万スター急増、Vercel がクロスプラットフォームの skill パッケージマネージャを発表
