## Azure が Agent コンテキストエンジニアリングの実測データを公開：ナレッジベース検索で token 34% 削減、ツール群で 97% 削減

- **概要**：Microsoft の Azure ブログが「Agent 最適化の経済学」シリーズの新しい記事を公開し、Microsoft Foundry のコンテキストエンジニアリングについて具体的な定量データを示した：Foundry IQ ナレッジベースは、幅広い文書検索の代わりに意味的リランキング + 的を絞った段落検索を用い、証拠の再現率を 54% 向上させ、検索の token コストを 34% 削減した；Toolboxes の仕組みは、全ツールを prompt に詰め込む代わりにツール定義をオンデマンドで検索し、大規模なツール群を持つシナリオでの入力 token 消費を約 97% 削減した；さらに Skills（再利用可能な手順を一元管理し、再デプロイなしで更新可能）と階層化された記憶（セッション/ユーザー/フローレベル）の仕組みも導入され、対話の再生による重複消費を減らしている。
- **なぜ重要か**：具体的な定量数値を伴う企業向けコンテキストエンジニアリングの実践事例は珍しく、「Agent は使えば使うほど高くつく」という企業導入の核心的な痛点に直接応えるものである；「ツールをオンデマンドで検索する」という発想は MCP のツール発見メカニズムや、harness エンジニアリングにおける「ツール一覧を絞り込んで token 膨張を避ける」考え方と同じ方向性の異なる実装であり、08-12 に Azure が提唱した「3 段速度ガバナンスモデル」の「ランタイム最適化」層をさらに具体化したものだ。
