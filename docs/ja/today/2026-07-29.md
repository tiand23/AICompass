## book-to-skill が GitHub Trending に：PDF を Claude Code Skill に変換

- **概要**：オープンソースツール book-to-skill（Python）が 1 日で +423 スター——PDF 書籍/文書を Claude Code が読み込める skill パッケージへ自動変換する。
- **なぜ重要か**：「知識 → skill」の自動化パイプラインが登場した：これまでドメイン知識をエージェントに教えるには skill を手書きする必要があったが、いまや文書が能力パッケージへコンパイルされる。skill エコシステムが手工業からツールチェーンへ移行するシグナル。
- **分類**：Coding
- **関連 Topic**：[agent-skills](/ja/topics/agent-skills)
- **出典**：https://github.com/virgiliojr94/book-to-skill

## マイクロソフト、agent-governance-toolkit をオープンソース化
