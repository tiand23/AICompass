## book-to-skill が GitHub Trending に：PDF を Claude Code Skill に変換

- **概要**：オープンソースツール book-to-skill（Python）が 1 日で +423 スター——PDF 書籍/文書を Claude Code が読み込める skill パッケージへ自動変換する。
- **なぜ重要か**：「知識 → skill」の自動化パイプラインが登場した：これまでドメイン知識をエージェントに教えるには skill を手書きする必要があったが、いまや文書が能力パッケージへコンパイルされる。skill エコシステムが手工業からツールチェーンへ移行するシグナル。
- **分類**：Coding
- **関連 Topic**：[agent-skills](/ja/topics/agent-skills)
- **出典**：https://github.com/virgiliojr94/book-to-skill

## マイクロソフト、agent-governance-toolkit をオープンソース化

- **概要**：マイクロソフトがエージェントの行動制約と安全ポリシーをカバーするガバナンス・セキュリティフレームワーク agent-governance-toolkit（Python）を公開、GitHub Trending 入り。
- **なぜ重要か**：大手ベンダーがエージェントガバナンスをプラットフォーム内蔵機能ではなくオープンソースツールとして出し始めた（同社 Agent365 コントロールプレーンの OSS 側翼）——ガバナンスツールチェーンの標準化は、企業がエージェントを大規模展開するための前提条件。
- **分類**：Agent
- **関連 Topic**：[agentic-safety](/ja/topics/agentic-safety) ・ [enterprise-ai-agents](/ja/topics/enterprise-ai-agents)
- **出典**：https://github.com/microsoft/agent-governance-toolkit

## LangChain、Deep Agents v0.7 をリリース

- **概要**：ベース harness を簡素化し、同等性能でベース入力トークンを 65% 削減。ファイルシステムツールを全面改善（ページネーション付き read_file、grep の 1,000 件上限とストリーミング出力、大規模ディレクトリでのハングを解消）。メッセージ履歴を DeltaChannel の増分保存に変更し、スレッドが長くなってもチェックポイントが肥大化しない。実験的な CodeInterpreterMiddleware がスコープ付き QuickJS ランタイムでのコード実行とプログラム的ツール呼び出しに対応。破壊的変更：TodoListMiddleware がオプトイン化、backend factories は削除。
- **なぜ重要か**：この更新一覧は長期タスクエージェントの本番痛点リストそのもの——トークンコスト、チェックポイント肥大、大規模ディレクトリ検索。「ベーストークン 65% 削減」は本番デプロイの直接的なコスト削減。利用中なら 2 つの破壊的変更を確認してからアップグレードを。
- **分類**：Agent
- **関連 Topic**：[deep-agents](/ja/topics/deep-agents)
- **出典**：https://www.langchain.com/blog/deep-agents-v0-7
