# 2026-09-24

## Microsoft Foundry が音声 Agent プレビュー、拡張されたモデル選択肢、継続的最適化を追加

- **概要**：Microsoft Foundry が 3 つの更新を発表：音声 Agent の公開プレビュー（サブ秒レイテンシ、80 以上の言語/140 以上のロケール、Web・Teams・Teams Phone・Twilio へのデプロイが可能、prompt 型とホスト型の両方の Agent 形態に対応、音声認識/音声合成モデルは OpenAI や Microsoft など複数ベンダーから選択可能）；拡張されたモデル選択肢（新しい GPT-6 系列 SKU と Claude Opus 5.5 を追加）；継続的最適化（本番環境のトレースデータを使って、Agent の指示・skills・ツール・モデル選択を品質・レイテンシ・コストの観点から継続的にチューニング）。
- **なぜ重要か**：音声 Agent は Google Gemini Live に対抗する Foundry の最後のピースを埋めるものであり（詳細は [voice-agents](/ja/topics/voice-agents)）、「本番トレースから継続的に最適化する」という発想は LangSmith Engine の自動診断・自動修正のアプローチと呼応している——2 大プラットフォームが「実際の稼働データで Agent を継続的に改善する」という同じ方法論に収斂しつつある。
- **分類**：Agent
- **関連Topic**：[cloud-agent-platforms](/ja/topics/cloud-agent-platforms)
- **出典**：https://azure.microsoft.com/en-us/blog/ship-agents-faster-with-expanded-model-choice-voice-agents-and-continuous-optimization/

## LangChain が LangSmith プラットフォーム更新の波を発表：Engine v2、Managed Deep Agents v0.8、Trajectories、Fine-Tuning、Custom Apps

- **概要**：LangChain が LangSmith の 5 つの更新を一度に発表——**Engine v2**：本番トレースを自動スキャンして Agent の不具合を診断する内蔵 Deep Agent「Engine」（直近は 08-25 に性能向上）にレッドチーム演習と自動テスト機能を追加；**Managed Deep Agents v0.8**：認証、記憶管理、メッセージチャネル機能を追加——09-09 の Connections に続く、2 週間以内でのホスト型ランタイム機能の再拡充；**Trajectories**：LangSmith 内で Agent セッションの全過程を「読める」形で確認できる新しいビュー；**LangSmith Fine-Tuning**：プラットフォーム組み込みのファインチューニング機能；**LangSmith Custom Apps**：Agent データを中心にカスタムインターフェースを構築する機能。
- **なぜ重要か**：可観測性（Trajectories）、セキュリティテスト（Engine v2 のレッドチーム演習）、ホスト型ランタイム（Managed Deep Agents v0.8）、モデルのカスタマイズ（Fine-Tuning）、インターフェース層（Custom Apps）という、これまで別々に進化してきた 5 つの方向性を一度にまとめた「プラットフォーム機能リリース週」であり、LangSmith が「ツールの寄せ集め」から「統合された Agent 生産プラットフォーム」へと収斂しつつあることを示している——特に Managed Deep Agents の新しい認証機能は 09-09 の Connections と直結しており、ホスト型の認証情報/ID というテーマが 2 週間のうちに 2 回連続で反復されている。
- **分類**：Agent
- **関連Topic**：[cloud-agent-platforms](/ja/topics/cloud-agent-platforms)・[deep-agents](/ja/topics/deep-agents)
- **出典**：https://www.langchain.com/blog/new-in-langsmith-engine-v2-managed-deep-agents-fine-tuning-and-more
