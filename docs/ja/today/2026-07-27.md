## NVIDIA が 36 社と共に Open Secure AI Alliance を発足：OpenAI/Google/Anthropic/Meta は揃って不在（補漏）

- **概要**：NVIDIA が Microsoft、Cisco、Cloudflare、CrowdStrike、HuggingFace、IBM、Palo Alto Networks、Red Hat、Elastic、SpaceXAI、Linux Foundation など、合計 37 の組織と共に Open Secure AI Alliance を発足させた。目標は「ソフトウェアと AI Agent のセキュリティを強化するためのオープンな技術・手法・ツールを開発し共有すること」。この連合の中核的主張は、サイバー防御側には「読める・改変できる・自分のハードウェア上で動かせる」モデルが必要であり、ベンダーの API を通じてしかアクセスできないクローズドシステムだけに頼るべきではない、というものだ。連合初の技術成果は NOOA（NVIDIA-labs OO Agents）フレームワーク——Apache 2.0 ライセンスの研究フレームワークで、Agent harness を Python クラスとして表現する：メソッド本体を省略記号（`...`）で書いた部分は実行時に LLM 駆動のループが「補完」し、標準の Python メソッドは決定論的な実行を保つ。CyberGym L1 ベンチマークで 86.8% を記録したが、リポジトリ自身が抽象構文木チェックとモジュール拒否リストは「多層防御の一層にすぎない」「隔離境界ではない」と明言している。注目すべきは、OpenAI、Google、Meta、Anthropic がいずれも創設メンバーリストに含まれていないことだ——これら 4 社はわずか数日前の 7 月 24 日に業界政策への連名書簡に署名したばかりだった。連合側の資料はこれらの企業が不在である理由、参加交渉中かどうか、参加に何が必要かについて説明していない。連合自体にも憲章、理事会、具体的な技術ワークストリーム、提供スケジュール、共有コードリポジトリが欠けており、Linux Foundation の役割は競合企業が協力するための中立の場を提供することにとどまり、正式なガバナンス構造ではない。今回の結成は 7 月の HuggingFace 侵入事件（07-21 の ExploitGym の記録を参照）への直接的な対応だ：攻撃者はリモートコードを実行するデータセットローダーを悪用し、データセット設定内でのテンプレートインジェクションを行う悪意あるデータセットを通じて、ノードアクセス・認証情報窃取・内部横展開を段階的に達成した。HuggingFace はその後、オープンウェイトモデルの GLM 5.2 を使って 17,000 件超の記録された行動を分析し、攻撃の全タイムラインを復元した——理由は、商用のクローズドソースなフロンティアモデル API の安全フィルターが、分析に必要な攻撃指示・エクスプロイトペイロード・C2（コマンド&コントロール）関連の内容を含むリクエストを最初から拒否したためだ。ただし報道は、オープンモデルは侵入の復元と事後対応の支援にとどまり、GLM 5.2 自体が侵入を検知・阻止・封じ込めたわけではないことも明確にしている。
- **なぜ重要か**：これは ExploitGym/HuggingFace 侵入事件に対する業界全体としての集団的対応であり、オープンウェイトモデルを巡る論争においてこれまで見過ごされてきた具体的な論拠でもある——商用クローズドソースモデルの安全ガードレールは、事後のフォレンジック分析という正当な防御シナリオにおいても「攻撃のように見える」リクエストを同様にブロックしてしまう。これは「ガードレールの厳格さ」と「防御能力」が単調増加の関係にないことを示しており、セキュリティ実務者が脅威分析を行うためには自身のモデルを読み書きできる能力そのものが必要であることを意味する。主要なフロンティアモデルベンダーがこの連合に揃って不在であることも同様に記録に値する——一方でこれらの企業は「ペーシングメカニズム」を求める業界政策書簡に連名しながら、他方でハードウェアベンダーとセキュリティ企業が主導するオープン技術連合への具体的な行動への参加は明らかに見られない。この「公の表明」と「具体的な行動」の乖離は、業界の実際のガバナンスの進展を判断する上で注視し続ける価値のあるシグナルだ。NOOA フレームワークの「決定論的コードと LLM 駆動コードを混在させ、自身のチェックが隔離境界ではなく多層防御にすぎないことを明確に認める」という率直な姿勢も、Agent セキュリティツールが過度な誇張をしない、現実的な自己定位へと成熟しつつあることの一例だ。
- **分類**：その他（セキュリティ）
