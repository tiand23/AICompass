## OpenAI が Cursor との提携を終了：SpaceX/xAI による Cursor 買収後、モデルアクセスを遮断

- **概要**：SpaceX は今年 6 月、株式による Cursor の買収に合意しており（600 億ドルでの買収、または 100 億ドルの解約金支払いというオプション条項付き）、取引は 8 月 14 日に完了した。8 月 29 日、OpenAI は Cursor との提携終了を発表し、Cursor が OpenAI のモデルへの直接アクセス権を失う日として 11 月 12 日を提示した——これは契約上許される最長の通知期間だ。OpenAI の公式見解：「イーロン・マスク氏傘下の企業がこれまで契約に違反してきた経験を踏まえると、SpaceX が当社の技術を利用規約の範囲内で使用すると確信できない。」Cursor の CEO Michael Truell は影響を軽視し、OpenAI のモデルは現在同社のトラフィックの約 5% しか処理していないと述べ、Anthropic が Claude モデルのサポート拡大を約束して補完に入った。
- **なぜ重要か**：これはコーディング Agent エコシステムにおいて、モデルベンダーが特定の下流顧客のアクセス権を自ら遮断するという稀な事例だ——直接の原因は、買収元（マスク氏関連企業）と OpenAI の間に既にあった信頼と契約上の対立が、モデルアクセス層にまで及んだことにある。Cursor や、競合するモデルベンダーに買収・関連付けられる可能性のある他の AI コーディングツールを使う開発者にとって、これは具体的なサプライチェーンリスクの事例だ：ツールの安定性は、そのツール自体の技術路線だけでなく、株式の帰属先や上流モデルベンダーとの商業関係にも左右される。トラフィックの 5% という数字と Anthropic による迅速な補完は、現在のコーディング Agent ツールが既に広くマルチモデル冗長性を組み込んでいることも示しており、単一モデルの供給停止による実際の影響は限定的かもしれない（詳細は [coding-agents](/ja/topics/coding-agents)）。
- **分類**：その他（エコシステム/サプライチェーン）
- **関連 Topic**：[coding-agents](/ja/topics/coding-agents) ・ [openai-models](/ja/topics/openai-models)
- **出典**：https://www.cnbc.com/2026/08/29/openai-cursor-spacex-model-access.html

## three.ws がオープンソース化：AI Agent に「身体・頭脳・財布・仕事」を与えるフルスタックフレームワーク

- **概要**：three.ws は、これまで別々だった 4 つの能力を単一の Agent インスタンスに統合するオープンソースプラットフォーム（Apache 2.0）だ：①**身体**——テキスト/写真/スケッチの入力を受け付ける 3D 生成パイプラインで、Microsoft TRELLIS、Hunyuan3D 2.1、TripoSR など複数の生成エンジンにレイテンシと稼働状況に応じてルーティングし（自動フェイルオーバー付き）、リギングとテクスチャ付きのアニメーション可能な glTF キャラクターを生成する；②**頭脳**——単一モデルではなくマルチモデルの Agent ランタイムで、Claude、GPT-5.x、Grok、そして NVIDIA NIM 経由で提供されるオープンモデルへリクエストをルーティングし、セッションを横断する型付き記憶（ユーザー/フィードバック/プロジェクト/参照）を維持し、感情状態を表情やジェスチャーに反映させ、ツール呼び出しを反復的に実行する；③**財布**——Solana 上のオンチェーン経済アイデンティティで、CREATE2 経由で ERC-8004 契約を 12 の EVM ネットワークにデプロイし、x402（HTTP 402 決済プロトコル）で決済することで、Agent は人間による秘密鍵の管理なしに関数呼び出しごとに USDC のマイクロペイメントを受け取れる——8 月 25 日時点で 110,416 件のオンチェーン USDC 決済が完了している；④**仕事**——マルチサーフェス配信：1 行の Web 埋め込み、AR の設置リンク、公式レジストリの 72 の MCP サーバー、ChatGPT プラグイン、Android では Trusted Web Activity 経由、そして `npx` によるターミナル利用——単一の Agent インスタンスが Web、チャットクライアント、物理空間、音声インターフェースに同時に存在できる。資金移動アクションは 7 層の強制チェックからなるガードチェーンを通過する。OpenAI（Select Partner）、NVIDIA（Inception メンバー）、IBM（Business Partner）と公式パートナーシップを結んでいる。
- **なぜ重要か**：これは本ナレッジベースが初めて目にする、「3D 具身化、マルチモデル推論、オンチェーン経済アイデンティティ、マルチサーフェス配信」というこれまで別々に進化してきた 4 つの方向性が、1 つのオープンソースフレームワークに統合された事例だ。特に「財布」の部分（x402 プロトコルとオンチェーンアイデンティティにより、Agent が人手を介さず自律的にマイクロペイメントを送受信できる）は、本ナレッジベースがこれまであまり扱ってこなかった Agent の経済活動という流れを補完するものだ；72 の MCP サーバーの公式レジストリも、分配層における MCP の大規模な応用例だ（詳細は [mcp](/ja/topics/mcp)）。単一のコミュニティプロジェクトとしての長期的な影響力はまだ未知数だが、「具身化＋推論＋決済＋配信」という組み合わせの発想自体が記録に値する新しい総合的な方向性だ（詳細は [agent-frameworks](/ja/topics/agent-frameworks)）。
- **分類**：Agent
- **関連 Topic**：[agent-frameworks](/ja/topics/agent-frameworks) ・ [mcp](/ja/topics/mcp)
- **出典**：https://huggingface.co/blog/three-ws/building-3d-ai-agents-end-to-end
