## LangChain が Deep Agents のマルチエージェント連携に「コンテキストモード」を導入：Forked vs Isolated Subagents

- **概要**：LangChain が Deep Agents フレームワークに `'mode': 'fork'` コンテキストモードを追加——サブエージェント起動時にスーパーバイザーの現在の状態と会話履歴全体を継承（プロンプトキャッシュで再利用）、デフォルトの Isolated モード（サブエージェントはタスク説明のみを受け取り、空のコンテキストから開始）とは区別される；使い分けの指針として Worker/Memory エージェントは fork、Verifier/Researcher エージェントは isolated を推奨。
- **なぜ重要か**：スーパーバイザー／サブエージェント構成では、空のコンテキストから始まるサブエージェントがスーパーバイザーがすでに行った調査作業（ファイル読み込みなど）をやり直す無駄が発生しがち；2 つのコンテキスト伝播モードを明示的に区別することで、この選択が「暗黙のデフォルト」から「役割ごとに明示的に選ぶエンジニアリング判断」に変わる。
- **分類**：Agent
- **関連Topic**：[deep-agents](/ja/topics/deep-agents)
- **出典**：https://www.langchain.com/blog/organizing-context-in-a-multi-agent-harness

## Microsoft が Discovery Engine と CLIO を発表：複数経路推論による科学的発見エージェント

- **概要**：Azure AI が Microsoft Discovery Engine を発表、中核は CLIO（Cognitive Loop via In-Situ Optimization）——複数の独立した推論経路が並行して問題を探索し、互いに比較・学習を共有し、証拠に裏付けられた 1 つの結果に収束する；探索継続・戦略切替・別モデル使用・人間の専門家関与を自律的に判断可能；「Agent's Last Exam」ベンチマークで健康/医学 61.6%、物理科学 75.2%、生命科学 64.6% を達成し、新しい有機系レドックスフロー電池の発見を支援したと主張。
- **なぜ重要か**：長時程 Agent が不確実性に直面した際にどうすべきか（探索継続／戦略切替／モデル切替／人間を呼ぶ）という Deep Agents の中核課題を、科学研究という垂直領域で具体的に製品化した事例であり、単なるコンセプト宣伝ではなく比較可能なベンチマークスコアを伴う。
- **分類**：Agent
- **関連Topic**：[deep-agents](/ja/topics/deep-agents)・[enterprise-ai-agents](/ja/topics/enterprise-ai-agents)
- **出典**：https://azure.microsoft.com/en-us/blog/beyond-the-benchmark-how-an-adaptive-approach-drives-scientific-discovery/
