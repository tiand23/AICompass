## LangChain が Connections を発表：Managed Deep Agents 向けの管理された認証情報と呼び出し元単位の ID

- **概要**：LangSmith Managed Deep Agents v0.7.0+ に Connections が追加——名前付き認証情報を LangSmith ワークスペースに保存（コードや `.env` には置かない）、実行時に `connections.get("<slug>", {"type": "agent"|"user"})` で取得；所有者（Agent 共有 vs 呼び出し元ごとのユーザー所有）と認証情報タイプ（静的シークレット vs OAuth 認可）という 2 つの独立した軸を持ち、OAuth コールバックルート／トークンストア／リフレッシュロジックを手作りする必要がなくなる。
- **なぜ重要か**：ホスト型エージェントの 2 つの現実的な課題を解決——認証情報のセキュリティ（再デプロイなしでキーをローテーション）と呼び出し元単位の ID（エージェントが誰かの代わりに行う操作が、汎用のボット ID ではなくその人自身の ID を伴う——例えば起票されたチケットに本人のハンドル名が表示される）；これまで手作業で構築していた OAuth の配管をフレームワークの組み込み機能に変える。
- **分類**：Agent
