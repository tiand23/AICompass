# 2026-08-09

## OpenAI が Atlas ブラウザを終了、「ブラウザエージェント」能力を ChatGPT と Codex に統合

- **概要**：OpenAI は、Atlas（2025 年 10 月 21 日ローンチ、ChatGPT を中核に据えた独立ブラウザで Agent モードをプレビュー搭載）を 2026-08-09 に停止すると発表し、それまでにブックマークなど重要データのエクスポートを推奨した。代わりに、Atlas から得た知見を活かして ChatGPT 自身のブラウザ体験を強化する——複数タブ、ダウンロード、ナビゲーション改善、アカウントログイン対応など。より深いエージェント的ブラウザ作業は ChatGPT デスクトップアプリへ誘導され、「ブラウザエージェント」能力は Codex にも統合される。
- **なぜ重要か**：「独立ブラウザエージェント製品」という路線が、1 年足らずで「既存の主力製品にエージェント能力を組み込む」方が割に合うと実証された事例——以前の Agent Builder などプラットフォーム層製品の廃止サイクルと同様、独立した新形態製品に賭けることの存続リスクをまた一つ裏付けた。本ナレッジベースが長らく指摘してきた「OpenAI のプラットフォーム層製品は廃止が早く、中核能力は ChatGPT/Codex へ収斂する」という行動パターンの再確認である。Atlas の Agent モードやブラウザ自動化 API を使って連携を組んでいた開発者は、ChatGPT/Codex の対応機能への移行経路を検討する必要がある。
- **分類**：Agent
- **関連 Topic**：[openai-models](/ja/topics/openai-models) ・ [agent-workspaces](/ja/topics/agent-workspaces)
- **出典**：https://help.openai.com/en/articles/20001371-evolving-atlas-into-chatgpt-for-browser-based-agentic-work

## Harvey が法律エージェントベンチマーク Harvey LAB を公開：24 の実務分野、1,671 の実タスク

- **概要**：法律 AI 企業 Harvey が Harvey LAB を公開（1 日で +47、累計 695 スター）——現実的な環境での法律業務における LLM エージェントの能力を評価するベンチマーク：エージェントへの指示・文書・採点基準からなるデータセットと、実行・評価用の harness をセットで提供する。24 の法律実務分野（特に契約業務）、1,671 のタスクをカバーし、現実的な M&A データルーム課題も含む。全通過（all-pass）の採点基準 + LLM judge による判定を採用し、スコアレポートと比較ダッシュボードを提供する。MIT ライセンスでオープンソース化、新しいタスクやモデルアダプターの貢献を受け付けている。
- **なぜ重要か**：ReviewBench（コードレビュー）や音声エージェントの 3 軸評価に続き、「実タスク由来ベンチマーク + LLM-as-judge」という評価方法論が、高度な専門性とリスクを伴う法律という垂直領域に着地した——しかもその領域を深く手がける企業自身が構築・公開したもので、第三者が作るより権威性とタスクの現実性が高い。これはまた、専門サービス系エージェント（法務、財務、医療）の能力上限を評価するには、その領域専用の全通過基準による実タスクベンチマークが必要であるという一般的なパターンを示している——汎用のコーディング/対話ベンチマークでは業界の深部での性能は測れない。
- **分類**：Evaluation
- **関連 Topic**：[agent-evaluation](/ja/topics/agent-evaluation)
- **出典**：https://github.com/harveyai/harvey-labs

## code-graph-rag が登場：純粋な AST ではなくナレッジグラフでクロス言語コード理解

- **概要**：vitali87/code-graph-rag（1 日で +59、累計 2.7k スター）——Tree-sitter で多言語コードベースの抽象構文木を解析し、その結果を Memgraph に格納してナレッジグラフを構築する（AST スナップショットに留まらない）。関数・クラス・import・データフロー間の問い合わせ可能な関係を維持する。AST ベースのコード検索と構造的置換、代入や関数呼び出しをまたぐデータフロー追跡、呼び出しグラフをたどるデッドコード検出、Claude Code などのクライアント向け MCP サーバー、AI が生成する Cypher クエリによる自然言語問い合わせに対応。Python、TypeScript、JavaScript、Rust、Go、Java、C/C++、C#、PHP、Lua、Dart など多数の言語をサポート。
- **なぜ重要か**：「AI ツール向けにコード構造グラフを構築する」という発想のグラフデータベース実装版——数日前に登場した Tree-sitter + ローカル SQLite の code-review-graph との対比が興味深い：同じ「コードナレッジグラフ」という目標に対し、一方は軽量なローカルストレージ + MCP 問い合わせツールの路線、もう一方は専門のグラフデータベース + 自然言語から Cypher への変換クエリの路線を取る。後者の強みは複雑な多段階の関係クエリ（例えば「この関数の呼び出し連鎖は最終的にどのデータベーステーブルに影響するか」）をネイティブにサポートできる点だが、代償として追加のグラフデータベース依存が生じる。この 2 つの路線の分岐自体が、「コードグラフ」という新興サブ分野におけるアーキテクチャ選定の具体的なサンプルである。
- **分類**：Coding
- **関連 Topic**：[ai-code-review](/ja/topics/ai-code-review) ・ [coding-agents](/ja/topics/coding-agents)
- **出典**：https://github.com/vitali87/code-graph-rag

## agency-agents が登場：230+ の分野横断エキスパートペルソナによるエージェントチームのテンプレート

- **概要**：msitarzewski/agency-agents（1 日で +446、累計約 14 万スター）——さまざまな職能に特化した 230+ の AI エージェント「ペルソナ」の集合。エンジニアリング（フロントエンド/バックエンド/DevOps/セキュリティ/データベースなど 50+ の細分野）、デザイン、マーケティング、セールス、プロダクト、テスト、セキュリティ、ゲーム開発（Unity/Unreal/Godot 専門を含む）、GIS、金融、医療、学術など 15+ の大分類にまたがる。Claude Code にネイティブ対応し、変換スクリプトで Copilot、Cursor、Aider、Windsurf など 8+ のプラットフォームをサポート。本番実戦で検証済みとうたい、測定可能な成功指標を付与、MIT ライセンスでオープンソース化、ネイティブアプリと CLI インストールスクリプトの両方を提供する。
- **なぜ重要か**：14 万スターは「既製のエキスパートペルソナチーム」という skill/エージェント配布形態への需要の大きさを物語る——単一の手順系 skill と比べ、「エージェントの役割設定をまるごと差し替える」ことを箱出しで使える製品に仕立てており、その範囲はコーディングを大きく超えてマーケティング、セールス、ゲーム開発といった純粋な業務職能にまで及ぶ。Agent 能力エコシステムが「エンジニアツール」から「汎用的な職場ロールプレイ」へと拡張している顕著なサンプルである。クロスプラットフォーム変換スクリプトの存在も、skill/ペルソナの配布が単一ツール専用から複数ツール共有へ移行しつつあることを改めて裏付けている。
- **分類**：Agent
- **関連 Topic**：[agent-skills](/ja/topics/agent-skills)
- **出典**：https://github.com/msitarzewski/agency-agents
