# 2026-09-30

## Claude Sonnet 4.5 の退役を発表、2026-11-30 にサービス終了

- **概要**：Anthropic が `claude-sonnet-4-5-20250929` の退役スケジュールを正式発表：2026-11-30 にサービス終了、2 日前の 09-28 に発表されたばかりの Claude Sonnet 5.5 への移行を推奨。
- **なぜ重要か**：2 か月の移行期間は Anthropic が最近行っているモデル退役の典型的なペースであり（08-05 の Opus 4.1 退役と同様）、固定のモデル ID を使っている統合先はこの日付を保守計画に組み込む必要がある；Opus 5.5 と Sonnet 5.5 が今月中（09-22、09-28）に相次いで発表されたことと合わせ、Claude モデルラインの新旧交代がこの 1 か月に集中して起きている。
