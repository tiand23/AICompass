## Barclays が Claude の活用を拡大：3 つの本番ユースケースと 20 億ポンドの削減目標

- **概要**：Anthropic が Barclays の事例を公開：2026 年末までに同行の開発者の 50%（2027 年にはさらに拡大）が Claude Code をソフトウェア開発とレガシーシステムの現代化に使うことを目標とする；2025 年にローンチした Colleague Knowledge Assistant（RAG ベース）は既に英国の 1.6 万人以上のスタッフにまたがり 100 万回超の検索を処理；Global Markets チームは Claude を使って 1 日あたり約 12 万通の受信メールを分類・補完・適切な処理経路へルーティングし、手作業の処理量を削減している。これらは約 20 億ポンド規模の複数年にわたる効率化プログラムの一部に位置づけられる。
- **なぜ重要か**：Toyota や Stripe など既存の「Agent 本番活用事例集」に加わるもので、Barclays は 3 つの異なるユースケースについて定量的な指標（開発者導入目標、検索量/利用者数、日次メール処理量）を一度に開示し、それを会社全体の財務目標に直接結びつけている珍しい銀行業界の事例であり、同業他社が Claude 導入の規模とペースを見積もる際の具体的な参照点となる。
