## Anthropic が Model Hardware Standard をプレビュー：Agent が実験室/製造業の物理設備を安全に操作するための共通規格

- **概要**：Anthropic が Model Hardware Standard（MHS）のリサーチプレビューを、最初の科学研究機関と先進製造企業のグループ向けに公開した——AI Agent が顕微鏡、液体ハンドラー、ロボットアームなど複数の実験室・製造機器を並行して操作できる共有仕様で、日常的な創薬実験から量子コンピュータのレーザー較正までのタスクをカバーする。解決しようとしている課題は、機器同士が通常互いに通信できず、実験室や工場は専門家によるオーダーメイドの統合作業に通常数週間から数か月を要することだ；MHS はこの統合作業を数時間から数分に圧縮する。MHS はモデルに依存せず、プログラム可能なインターフェースを持つあらゆる機器で動作し、どの Agent harness も Model Context Protocol のような標準プロトコル経由でアクセスできる。HHMI Janelia Research Campus との協業で開発され、現時点ではリサーチプレビューのみだが、将来的にオープンソース化する計画がある。
- **なぜ重要か**：これは本ナレッジベースが初めて記録する、「Agent が物理世界のハードウェアを安全に操作する」という路線が体系的に標準化された事例だ——これまでの agentic safety の議論はデジタル世界（サンドボックス脱出、ツールの悪用）に集中していたが、MHS は「Agent にどの権限を与えるか、どう承認するか、どう隔離するか」という原則を、ミスが現実の物理的な結果を招く実験室・製造機器のシナリオへ体系的に移植した初めての例だ。既存のプロトコル（MCP）経由でアクセスできることも、プロトコル層を再発明する必要はなかったことを示しており、新しいのは機器統合と安全操作の規格そのものだ（詳細は [agentic-safety](/ja/topics/agentic-safety)）。

## Anthropic が科学者向け支援を拡大：Claude 無料/割引席を 1 万席開放、政府提携で生命科学研究者に Mythos 級モデルを開放

- **概要**：Anthropic は科学者向けに Claude Team の無料/割引席を 1 万席開放すると発表した——標準席は無料、利用上限が 5 倍のプレミアム席は月額 15 ドルで価格は 1 年間固定、今後数か月でこの 1 万席をはるかに超える規模へ拡大する計画だ。この拡大は 06-30 に発表された Claude Science（ゲノミクス、単一細胞解析、プロテオミクス、構造生物学、ケモインフォマティクス向けに 60 以上の skill とコネクタを事前設定した AI ワークベンチ）を土台としており、これまで生物科学分野に限定されていた AI for Science クレジットプログラムをより広い分野へ拡張する。同時に Anthropic は米国政府と提携し、生命科学の専門家が Mythos 級モデルを生命科学の研究開発に利用できるアクセスプログラムを構築しており、最初の参加者はすでに登録済みだ。
- **なぜ重要か**：Claude Science 製品ライン（06-30 発表、08-26 に Compliance API の対応範囲が拡大されたばかり）のさらなる大幅な拡張だ——「無料/割引アクセス」と「政府提携による Mythos 級モデルアクセス」という 2 つの経路を同時に開くことは、科学研究がエンタープライズ Agent と並ぶ Anthropic の第 2 の重点製品ラインになりつつあることを示唆する（詳細は [claude-models](/ja/topics/claude-models)）。
