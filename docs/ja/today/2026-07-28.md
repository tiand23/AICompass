## Liquid AI、LFM2.5-Encoders を発表：CPU 上の高速長文脈推論

- **概要**：Liquid AI が HuggingFace で LFM2.5-Encoders を発表。一般的な CPU 上で長文脈推論を効率的に処理するよう最適化されたエンコーダモデル。
- **なぜ重要か**：「GPU なしで長文脈が動く」ことは埋め込み/検索系ワークロードのデプロイ障壁とコストを直接下げる——RAG パイプラインの embedding 工程やエッジ/オンプレ展開に実用的な恩恵であり、効率アーキテクチャ路線（Liquid の非 Transformer 系 LFM）が実地に定着し続けるシグナルでもある。
- **分類**：Deployment
- **関連 Topic**：[model-efficiency](/ja/topics/model-efficiency)
- **出典**：https://huggingface.co/blog

## フロンティアラボ従業員 1,100 名超が AI「ペーシング」公開書簡に署名

- **概要**：OpenAI、Anthropic、Google、Meta の従業員 1,100 名超が公開書簡に署名し、AI の進歩が人間の安全な監督能力を超えた場合に検証可能な形で減速を調整できる国際的「ペーシングメカニズム」の構築を米国政府に主導するよう求めた。

## Google が Gemini API Managed Agents を拡張：3.6 Flash デフォルト、実行 Hooks、予算制御

- **概要**：Gemini API Managed Agents の一括更新：デフォルトモデルが Gemini 3.6 Flash に（3.5 Flash / Flash-Lite の明示指定でコスパを選択可）；サンドボックス内の pre/post 実行 hooks を新設（command または HTTP ハンドラで、ツール呼び出しやファイル書き込みをブロック・lint・監査できる）；`max_total_tokens` による予算ガードレール（中断したタスクは新予算で再開可）；cron 定期トリガー（サンドボックスの永続再利用）、サンドボックスセッションを管理する Environments API、そして無料枠の開放。
- **なぜ重要か**：ホスト型エージェントランタイムの「本番化三点セット」（hooks 検証パイプライン、予算ガードレール、定期実行）が Google プラットフォームで揃った——「エージェントが動く」から「エージェントを運用できる」へ。Claude Managed Agents のエンジニアリング路線と正面から並び、サンドボックス内実行検証という hooks 設計は自前ランタイムにも参考になる。
- **分類**：Agent
- **関連 Topic**：[cloud-agent-platforms](/ja/topics/cloud-agent-platforms)
- **出典**：https://blog.google/innovation-and-ai/technology/developers-tools/expanding-managed-agents-gemini-api-3-6-flash-hooks/
