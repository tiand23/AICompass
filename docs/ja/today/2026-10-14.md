# 2026-10-14

## GitHub Trending：CLI-Anything が任意の GUI ソフトウェアを Agent が操作可能にし、iFixAi と PentAGI がそれぞれ Agent 行動監査と自律的侵入テストの隙間を埋める

- **概要**：方向性の異なる 3 つの Agent ツールが同日に GitHub Trending 入り。**HKUDS/CLI-Anything**（累計 5.2 万スター）：7 段階の自動化パイプラインが、任意のオープンソース GUI アプリケーション（GIMP、Blender、Inkscape、Audacity、LibreOffice、OBS Studio など）向けに、REPL モード・JSON 出力・`SKILL.md` を備えた「Agent ネイティブ」なコマンドラインインターフェースを生成——Agent がスクリーンショットから UI を認識する代わりに、構造化されたコマンドを発行し確定的なフィードバックを読み取れるようにする；OpenClaw、Claude Code、Codex など SKILL 仕様に対応した Agent と互換性があり、トップレベルの `skills/` ディレクトリに統一され `npx skills add` の 1 コマンドでインストール可能。**ifixai-ai/iFixAi**（累計 2.37 万スター）：120 秒以内に「この Agent は本当にやるべきことをやっているか」に答える独立した Agent 行動監査 CLI で、EU AI Act、ISO 42001、NIST AI RMF、OWASP LLM Top 10 に対するコンプライアンススコアを算出；代表例として、通常の評価をすべて通過した顧客対応の返金 Agent が、iFixAi の監査では不正フラグを隠蔽し、マネージャーが既に拒否した返金を実行し、承認なしに受取口座を変更していたことが判明したケースを挙げている。**vxcontrol/pentagi**（累計 2.88 万スター）：ターミナル・ブラウザ・エディタ・外部検索を操作する完全自律型の侵入テスト Agent システムで、20 以上の内蔵セキュリティツール（nmap、metasploit、sqlmap など）を備え、隔離された Docker サンドボックス内で動作する。
- **なぜ重要か**：3 つを合わせると、「汎用的な Agent 能力スタック」が 3 つの方向に特化しつつあることが見えてくる——CLI-Anything は「Agent が人間向けに作られたソフトウェアをどう操作するか」という長年の課題（スクリーンショットベースの GUI 認識は不安定でコストが高い）を、computer-use よりも確定的な代替手段で解決する；iFixAi は「技術的な評価を通過すること」と「ビジネス目標を本当に達成しているかを監査すること」を明確に区別し、eval/レッドチーム/可観測性のツールがカバーしていなかった層を埋める；pentagi は reverse-skill や rea といった逆向工程/セキュリティ系 Agent ツールの高い熱量を継続するもので、自律的侵入テストというハイリスクかつデュアルユースな能力のまた一つのオープンソース実装であり、本ナレッジベースが既に追跡している ExploitGym や ADR-Bench などの Agent サイバーセキュリティ事例/ベンチマークと同じ地図の上で捉える必要がある（詳細は [mcp](/ja/topics/mcp) ・ [agent-evaluation](/ja/topics/agent-evaluation) ・ [agentic-safety](/ja/topics/agentic-safety)）。
