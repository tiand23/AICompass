## Anthropic が Claude Frontier Academy に 1 億ドルを投資、1 万人のデプロイエンジニア育成を目標に

- **概要**：Anthropic が Claude Frontier Academy を発表——2027 年末までに「Frontier Deployed Engineer（FDE）」を 1 万人育成するため 1 億ドルを投じる計画で、最初のコホートは Accenture、Bain、Capgemini、Commonwealth Bank of Australia、Deloitte、McKinsey、Morgan Stanley、Novo Nordisk から選出；12 週間のレジデンシー形式で、まず模擬的な企業導入と採点付き評価からスタートし、合格者は医療研修のようなレジデンシーに進んで実際の事例で実践を積んだ後に認定評価を受け、最初のエンジニアは 2027 年初頭に認定される見込み。
- **なぜ重要か**：企業向け Agent の「デリバリーモデルのスペクトラム」において、プラットフォーム + 常駐エンジニア（FDE モデル）はこれまで有資格エンジニアの供給不足に制約されてきた——Anthropic が自ら人材育成パイプラインに資金を投じることは、「デリバリー能力の不足」という企業 AI 導入の隠れたボトルネックを戦略的課題として正面から解決しようとする動きであり、コンサルティング会社が自然に人材を育てるのを待つのではない。具体的な数字（1 億ドル、1 万人、12 週間）は比較可能な投資規模を示している。
- **分類**：その他

## ServiceNow が AutoSynthData を発表：モデルの能力ギャップから企業 Agent の訓練データを自動生成

- **概要**：ServiceNow CoreAI が AutoSynthData を発表——対象モデルの失敗パターンとより強い教師モデルの成功例を比較してモデルが次に何を学ぶべきかを判断し、それに基づいてエンティティ・初期環境状態・ワークフロー構成・ツールの組み合わせ・表現・難易度を変化させた新しいタスクを自動生成・検証する。人手でデータセットを作るのではない；約 18 時間で 2000 件の訓練サンプルを自動生成し、Gemma に教師あり微調整を施したところ、Hybrid ベンチマークで Pass@1 が 7.2 ポイント向上、ITSM ベンチマークでは 18.77% から 27.18% に向上した。
- **なぜ重要か**：これは合成データ生成という技術路線が「企業ワークフロー Agent」という具体的な場面に着地した事例——汎用的な合成データではなく、モデルの実際の能力ギャップから逆算してデータの形を決める；中小チームが低コストで専用 Agent モデルを自作するための再現可能な道筋を示している。
- **分類**：Agent
- **関連Topic**：[model-efficiency](/ja/topics/model-efficiency)・[enterprise-ai-agents](/ja/topics/enterprise-ai-agents)
- **出典**：https://huggingface.co/blog/ServiceNow-AI/autosynthdata
