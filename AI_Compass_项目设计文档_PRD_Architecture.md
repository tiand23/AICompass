# AI Compass 项目设计文档（PRD + 技术架构）

> **项目名称：AI Compass**
>
> **定位：面向 AI 开发者的持续演进知识库（Living AI Developer
> Handbook）**

------------------------------------------------------------------------

# 一、项目背景

随着 AI 技术的发展速度越来越快，开发者每天都会接触到新的概念，例如：

-   MCP
-   Foundry
-   Claude Code
-   Codex
-   LangGraph
-   AG-UI
-   A2A
-   Agent Runtime
-   Responses API
-   新模型
-   新框架

真正的问题不是**信息获取不到**，而是：

> **不知道哪些值得学习、哪些只是营销新闻、哪些未来会成为基础设施。**

因此，本项目希望构建一套能够长期维护 AI
开发生态知识的系统，而不是传统新闻网站。

------------------------------------------------------------------------

# 二、项目目标

AI Compass 不做：

-   AI 新闻网站
-   AI 工具导航
-   AI 模型排行榜

AI Compass 要做的是：

> **持续维护 AI 开发知识库。**

每天自动收集最新信息，并将它们整理为长期可维护的 Markdown 文档。

核心理念：

-   Knowledge \> News
-   长期积累 \> 每日资讯
-   Markdown First
-   Git as Database
-   AI 自动维护知识库

------------------------------------------------------------------------

# 三、目标用户

主要面向：

-   AI 开发者
-   独立开发者
-   企业 AI 工程师
-   Agent 开发者
-   RAG 开发者
-   LLM 应用开发者

------------------------------------------------------------------------

# 四、主要功能

## 1. 每日更新

每天自动收集：

-   OpenAI
-   Anthropic
-   Google AI
-   Microsoft AI
-   LangChain
-   LlamaIndex
-   GitHub Trending
-   HuggingFace

输出：

docs/today/YYYY-MM-DD.md

内容包括：

-   今日重要更新
-   为什么重要
-   是否值得学习
-   推荐指数
-   关联 Topic

------------------------------------------------------------------------

## 2. Weekly

自动汇总一周：

-   最重要技术
-   新概念
-   新框架
-   最值得学习内容

------------------------------------------------------------------------

## 3. Monthly

自动总结：

-   本月趋势
-   本月最佳实践
-   本月值得投入学习方向

------------------------------------------------------------------------

## 4. Topic

每个知识点只有一个 Markdown。

例如：

topics/

-   foundry.md
-   mcp.md
-   claude-code.md
-   codex.md
-   langgraph.md

所有历史都会持续追加。

------------------------------------------------------------------------

## 5. AI 自动维护

新增内容时：

-   去重
-   更新目录
-   更新时间线
-   建立关联
-   合并重复概念

而不是简单追加。

# 七、Claude Code Skills

建议实现以下 Skill：

### /update

执行：

-   抓取最新内容
-   AI 分类
-   更新 Today
-   更新 Topic

------------------------------------------------------------------------

### /today

生成：

today/YYYY-MM-DD.md

------------------------------------------------------------------------

### /weekly

生成：

weekly/Wxx.md

------------------------------------------------------------------------

### /monthly

生成：

monthly/YYYY-MM.md

------------------------------------------------------------------------

### /topic `<名称>`{=html}

作用：

如果 Topic 不存在：

自动创建。

如果存在：

自动更新。

------------------------------------------------------------------------

### /cleanup

执行：

-   去重
-   更新时间线
-   更新目录
-   更新引用
-   合并内容

# 九、AI Prompt 设计

对于每条资讯，让 AI 输出：

-   标题
-   一句话总结
-   为什么重要
-   是否值得学习
-   推荐指数（★1\~★5）
-   分类
-   是否需要新增 Topic
-   关联 Topic
-   是否需要更新时间线

------------------------------------------------------------------------

# 十、去重策略

Claude Code 更新 Topic 时：

不要直接追加。

应该：

1.  判断是否已有相同知识
2.  合并相似内容
3.  更新时间线
4.  更新引用
5.  保持文档结构整洁

# 十四、项目使命

AI Compass 不追求每天发布大量新闻。

真正的目标是：

> **建立一套不断成长、不断完善的 AI 开发知识体系。**

未来，当开发者想了解：

-   MCP
-   Foundry
-   Claude Code
-   Codex
-   LangGraph

无需重新搜索互联网，只需要阅读 AI Compass 中对应的
Topic，即可了解其背景、演进历史、最佳实践以及与其他技术之间的关系。

最终，它将成为一个真正意义上的 **Living AI Developer
Handbook（持续演进的 AI 开发者手册）**。
